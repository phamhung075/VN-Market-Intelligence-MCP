# REQ-211 — Modular Monolith Phase 3a: kinhdich module file moves

## Business goal

Phase 3 of the Modular Monolith refactor. kinhdich is the smallest module (1 tool file, 1 wrapper service) and the lowest-risk starting point. `domain/services/kinhDich/` subfolder already exists with 10 files. Only the tool file and the wrapper need to move.

## Scope

### IN
- Move `src/interface/mcp/tools/kinhDichTools.ts` → `src/interface/mcp/tools/kinhdich/kinhDichTools.ts`
- Move `src/domain/services/kinhDichWrapper.ts` → `src/domain/services/kinhDich/kinhDichWrapper.ts`
- Update barrel re-export paths:
  - `src/interface/mcp/tools/kinhdich/index.ts`: change `../kinhDichTools.js` → `./kinhDichTools.js`
  - `src/domain/services/index.ts`: change `./kinhDichWrapper.js` → `./kinhDich/kinhDichWrapper.js`
- Update any internal imports inside moved files (relative paths shift by one level)

### OUT
- No logic changes
- No other modules touched
- Scheduler: kinhdich has no scheduler jobs — nothing to move

- Fewest files (2 moves)
