## FR-024: Trading Economics Scraper

### Overview

`fetchMacroIndicators()` scrapes the Trading Economics Vietnam country page to extract three macro indicators consumed by the cascade engine. This is the first external macro data source; it establishes a pattern for task 025 (Yahoo Finance) and task 028 (SBV).

### Functional requirements

#### Input / output contract

```typescript
export interface MacroIndicators {
  country: string;       // e.g. "vietnam"
  cpi: number | null;          // CPI index or % YoY
  gdpGrowth: number | null;    // GDP growth rate % YoY
  interestRate: number | null; // Central bank base rate %
  fetchedAt: string;     // ISO 8601 timestamp
}
```

Fields are `null` (not omitted, not `0`) when the scraper cannot extract a value for that indicator. The function never throws — all errors are caught, logged, and reflected as `null` fields.

#### Scraping target

- Base URL: `https://tradingeconomics.com/vietnam/indicators` (configurable via env `TRADING_ECONOMICS_BASE_URL`; used in tests to inject a mock server URL).
- The page contains indicator cards. Each card has a CSS selector pattern: `.te-table` rows or similar structured table. The exact selector must be reverse-engineered from the live page — the Architect should document the final chosen selector in TECH_007.md.
- Selector contract for BA purposes: look for a `<table>` or structured element whose row text contains the indicator label "Inflation Rate" (→ `cpi`), "GDP Growth Rate" (→ `gdpGrowth`), "Interest Rate" (→ `interestRate`).

#### Number parsing

- Values from Trading Economics are in English format (e.g. `"6.3"`); use `parseFloat()`.
- Strip `%` suffix if present.
- If parsed value is `NaN`, set field to `null`.

#### Storage

`storeMacroIndicators(indicators: MacroIndicators, db?: Database): void`

- Upserts into `macro_indicators` SQLite table (new table added to `src/infrastructure/db/schema.ts`):

```sql
CREATE TABLE IF NOT EXISTS macro_indicators (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  country    TEXT NOT NULL,
  cpi        REAL,
  gdp_growth REAL,
  interest_rate REAL,
  fetched_at TEXT NOT NULL,
  UNIQUE(country)
);
```

- Uses `INSERT OR REPLACE INTO macro_indicators (country, cpi, gdp_growth, interest_rate, fetched_at) VALUES (?, ?, ?, ?, ?)`.

#### Integration with cascade engine

The macro indicators are not wired to the cascade engine in this sprint. Task 024 only delivers the scraper and storage. Integration with cascade is deferred to Sprint 008. The `macro_indicators` table being populated is sufficient for task 125 to assert `macroContext` is present in `EveningSummary`.

## Edge Cases & Data Quality

- [ ] PDF with no extractable text (image scan): all BCTC extractor functions receive empty string → all fields return `0` → test case C-05 / B-04 above.
- [ ] BCTC numbers with VND unit suffix in the line: e.g. "1.234.567 triệu đồng" — `extractNumber` regex matches the numeric token before the suffix; suffix is not numeric so the regex's `$` anchor at end of string would not match. **Risk:** if suffix immediately follows the number without space, the regex `(\(?\-?[\d.,]+\)?)[\s]*$` fails. The test suite should include a case with an inline suffix to confirm behavior.
- [ ] Trading Economics page structure may change: use configurable base URL so tests are fully decoupled.
- [ ] `midnightVietnamAsUtc()` in `assembleBriefing.ts` relies on `Date.now()` — tests seeding data "since midnight" must seed rows with `created_at` set to a known UTC time relative to the test's notion of "today". Use a fixed date string in test seeds to avoid flakiness.
- [ ] `parseAffectedCodes` handles two JSON formats (`[{code:"X"}]` and `["X"]`) plus malformed JSON — all three branches exercised in E2E-10, E2E-11, E2E-12.
- [ ] `isWithinHours` in `signalDetector.ts` calls `Date.now()` internally — tests for SD-14 (report within 24 h) should use `new Date().toISOString()` as the report date so the test is always "fresh". Tests for SD-15 (old report) should use a hardcoded ISO string far in the past.
