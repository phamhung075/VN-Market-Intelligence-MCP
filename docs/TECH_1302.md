## Architecture Decision

`formatAnalysisNewsSummary` and `formatAnalysisPolicySummary` are pure grapheme-aware
string truncation functions with zero infrastructure dependencies. They belong in
`src/domain/services/textUtils.ts`. The `analysisFormatters.ts` shim in `infrastructure/adapters/`
was a workaround for sprint 1300b that inadvertently created an upward dependency chain
(domain → infrastructure) that has triggered 6 separate fix commits.

The fix is a relocation, not a redesign. `TelegramMessageFactory` retains its own private
`graphemeLength`/`graphemeSlice`/`smartTruncate` helpers (no cross-layer coupling needed).

## Root Cause Analysis (for `dev-standards.md` update)

The `analysisFormatters.ts` shim was the anti-pattern. Pattern: "I need a domain service to truncate text but the logic lives in infra — I'll add an adapter shim." This is always wrong for stateless pure functions. Correct pattern: extract the pure logic to domain, let infra import domain (allowed direction).

**Canonical rule added to dev-standards.md:**
> Pure string/number utilities with no I/O → `src/domain/services/textUtils.ts`. Never proxy through infrastructure adapters.
