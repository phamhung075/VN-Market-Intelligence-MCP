## Architecture Decision

All 6 FRs are pure domain additions: keyword arrays + a lookup table. Zero I/O, zero infra imports. `climateImpactMapper.ts` is a standalone pure function; it is NOT imported by `cascadeEngine.ts` in this sprint (standalone lookup for future use). This avoids any circular dep risk and keeps cascadeEngine growth bounded.

Sentiment compound phrases use weight 3–4 to guarantee net-bearish outcome when mixed with "tăng" (w1) co-occurring in same text — consistent with Task 1308a weighting rationale already in file.

## Edge Case Resolutions

| Edge case | Resolution |
|-----------|-----------|
| "giá than tăng" overlap with oil_gas ~line 886 | oil_gas rule uses `"kinh doanh than"` (coal trading business) — different keyword, zero overlap. Cross-domain conflict impossible (first-match-wins is per-domain, not cross-domain). |
| "vật liệu xây dựng tăng giá" overlap with steel demand rules | Steel demand rules use `"đầu tư công"`, `"infrastructure spending"` — no keyword overlap with FR-4 material-cost keywords. Confirmed safe. |
| Numeric suffix in VN news ("tăng 15%") | Classifier uses `includes()` substring match — "15%" not a keyword, not matched. No impact. |
| HNG domain tag | `bctc-schema.ts` confirms `utilities = "REE, PC1, POW"` — HNG (city gas distribution) correctly maps to `utilities`. Domain tag valid. |
| climateImpactMapper.ts import guard | Zero imports from `infrastructure/` or `application/`. Only: `DomainType` from `../../../bctc-schema`. DDD compliance verified at design time. |
| climateImpactMapper.ts not imported by cascadeEngine.ts | Standalone lookup only. No circular dep risk. Dev must NOT import from cascadeEngine. |
