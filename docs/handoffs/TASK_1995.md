## TLDR

QA gate: LIVE + 53-fail baseline-diff on fire-time leader election. Verify:
1. Two parallel sessions same cron tick → exactly one wins (claimed:true), one defers (cleanly)
2. Stale leader reclaim: if leader dies, next fire-time elects new leader
3. Period-key collision dedup: same-period ticks do NOT create duplicate claims
4. No orphan work: deferral leaves zero task assignments
5. Presence roster shows winner + loser sessions
