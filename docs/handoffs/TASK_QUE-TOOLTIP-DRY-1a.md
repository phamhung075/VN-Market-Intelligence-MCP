## Implementation Notes

### gen-que-descriptions.ts Rewrite

Replace the current hexagramLibrary import with a direct file read:

```typescript
// BEFORE
import { QUE_DATA, QUE_META } from '../apps/mcp-server/src/domain/services/kinhDich/hexagramLibrary'

// AFTER
import { readFileSync } from 'fs'
import { resolve } from 'path'

const queRefPath = resolve(__dirname, '../apps/kinh-dich-service/dashboard/que-reference.js')
const queRefContent = readFileSync(queRefPath, 'utf-8')
const stripped = queRefContent.replace('window.__QUE_REFERENCE__ = ', '').replace(/;\s*$/, '')
const queReference = JSON.parse(stripped)
```

Field mapping:
- `queReference[i].coreMeaning.vi` → `QueDescription.coreMeaning`
- `queReference[i].marketTrendLabel.vi` → `QueDescription.marketTrendLabel`

Drop these fields (not used in tooltip):
- `judgment_interpretation` (was from hexagramLibrary.ts `judgment.interpretation`)
- `image_action` (was from hexagramLibrary.ts `image.action`)
- `state_trend` (was raw ASCII prefix; replaced by marketTrendLabel)

### Smoke Test

### QueName.tsx Changes

Update the QueDescription interface in the component file:

Update tooltip secondary field:

Note: `className` removes `italic`.
