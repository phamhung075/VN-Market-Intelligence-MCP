## Implementation

**Patch site:** Immediately before line 143 (the `if [ "${is_sprint_scoped}" = "true" ]` check). The `scope` variable is already extracted at line 129.

**Insert logic (lines 143–159):**

```bash
  # C2 exempt: scope digit is cycle/PM-cycle reference, not sprint task
  # Or: subject is a sprint-scoped merge-task chore (AC lives on feat/fix)
  local is_c2_exempt=false
  case "${scope}" in
    cycle-[0-9]*)
      is_c2_exempt=true
      ;;
    pm/c[0-9]*)
      is_c2_exempt=true
      ;;
    pm/[0-9][0-9][0-9][0-9]*)
      is_c2_exempt=true
      ;;
  esac
  case "${lsubj}" in
    *"merge task/"*)
      is_c2_exempt=true
      ;;
  esac

  if [ "${is_sprint_scoped}" = "true" ] && [ "${is_notebook}" = "false" ] && [ "${is_c2_exempt}" = "false" ]; then
    c2_denominator=$((c2_denominator + 1))
```

**Bash 3.2 compliance:**
- POSIX `case` with glob patterns (no ERE, no `[[ ]]`)
- Literal string in quotes for `"merge task/"` match
- No `local -n`, `mapfile`, `declare -A`
- LC_ALL=C already set at script top
