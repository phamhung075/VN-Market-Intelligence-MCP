# TASK_1420 — wrap-missing-jobs-recordJobRun

Branch: `task/1420-cron-health-coverage`

## Summary

9 scheduler jobs were invisible to `get_cron_health` because they used bare `try/catch` in `jobs.ts` and had no `recordJobRun` call in their execution path.

### Root cause analysis

| Job | Status before fix |
|-----|------------------|
| `marketScanJob:open/close` | `recordJobRun` inside `runMarketScan()` → already visible |
| `sscCheckerJob` | `recordJobRun` inside `runSscCheck()` → already visible |
| `dataAuditJob:daily` | `recordJobRun` inside `runDailyAudit()` → already visible |
| `dataAuditJob:weekly` | NO `recordJobRun` anywhere → invisible |
| `bctcReparseJob` | NO `recordJobRun` anywhere → invisible |
| `evidenceAccumulatorJob` | `recordJobRun` only in wrapper `runEvidenceAccumulatorJob()`, not in `runEvidenceAccumulator()` → invisible via `jobs.ts` path |
| `baseRateComputationJob` | same pattern → invisible |
| `predictionResolutionJob` | same pattern → invisible |
| `calibrationReportJob` | same pattern → invisible |

### Fix

Added 6 exported testable wrapper functions to `jobs.ts`:
- `runWeeklyAuditWithDb(db, fn?)`
- `runBctcReparseWithDb(db, fn?)`
- `runEvidenceAccumulatorWithDb(db, fn?)`
- `runBaseRateComputationWithDb(db, fn?)`
- `runPredictionResolutionWithDb(db, fn?)`
- `runCalibrationReportWithDb(db, fn?)`

Each calls `recordJobRun(db, jobName, fn)`. Production cron callbacks updated to use these wrappers with `getDb()`.
