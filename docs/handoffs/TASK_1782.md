# TASK_1782 Handoff — BCTC Q1-2026 Queue Seeding Fix

## Status
DONE — implementation committed on `task/1782-bctc-enricher-q1-2026`

## Root Cause (confirmed: Option A + missing seeder)

Two separate bugs combined to produce 0 Q1-2026 rows:

**Bug 1 — No Q1-2026 seeder exists:**
- `backfillBctcQ4()` in `schema.ts` only seeds Q4-2025 rows (hardcoded year).
- `/api/bctc-fetch-queue` uses `detectTargetQuarter(year, month)` which returns
  Q4-2025 for months 1–4 (April = month 4). Today is April 30 — still in the
  Q4-2025 window. Q1-2026 rows are not seeded until May 1 when month becomes 5.
- Result: `bctc_vps_queue` has 54 Q4-2025 rows, 0 Q1-2026 rows.

**Bug 2 — Enricher leaves no-URL rows pending forever:**
- The 35 rows with `status=pending, source_url=NULL` represent failed URL
  discovery runs. The enricher left them `pending` (documented as "VPS retry
  later") but VPS only pulls rows where `source_url LIKE 'http://125.212.251.27:8765/bctc-files/%'`.
- These rows had no `attempts` tracking — the enricher never incremented
  `attempts`, so there was no mechanism to park exhausted rows.

## Changes Made

### `apps/mcp-server/src/infrastructure/db/seedWatchlist.ts`
- Added `backfillBctcQ1_2026(db)`: idempotent `INSERT OR IGNORE` for all
  watchlist tickers not yet in `financial_reports` for Q1-2026. Same pattern
  as `backfillBctcQ4()`.

### `apps/mcp-server/src/infrastructure/db/schema.ts`
- Imported and called `backfillBctcQ1_2026()` inside `initDatabase()` alongside
  `backfillBctcQ4()`. Guarded by `!isTestEnv` (same as Q4 backfill).

### `apps/mcp-server/src/scheduler/financial-reports/bctcQueueEnricherJob.ts`
- Added `MAX_ENRICH_ATTEMPTS = 5` constant.
- Query now also selects `attempts` column.
- On no-URL result: if `attempts >= MAX_ENRICH_ATTEMPTS` → marks row
  `status='url_not_found'`; else increments `attempts` and leaves `pending`.
- On discovery error: always increments `attempts` (so error-looping rows
  also eventually park).
- Prepared statements: added `incrementAttemptsStmt` and `markUrlNotFoundStmt`.

### `apps/mcp-server/src/__tests__/1782-bctc-q1-2026-seeding.test.ts`
- 11 tests covering:
  - `backfillBctcQ1_2026()` seeds Q1-2026 rows
  - Skips tickers with existing Q1-2026 financial_report
  - Idempotency (calling twice = same row count)
  - INSERT OR IGNORE semantics (in-progress rows not reset)
  - schema.ts wiring (export present, import compiles)
  - Enricher marks `url_not_found` at attempts >= MAX
  - Enricher stays `pending` below MAX
  - Enricher increments `attempts` on no-URL run
  - `partialFailures` counted correctly
