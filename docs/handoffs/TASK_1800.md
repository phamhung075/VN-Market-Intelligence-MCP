## What was done

### 1. `apps/mcp-server/src/infrastructure/fetchers/tradingEconomicsChromium.ts`

Both `playwrightScrape` (indicators) and `playwrightScrapeNews` (news) functions updated:

**puppeteer.launch() args** — expanded from 3 flags to 14:
- `--disable-dev-shm-usage` (already present, kept)
- Added: `--disable-gpu`, `--no-first-run`, `--no-zygote`, `--single-process`,
  `--disable-extensions`, `--disable-background-networking`, `--disable-default-apps`,
  `--disable-sync`, `--disable-translate`, `--hide-scrollbars`,
  `--metrics-recording-only`, `--mute-audio`, `--safebrowsing-disable-auto-update`

**Navigation strategy** — changed in both scrapers:
```
Before: await page.goto(url, { waitUntil: 'networkidle2', timeout: 30_000 });
After:  await page.goto(url, { waitUntil: 'domcontentloaded', timeout: 30_000 });
        // followed by existing waitForSelector() call
```

The indicators scraper waitForSelector timeout was also bumped 15s → 20s for consistency.

### 2. `docker-compose.yml`

Added `shm_size: '256mb'` to the `mcp-server` service (directly after the `build:` block).
Docker default is 64 MB; Chromium renderer requires 256 MB+ for complex pages.
