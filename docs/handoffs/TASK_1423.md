### 1423c — Carry Trade Signal MCP tool

**Depends on:** 1423b (fredApi.ts must exist)

**Files to create:**
- `apps/mcp-server/src/domain/services/macro/carryTradeSignal.ts`
  - `computeCarryTradeSignal(vndRate: number, fedRate: number): CarryTradeSignal`
  - Pure function — ZERO infrastructure imports
  - Regime thresholds: HOT_MONEY_INFLOW (spread > 2.5%), NEUTRAL (0.5–2.5%), FII_OUTFLOW_RISK (< 0.5%)
  - Degrades gracefully: if vndRate=0 → regime="UNKNOWN", do not crash

```typescript
interface CarryTradeSignal {
  vndDepositRate: number;
  fedFundsRate: number;
  carrySpread: number;
  regime: "HOT_MONEY_INFLOW" | "NEUTRAL" | "FII_OUTFLOW_RISK" | "UNKNOWN";
  reasoning: string;
  computedAt: string;
}
```

- `apps/mcp-server/src/interface/mcp/tools/macro/carryTools.ts`
  - Registers `get_carry_trade_signal` MCP tool
  - Tool handler: queries `sbv_rates.max_deposit_rate_pct` (latest) + `tracked_indicators` where `indicator='fed_funds_rate'`, calls `computeCarryTradeSignal`
  - Registers `get_macro_calendar` MCP tool (re-export from macroCalendar.ts — see 1423e)

**Files to modify:**
- `apps/mcp-server/src/interface/mcp/tools/macro/index.ts` — export carryTools
- `apps/mcp-server/src/interface/mcp/tools/registry.ts` — register carryTools

**Test:** `apps/mcp-server/src/__tests__/1423-bau-phase1.test.ts`
- All 3 regime branches (HOT_MONEY_INFLOW / NEUTRAL / FII_OUTFLOW_RISK)
- Zero-rate edge case (UNKNOWN regime)

**Acceptance:** `get_carry_trade_signal` returns valid CarryTradeSignal with regime label.

### 1423d — Extend get_macro_snapshot (Thien Thoi section)

**Depends on:** 1423a (us10yYield in commodity), 1423b (fed_funds_rate in tracked_indicators)

**Files to modify:**
- `apps/mcp-server/src/interface/mcp/tools/macro/macroTools.ts`
  - Query `tracked_indicators` for `fed_funds_rate` before formatting
  - Compute carry spread inline from `rates.max_deposit_rate_pct` + `fedFundsRate`
  - Call `computeCarryTradeSignal` for regime label
  - Add `[Global Macro Inputs — Thien Thoi]` section to `formatMacroSnapshot` output:

```
[Global Macro Inputs — Thien Thoi]
  DXY:            104.2 (+0.3% vs 30d avg) — USD STRENGTHENING → EM pressure
  US 10Y Yield:   4.52% — RISK-OFF (>4.5%) — PE compression signal
  Fed Funds Rate: 5.33% (FRED)
  VND Carry Spread: +2.1% (VND 5.5% - Fed 5.33%) — NEUTRAL
  Global Liquidity: TIGHTENING
```

Signal thresholds (hard-coded per methodology):
- DXY > 30d mean +2%: USD STRENGTHENING; < -2%: USD WEAKENING
- US 10Y > 4.5%: RISK-OFF; < 4.0%: RISK-ON
- Carry spread > 2.5%: HOT_MONEY_INFLOW; < 0.5%: FII_OUTFLOW_RISK
- Global Liquidity label: majority vote across 3 signals

IMPORTANT: When DXY=0, show "unavailable" — do NOT show "0%".
IMPORTANT: Check existing tests in macroTools.test.ts — if any use full-text equality on `formatMacroSnapshot` output, add the new section to their expected value. All other tests using `toContain` will pass unchanged.

**No type change to `MacroSnapshotResponse`** — carry data computed inline, not stored in struct.

**Test:** `apps/mcp-server/src/__tests__/1423-bau-phase1.test.ts`
- Snapshot test covering each regime combination (TIGHTENING / NEUTRAL / EXPANSIVE)
- Zero-DXY graceful degradation

**Acceptance:** `get_macro_snapshot` output contains `[Global Macro Inputs — Thien Thoi]` section with non-zero values.

### 1423e — get_macro_calendar tool (independent)

**No dependencies — Tier 1, start in parallel with 1423a and 1423b.**

**Files to create:**
- `apps/mcp-server/src/domain/services/macro/macroCalendar.ts`
  - `getMacroCalendar(referenceDate?: Date): MacroCalendarResult`
  - Pure function — ZERO infrastructure imports, ZERO DB, ZERO HTTP
  - Static FOMC dates array (2025–2026 meetings)
  - Static recurrence rules:
    - GSO CPI: first week of each month (day 7 anchor)
    - GSO GDP: day 15 of month after quarter end (Apr 15, Jul 15, Oct 15, Jan 15)
    - SBV pivot windows: months 3, 6, 9, 12 (day 15 anchor)
    - PMI: day 2–3 of each month (day 2 anchor)
  - Output: events within `daysAhead=60` window, each with `{ event, date, daysUntil, type, importance: "HIGH" | "MEDIUM" }`
  - Placement: `apps/mcp-server/src/domain/services/macro/macroCalendar.ts` (domain layer, inline constants — NOT shared-config)

**Note:** `get_macro_calendar` MCP tool registration is in `carryTools.ts` (Task 1423c). If 1423e ships before 1423c, the domain function is ready but tool registration waits for 1423c.

**Test:** `apps/mcp-server/src/__tests__/1423-bau-phase1.test.ts`
- Fixed reference date → verify correct events generated with correct `daysUntil`
- At least 3 events returned for any call date within a 60-day window

**Acceptance:** `get_macro_calendar` returns at least 3 upcoming events for any call date.

## Cross-Cutting Constraints

- DDD golden rule: `domain/` files (`carryTradeSignal.ts`, `macroCalendar.ts`) have ZERO imports from `infrastructure/`.
- All fetchers use browser User-Agent (Vietnamese sites; FRED is US but follow the standard).
- Bun.env (not process.env) for any env var access (e.g., optional FRED_API_KEY fallback).
- Import paths: always `.js` extension (ESM compatibility).
- MCP tools return format: `{ content: [{ type: "text" as const, text: JSON.stringify(result, null, 2) }] }`.
- Test baseline: must stay at 8090+ pass, 0 fail after all tasks merge.
