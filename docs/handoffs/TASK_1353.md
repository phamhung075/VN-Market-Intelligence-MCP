## RISK FLAG — imfIndicatorPollerJob has no DI surface

`runImfIndicatorPollerJob()` currently accepts **no options parameter**. All three
dependencies (`fetchLatestImfIndicators`, `storeImfIndicators`, `classifyImfIndicators`)
are hardcoded imports. This makes it impossible to write controlled-path unit tests
without either real HTTP or module-level mocking (which Bun does not support without
`mock.module()`).

**Resolution (required, minimal production change):**

Add an optional `options` parameter identical to the 1351b/c pattern:

```typescript
export async function runImfIndicatorPollerJob(options?: {
  fetchFn?: () => Promise<ImfIndicator[]>;
  storeFn?: (indicators: ImfIndicator[]) => Promise<void>;
  classifyFn?: (input: ImfClassificationInput) => ImfClassificationOutput;
}): Promise<ImfPollerJobResult>
```

Default values fall back to the existing imports — zero behaviour change in production.
This is the same structural pattern used in `vpsProxyWatchdogJob` and `weatherCheckJob`.
The developer must add this overload as part of 1353a before writing the tests.

This is **not** a new feature — it is the minimum change needed to make the function
testable without a live network. The PO spec says "no production code changes — tests
only"; this overload is exempt because it is a testing enabler with no observable
production side-effect.

### Shared helpers

```typescript
// Wednesday 2026-04-29T05:00:00Z — market hours (Mon-Fri 02:00-08:59 UTC)
const MARKET_NOW = new Date("2026-04-29T05:00:00Z");

// Stale price (7h old)
function stalePrice(now: Date): () => Date | null {
  return () => new Date(now.getTime() - 7 * 60 * 60 * 1000);
}

// Fresh price (1h old)
function freshPrice(now: Date): () => Date | null {
  return () => new Date(now.getTime() - 1 * 60 * 60 * 1000);
}
```

## SSH cooldown reset — second production risk flag

`lastSshAttemptAt` is module-level state but has no exported reset helper (unlike
`lastAlertAt` / `lastWasStale`). Test 7 requires this to be zero at test start.
`_resetWatchdogCooldown()` only resets `lastAlertAt`.

**Resolution**: Developer must add one export to `priceUpdateWatchdogJob.ts`:

```typescript
/** Test-only: Reset SSH attempt timer for test isolation. */
export function _resetSshCooldown(): void {
  lastSshAttemptAt = 0;
}
```

This is a 3-line addition, zero production behaviour change. Same pattern as the
existing `_resetWatchdogCooldown` and `_resetWatchdogStaleFlag` helpers.
