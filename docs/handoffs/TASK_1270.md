## Problem Summary

SBV FX rate has inherent micro-fluctuations (±2-3 VND daily noise). Current threshold in `src/domain/services/macroThresholds.ts` is too tight — 2.8 VND deviation fires CRITICAL alert as -3.73σ. This is economically meaningless (0.011% move) but creates false-alarm fatigue.

---

## Solution Implemented

Added **minimum absolute deviation guard** for VND-based indicators in `classifyDeviation()`:

- For `usdVndRate`, `usdVndOfficial`, and similar (any indicator name containing "VND"):
  - If absolute deviation < 10 VND: cap level at "elevated" max (prevent high/extreme false positives)
  - If absolute deviation ≥ 10 VND: apply normal z-score thresholds

Logic: `name.toLowerCase().includes("vnd")` → `minAbsDeviation = 10`, else `0`
Downgrade: extreme/high → elevated when below threshold

This prevents economically meaningless micro-moves from triggering CRITICAL alerts without affecting other indicators (oil, gold, rates).
