## Context
`ChainCatalystFindingDataSchema` (Zod, server-side) does NOT include
`regime` or `regime_adjusted_score` fields. When news-scout posts a
`chain_catalyst` signal with those fields, they are silently stripped
before storage. The cycle.md template shows them as valid — this is
misleading and causes future agents to trust data that was never saved.

The `urgent_news` finding_data block also has these fields and they ARE
stored (different schema) — do not touch that block.

## Changes Required

### chain_catalyst finding_data block (Step 3, second signal template)

Current block (lines ~84-97):
```json
"finding_data": {
  "event_type": "<credit_policy|trade_war|earnings|macro|legal|crisis|sector_event>",
  "direction": "<bullish|bearish|neutral>",
```

Remove `"regime"` and `"regime_adjusted_score"` lines entirely.

Move the regime context to `payload.detail` instead — update the `payload` block to:

Final `finding_data` block should be:
