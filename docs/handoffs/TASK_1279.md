## Design Decisions

### 1. Domain Logic: MSCI_INCLUSION_RULES Structure

```typescript
// At cascadeEngine.ts:2180
export const MSCI_INCLUSION_RULES: CascadeKeywordRule[] = [
  { key: "msci_large_cap_1", keyword: "nộp danh sách", sector: "all_largecp" },
  { key: "msci_large_cap_2", keyword: "đáp ứng tiêu chí", sector: "all_largecp" },
  { key: "msci_large_cap_3", keyword: "chỉ số msci", sector: "all_largecp" },
];
```

**Rationale:**
- `sector: "all_largecp"` is pseudo-domain; application layer filters by actual stock classification
- Keywords = case-insensitive, whole-word match (not substring)
- Parallel to INSIDER_DUMP_RULES (3 rules, shared key prefix)

### 4. Cascade Strategy: NOT Like Insider Dump

| Aspect | Insider Dump (1278) | MSCI Inclusion (1279) |
|--------|------------------|----------------------|
| **Trigger** | CEO exits at VCB | Stock eligible for MSCI |
| **Contagion** | Bearish → cascade to peer banks | Bullish → target large-caps only |
| **Affected Stocks** | VCB + peers (BID, CTG, ACB) | MWG + only if mentioned/eligible |
| **Sentiment** | Bearish (negative) | Bullish (positive) |
| **Impact Duration** | Short (weeks) | Medium (3–6 months) |
