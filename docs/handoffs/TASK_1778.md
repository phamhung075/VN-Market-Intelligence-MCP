## Problem
vnstock API returns box-drawing characters (`╭──...`) instead of JSON on VPS
Playwright + SSC + cafef endpoints. The three `JSON.parse` calls in
`bctcDiscovery.ts` were inside `try/catch` but silently returned `[]` — causing
all 4 discovery strategies to produce empty results and leaving 28 tickers stuck
at `status=pending, url=MISSING` forever.

## Fix
**2 files changed:**

### `apps/mcp-server/src/domain/services/bctcDiscovery.ts`
- Added exported `stripAnsiJunk(raw: string): JunkCheckResult` — same regex
  as Task 1776's `stripAnsiAndDetectJunk` in `vnstockBridge.ts`, inlined here
  because the domain layer cannot import from infrastructure.
- Guards added to `extractVpsPlaywrightUrls`, `extractSscUrls`,
  `extractCafefUrls` — each checks `stripAnsiJunk()` before calling
  `JSON.parse`. Junk responses return `[]` immediately with no false fallthrough.

### `apps/mcp-server/src/__tests__/1778-bctc-vnstock-junk-response.test.ts`

  non-JSON-first-char) + integration tests (`discoverHosePdfUrls` falls through

### Blocking Issue: B-1

**File:** `apps/mcp-server/src/domain/services/bctcDiscovery.ts` lines 268–269

`extractCafefUrls` applies `stripAnsiJunk` before Strategy A (JSON parse) and
immediately returns `[]` on `{ junk: true }`. Since HTML responses start with
`<`, they are classified as junk — the early return fires before Strategy B
(HTML href scraping at lines 295–304) can execute.

**Failing test (regression):**
`apps/mcp-server/src/__tests__/1343b-hose-pdf-discovery-red.test.ts`
"should fallback to cafef.vn when SSC returns no results"
Expected: `result.source === "cafef"` / Received: `null`

**Required fix:**
Move the junk guard so it only gates `JSON.parse` (Strategy A). Strategy B
(HTML scraping) must always execute if Strategy A produces no results — even
when the raw input is HTML (not JSON junk).

```typescript
// Correct structure:
function extractCafefUrls(raw: string, _ticker: string): string[] {
  // Strategy A: JSON API — junk guard applies here only
  const check = stripAnsiJunk(raw);
  if (!check.junk && !check.isNull) {
    try {
      const parsed = JSON.parse(check.cleaned) as unknown;
      // ... extract json urls ...
      if (urls.length > 0) return urls;
    } catch { /* not JSON, fall through */ }
  }

  // Strategy B: HTML href scraping — always runs
  const urls: string[] = [];
  PDF_HREF_RE.lastIndex = 0;
  let match: RegExpExecArray | null;
  while ((match = PDF_HREF_RE.exec(raw)) !== null) {
    const href = match[1];
    if (href === undefined) continue;
    const absolute = href.startsWith("http") ? href : `${CAFEF_BASE}${href}`;
    urls.push(absolute);
  }
  return urls;
}
```
