# TASK_1390 Handoff — Volume Decimal Shift Fix

## Status: IMPL DONE — awaiting QA

## Root Cause

`ohlcvDailyAggregatorJob.ts` line 114 stored `const volume = count` where `count`
is `COUNT(*)` — the number of price-snapshot poll records in the intraday window
(e.g. 519 polls over market hours), not the actual traded volume in shares.

`market_prices_history.volume` already contains the cumulative traded volume
reported by the exchange at each snapshot (e.g. 5,194,900 shares for VIC by close).
The correct aggregation is `MAX(volume)` — the last snapshot's cumulative total
equals the end-of-day traded volume.

**Bug effect**: VIC displayed as 519.5K instead of 5,194.9K (×10 underreported at
~8.6h of 1-minute polls = ~519 ticks).
