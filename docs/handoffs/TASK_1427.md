Add helper function `fmtThousands` near the top of the formatting helpers section:

```typescript
/** Vietnamese dot-thousands formatter: 1285 → "1.285" */
function fmtThousands(n: number): string {
  return Math.round(n).toString().replace(/\B(?=(\d{3})+(?!\d))/g, ".");
}
```

**Why regex over `toLocaleString`**: avoids Bun ICU locale availability uncertainty. Regex is zero-dependency and deterministic.
