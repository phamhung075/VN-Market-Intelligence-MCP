# TASK_1380 Handoff — change_pct pre-open phantom alert guard

## Summary

Fixed: `change_pct` price alerts fired at 00:10 UTC (market closed) because
`detectSignals` was called unconditionally on every VPS push, regardless of
trading hours. Stale `ref_price` from closed sessions produced phantom readings
(GAS alert id 316: +1.16% phantom vs actual -3.07% intraday).

## Fix Detail

Added `isVnTradingWindowUtc(now: Date): boolean` to `server.ts`:
- Returns `true` only 02:00–08:59 UTC, Mon–Fri
- Same logic as existing `isVnMarketHoursUtc` in `vpsProxyWatchdogJob.ts`
- Placed as early return guard before the `detectSignals` import block in the
  `setImmediate` async handler (line ~685)

The guard suppresses both `change_pct`-derived signals AND user-defined price
alerts outside the trading window (checkPriceAlerts is also inside the guarded
block). Pre-open VPS pushes continue to write to `market_prices` and
`market_prices_history` — only the alert/signal generation is skipped.
