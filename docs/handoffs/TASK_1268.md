## Root Cause

retail_netbuy_securities rule only affected brokerages (SSI/VCI/VIX/VND) via domain mapping. However, major banking stocks (VCB, BID, CTG, ACB) also benefit from:
- Market confidence boost from retail buying (stabilization signal)
- Liquidity increase enabling better execution for institutional positions
- Positive sentiment spillover from trading activity

Without affected_actions, alerts for retail net-buying events did not trigger for banking stocks.

## Solution Details

Added affected_actions array to retail_netbuy_securities rule with 4 banking stock codes (VCB, BID, CTG, ACB), each mapped to direction "up" (BULLISH). This ensures that high-confidence market stabilization signals (retail buying + liquidity increase) trigger alerts for major banks.
