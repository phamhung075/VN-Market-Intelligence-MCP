# TASK 1784 — Handoff to QA

## What was fixed

### BUG-4: Sector alert label rewrite
Alerts generated for sector-wide declines store a message like:
`ACB alert [HIGH]: price_drop — ⚠️ Ngành Ngân hàng giảm đồng loạt ...`

The per-ticker prefix ("ACB alert") was misleading — the body describes the entire sector,
not ACB specifically. Fix: the new `formatAlertLines()` detects "Ngành" in the body text
and rewrites the display label to `[Ngân hàng] Sector (CAO)`.

### BUG-5: Same-body deduplication
Because `scanMarket.ts` emits one sector-decline signal per watchlist ticker in the sector,
the `alerts` DB has 3 rows (ACB, BID, CTG) with identical body text. The old 40-char prefix
dedup in `fetchTopAlerts` did NOT collapse them because their prefixes differed by ticker name
("ACB alert..." vs "BID alert..." vs "CTG alert...").

Fix: `formatAlertLines()` groups by body text (the part after ` — `), collapses to one line,
and appends `(+3)` to show the original count.
