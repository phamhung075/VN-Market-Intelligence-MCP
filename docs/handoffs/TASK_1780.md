**Type:** FIX

## What Was Fixed

### Problem
The vnstock finance endpoints (balance_sheet, cash_flow, income_statement/financials, trading_stats) were receiving box-drawing characters (`╭`) from the VCI API — a rate-limit / IP-block response from vnstock's `rich` progress bar. Previously:
- The junk was detected by `stripAnsiAndDetectJunk()` and returned `null` immediately
- No distinction between rate-limit (retryable) and generic Python errors (non-retryable)
- No backoff — fetcher would hammer the rate-limited endpoint again on the next cycle
- No structured WARN log with retry context

### Fix Applied (2 exports added, 4 call sites updated)

**File:** `apps/mcp-server/src/infrastructure/fetchers/vnstockBridge.ts`

1. **`isRateLimitResponse(raw: string): boolean`** (exported)
   - Returns `true` when stdout contains Unicode Box Drawing chars (`\u2500-\u257F`)
   - Specifically classifies the vnstock `rich` UI response as RATE_LIMITED
   - Distinct from generic Python errors (no box-drawing) — those are NOT retried
   - Empty / `"null"` → `false` (legitimate null result, not rate-limited)

2. **`calcBackoffMs(attempt, opts): number`** (exported)
   - Exponential backoff: `min(baseMs * 2^attempt + rand(0, jitterMs), maxMs)`
   - Default: base=2000ms, jitter=1000ms, max=30000ms → 2s/4s/8s with ±1s jitter

3. **`runPythonWithBackoff<T>()`** (internal)
   - Wraps `runPython` with up to 3 retries on `RATE_LIMITED` sentinel
   - Each retry: WARN log with `{label, attempt, wait_ms}`, then waits backoff period
   - Exhausted retries: WARN log then returns `null` (circuit breaker in `syncVnstockData` handles the rest)

4. **Updated call sites** to use `runPythonWithBackoff` for finance endpoints:
   - `fetchVnstockFinancials` (income statement + ratios)
   - `fetchVnstockTradingStats`
   - `fetchVnstockBalanceSheet`
   - `fetchVnstockCashFlow`
   - Non-finance endpoints (prices, officers, shareholders, intraday, orderbook, events, news) remain on `runPython` — no backoff needed

### Design Decisions
- `RATE_LIMITED` sentinel is a module-internal string constant — not exported; only `isRateLimitResponse` and `calcBackoffMs` are exported for testability
- Box-drawing range `\u2500-\u257F` covers all 128 Box Drawing Unicode chars including `╭ ╮ ╰ ╯ │ ─`
- Existing circuit breaker in `syncVnstockData.ts` is unchanged — it still opens after 3 consecutive nulls. The backoff in the fetcher adds a wait-before-retry layer that reduces circuit-open probability
