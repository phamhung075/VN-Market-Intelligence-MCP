# Task 1476 — Test Isolation: console.error Suppression for WAL Stuck Alert

## Summary

Add test isolation to prevent `console.error` leakage during parallel test execution in `walCheckpointAlert` unit tests.

## Problem

Test 1476 (`1476-wal-stuck-alert.test.ts`) calls `walCheckpointAlert()` with a throwing function to verify error resilience. The error handler logs to `console.error` (line 43 of `walCheckpointAlert.ts`). In parallel test mode, this stderr output pollutes other test runs and makes logs hard to read.

## Solution

Mock `console.error` in test fixtures using `beforeEach`/`afterEach` hooks:
- **beforeEach**: Capture and replace `console.error` with no-op
- **afterEach**: Restore original immediately after each test
