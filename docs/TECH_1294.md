## Architecture Decision

**Problem:** Sprint 1293 strict signal validation prevents incomplete payloads from reaching downstream. But News Scout + Market Watcher are not populating `newsSentiment` field (required for 4-AND alerts). Additionally, BCTC extraction timeouts cause silent data loss—no fallback to enrich from available signals.

**Solution:** Two-part enrichment strategy:

1. **IMF Sentiment Detection (FR-1 → 1294a)**
   - NEW domain service `imfSentimentClassifier.ts`: detect IMF-related news (policy vs crisis)
   - Classify sentiment as policy_adjustment (+0.3..+0.7) vs crisis_signal (-0.6..-0.3) vs neutral (0.0)
   - Integrate into cascadeEngine → assign IMF classification label to CausalChainEntry
   - Wire into pollNews.ts → populate ChainCatalystFindingData.newsSentiment before Zod validation
   - Keyword list: "IMF", "International Monetary Fund", "Quỹ Tiền Tệ Quốc Tế", "SPA", "Stand-by Arrangement"

2. **BCTC PDF Timeout Fallback (FR-2 → 1294b)**
   - NEW domain service `signalToBctcMapper.ts`: map signal findingData → financial_reports fields
   - MODIFY fetchParseAndStoreBctc.ts: catch timeout/OCR errors → query recent chain_catalyst signals
   - Fallback only if ≥2 signals mention BCTC keywords ("revenue", "margin", "debt", "reserves") + signals ≤7 days old
   - Populate financial_reports with extraction_method='news_inference' + confidence=0.55 + source_note
   - Downstream tools apply 10% confidence penalty (per PO decision B2)

**Rationale:**
- IMF classification is pure domain logic (keyword matching + rule-based sentiment); no I/O needed
- Signal-to-BCTC mapping is domain utility (field transformer); reuses existing signal schema
- Fallback logic lives in application (fetchParseAndStoreBctc orchestrator) — integrates infrastructure I/O + domain logic
- Age window configurable via env var (BCTC_FALLBACK_SIGNAL_MAX_AGE_DAYS, default 7) — ops flexibility
- Maintains backward compat: newsSentiment optional during rollout; extraction_method handles both OCR + news_inference

/**
 * IMF Sentiment Classifier — pure domain service (Task 1294a)
 *
 * Detects IMF-related news and classifies as policy_adjustment vs crisis_signal.
 * No I/O, no infrastructure imports.
 */

export interface ImfClassification {
  /** 'imf_policy_adjustment' | 'imf_crisis_signal' | 'non_imf' | 'imf_neutral' */
  classification: 'imf_policy_adjustment' | 'imf_crisis_signal' | 'non_imf' | 'imf_neutral';
  /** Sentiment value to populate ChainCatalystFindingData.newsSentiment */
  sentiment: number; // [-1, 1]
  /** Confidence in classification [0, 1] */
  confidence: number;
  /** Matched keyword or rule label for audit */
  reason: string;
}

/**
 * Classify IMF-related sentiment from headline + summary.
 *
 * Rules:
 *   - Contains IMF keyword + "stand-by arrangement" / "emergency financing" → crisis_signal (-0.6..-0.3)
 *   - Contains IMF keyword + "staff report" / "policy support" → policy_adjustment (+0.3..+0.7)
 *   - Contains IMF keyword (no program) → imf_neutral (0.0..+0.3)
 *   - No IMF keyword → non_imf (sentiment = 0.0)
 *
 * @param headline News article headline
 * @param summary News article summary / body
 * @returns ImfClassification with sentiment + confidence
 */
export function classifyImfSentiment(headline: string, summary: string): ImfClassification
```

### New Domain Service: signalToBctcMapper

/**
 * Signal-to-BCTC Field Mapper — pure domain service (Task 1294b)
 *
 * Transforms signal.findingData into financial_reports field hints.
 * Extracts revenue growth, margin trend, debt ratio from signal headlines/summaries.
 * No I/O, no infrastructure imports.
 */

export interface BctcFieldHints {
  /** Derived revenue growth direction: +1 (bullish), -1 (bearish), 0 (unclear) */
  revenue_growth_hint: number;
  /** Margin trend: +1 (expansion), -1 (compression), 0 (unchanged) */
  margin_trend: number;
  /** Debt ratio if extractable: 45 (means 45%), null if not found */
  debt_ratio_pct: number | null;
  /** List of financial keywords detected in signal */
  keywords_found: string[];
  /** Confidence in extracted hints [0, 1] */
  confidence: number;
}

/**
 * Extract BCTC-like field hints from a single chain_catalyst signal.
 *
 * Regex patterns:
 *   - Revenue: "revenue.*up|revenue.*growth|doanh thu.*tăng"
 *   - Margin: "margin.*compression|biên lợi nhuận.*hẹp" (bearish) vs "margin expansion" (bullish)
 *   - Debt: "debt\s+(\d+%)" or "d/e\s+ratio.*(\d+\.?\d*)"
 *
 * @param signal Agent signal with findingData (headline, source, direction)
 * @returns BctcFieldHints with extracted fields + confidence
 */
export function extractBctcHints(signal: {
  findingData: Record<string, unknown>;
  headline?: string;
  direction?: 'bullish' | 'bearish' | 'neutral';
}): BctcFieldHints
```

## Risk Assessment

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|-----------|
| **IMF keyword false positives** (non-IMF using "IMF-like" language) | Medium | Low | Strict regex: require "International Monetary Fund" OR "IMF" OR "Quỹ Tiền Tệ Quốc Tế" in exact form; exclude World Bank/ADB/BIS |
| **BCTC fallback confidence threshold mismatch** | Low | Medium | PO decision B2: 0.5+ threshold captures 80% of signals; 10% downstream penalty applied for news_inference; audit trail logs all fallback events |
| **Signal age window default too conservative** | Low | Medium | Configurable env var (BCTC_FALLBACK_SIGNAL_MAX_AGE_DAYS, default=7); ops can adjust without redeploy |
| **Stale signals cause incorrect BCTC field inference** | Medium | Medium | Require ≥2 credible signals + contradiction check; skip fallback if signals conflict; temporal discount for old signals |
| **PDF extraction succeeds AFTER fallback inserted** | Low | Low | UNIQUE(action_code, sort_key) ensures OCR row overwrites; extraction_method field distinguishes source for downstream validation |
| **Configurability confusion (env var unused)** | Low | Low | Docs + default value document in TECH_1294; signal_rejections audit table (from 1293c) logs fallback usage |
