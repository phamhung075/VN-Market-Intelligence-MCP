# REQ_210 — Phase 2: Module Barrel Index Files

## Product Vision

**Goal**: Enforce explicit public contracts per feature module by adding barrel `index.ts` files — no file moves, no logic changes, zero production risk.

**Scope**:
- IN: barrel `index.ts` files for tools module groups + domain services groups + scheduler group
- IN: update `registry.ts` to import from module barrels (or keep flat — Architect decides)
- OUT: no file moves, no folder restructuring (Phase 3), no logic changes

**Success metric**: Each module group has a typed `index.ts` that re-exports its public API; `bun tsc --noEmit` clean; all tests green.
