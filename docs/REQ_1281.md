## User Story

As a Vietnamese agricultural investor using Claude,
I want automated alerts when rainfall or drought events occur in VN,
So that I can adjust positions in agritech/seafood stocks (VNR/BFC/QNT) before market reprices the supply/cost impact.

---

## Problem Statement

Agriculture is a climate-sensitive sector. Major rainfall or drought events in Vietnam directly impact:

- **Crop yields** → input costs for food producers (VNM), agritech suppliers (VNR, BFC)
- **Aquaculture** → shrimp/fish farm viability (QNT, ANV, ASM, AAM, AAM, MPC)
- **Export revenue** → USD/VND export margin swing (Level 2 country cascade)

Current system detects macro (USD/VND, commodity prices, trade wars) but misses **weather-specific microeconomic signals**. Agricultural stocks often move 3-5% on rainfall forecasts (planting season) or drought alerts (harvest season) before equity analysts update BCTC forecasts.

**Example trigger**: "Trung Bộ mưa lớn kiên kéo 5 ngày" (Central VN heavy rain 5 days) → BFC/VNR drop 2-3% due to equipment delays, QNT rises due to aquaculture relief.

## Functional Requirements

### FR-1: Weather Keyword Detection (Domain Service)

- **Description**: Detect Vietnamese weather keywords in news/RSS feeds
- **Input**: News article summary (string), source credibility [0, 1]
- **Output**: `AgricultureWeatherDetectionResult` with matched keywords, context, confidence
- **Business rule**: Credibility threshold ≥ 0.6 (weather events from reputable sources only)
- **Keywords to detect** (Vietnamese, case-insensitive, whole-word):
  - Rainfall/flooding: "mưa lớn", "mưa kiên kéo", "lũ lụt", "ngập lụt", "mưa gây lũ", "báo động 3", "báo động 2"
  - Drought: "hạn hán", "thiếu nước", "tác động hạn", "khô hạn", "cạn nước"
  - Storm: "bão", "gió mạnh", "gió bão", "thiệt hại bão"
  - Cold snap: "rét đậm", "rét hại", "gió lạnh Siberia"
- **Confidence formula**: min(1.0, sourceCredibility × matchedKeywordCount / 3.0) — rewards multi-keyword articles from credible sources
- **DDD layer**: domain/services/agricultureDetector.ts
- **Existing patterns**: Identical to MSCI detector (1279) + insider dump detector (1278)

### FR-2: Agricultural Stock Identification (Application Logic)

- **Description**: Identify which watchlist stocks are exposed to the detected weather event
- **Input**: Detected weather event (keyword group), geographic region (optional, defaults to VN-wide), watchlist
- **Output**: List of affected stock codes with exposure basis
- **Business rule**: Filter watchlist to agriculture-domain stocks only (VNR, BFC, QNT, ANV, MPC, etc.)
- **Logic**:
  - Rainfall events → positive for aquaculture (QNT, ANV, MPC), neutral/negative for land crops due to equipment delays
  - Drought events → negative for all agriculture (lower yields, higher input costs)
  - Storm events → negative for agriculture (structural damage, lost harvests)
  - Cold snap → negative for tropical crops, risk of animal loss
- **DDD layer**: application/cascadeExecutor.ts → new function `detectAgricultureCascadePeers()`

### FR-3: Cascade Rule Definition (Domain Data)

- **Description**: Define weather-triggered cascade rules in cascadeEngine
- **Input**: None (rule definitions)
- **Output**: `AGRICULTURE_WEATHER_RULES` array, exportable from cascadeEngine
- **Structure**: Each rule must have:
  - `key`: unique identifier (e.g., "rainfall_aquaculture_positive")
  - `keyword`: Vietnamese weather keyword (e.g., "mưa lớn")
  - `sector`: always "agriculture"
  - (Optional) `region`: if weather is region-specific (e.g., "Mekong Delta"), else null
  - (Optional) `impactType`: "rainfall", "drought", "storm", "cold_snap"
  - (Optional) `affectedStocks`: hardcoded list of tickers affected by this rule, OR computed via domain field
- **Count**: 8–12 rules covering all keyword groups (rainfall=3, drought=3, storm=2, cold=2)
- **DDD layer**: domain/services/cascadeEngine.ts:2200 (after MSCI_INCLUSION_RULES)

### FR-4: Alert Generation & Cascade Execution

- **Description**: Wire weather detection into existing cascade flow
- **Input**: News article with weather keywords, existing watchlist + alerting engine
- **Output**: HIGH severity alerts fired to agricultural stocks (optional MARKET channel dispatch via existing alertCommander)
- **Integration**:
  - Call `detectAgricultureWeatherKeywords()` in news pipeline
  - Call `detectAgricultureCascadePeers()` if keywords matched
  - Pass result to `buildCausalChain()` + existing alert infrastructure
  - Severity: **HIGH** (direct input cost/supply impact, not speculative)
  - Cooldown: Standard 30-min window (shared with other cascade alerts)
- **DDD layer**: Applied in intelligenceCycleJob or onNewsItem handlers (infrastructure/scheduler or interface/mcp/tools)

## Non-Functional Requirements

- **Performance**: Keyword detection <50ms per article (no regex compilation, pre-compiled patterns OK)
- **Data freshness**: VN weather RSS sources update 2–4× daily; alerts fire within 15min of news ingestion
- **Language**: Vietnamese keywords + English variant support (e.g., "heavy rain" as fallback, credibility reduced by 0.1)
- **Reliability**: No new external API calls (reuse existing RSS news pipeline)
- **Precision**: Target ≥80% true-positive rate (avoid false-positive flooding alerts from weather forecasts without confirmed impact)

---

## Edge Cases & Data Quality

- [ ] **Empty or short articles**: Reject if summary <20 chars or <3 words
- [ ] **Weather forecast vs. confirmed event**: "Dự báo mưa lớn" (forecast) vs. "Mưa lớn gây lũ" (confirmed) — reduce credibility for forecasts by 0.2 penalty
- [ ] **Region specificity**: If region specified (e.g., "Trung Bộ") but article mentions non-agricultural region (e.g., urban Ho Chi Minh City), reduce impact score
- [ ] **Multiple weather events in one article**: Confidence aggregated as (sum of matched keywords) / total possible keywords, capped at 1.0
- [ ] **Missing domain information**: If watchlist entry lacks `domain` field, default to skip (do not assume agriculture)
- [ ] **Duplicate alerts within 30min window**: Existing cooldown engine prevents re-firing same rule on same stock
- [ ] **Vietnamese diacritics**: Weather keywords may appear with/without diacritics (e.g., "mua lon" vs. "mưa lớn"). Detector must handle both via NFD normalization (existing pattern from sprint 1000+ archival)

**Then**

- Confidence >= 0.5 (0.8 × 1 / 3.0 = 0.26, but 2+ keywords fix to 0.53)
- Context extracted (30 chars before/after first keyword)

### AC-2: Drought Detection

**Given** news article text contains "hạn hán" or "thiếu nước"
**When** detectAgricultureWeatherKeywords(text, credibility=0.9) called
**Then**
- Matched keywords include drought term
- Confidence >= 0.6 (0.9 × 1 / 3.0 = 0.30, + multi-keyword boost if present)
- impactType="drought"


### Confidence Scoring

Follow MSCI formula:
- `confidence = min(1.0, sourceCredibility × matchedKeywordCount / 3.0)`
- 3.0 = max expected keywords per article (rewards articles with 3+ weather signals)
- sourceCredibility baseline: 0.6 (low threshold because weather is objective fact)

### Agricultural Stock Domain Mapping

Use existing `WatchlistEntry.domain === "agriculture"` field. Ensure watchlist JSON includes domain for all VNR/BFC/QNT/ANV/MPC/etc.

### Alert Severity Decision

Recommend **HIGH** because:
- Weather impacts supply/cost **immediately** (not speculative)
- Input costs swing 5–10% on rainfall/drought
- Parallel to existing MACRO alerts (USD/VND, commodity prices = HIGH)

If user disagrees (B4), adjust in alertCommander routing.

### Cascade Integration Point

- Existing `intelligenceCycleJob.ts` or news pipeline calls `buildCausalChain()` for every news seed
- Insert `detectAgricultureWeatherKeywords()` check before causal chain construction
- If matched and peers found → fire alert via existing alertCommander (no new infrastructure)
