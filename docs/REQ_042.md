---

## User Stories

### US-1: Cảnh báo khí hậu đầu tư
As a Vietnamese stock investor,
I want the system to monitor weather events (typhoons, droughts, El Niño, floods) and their impact on Vietnamese stocks,
So that I can position early: REE benefits from solar replacing hydro during drought; BVH faces claims during typhoons; MPC loses inventory during floods.

### US-2: Monitor điện lực
As a Vietnamese stock investor,
I want the system to track Vietnam power grid data (hydro reservoir levels, dispatch mix, FIT prices),
So that I can assess earnings drivers for energy stocks (REE, GEG, PC1) and risk to industrial zone stocks (IDC, KBC) from power shortages.

### US-3: Seasonal risk calendar
As a Vietnamese stock investor,
I want the system to proactively warn me of seasonal risk windows (typhoon season Sep-Nov, drought Dec-Apr, power shortage Jun-Aug),
So that I can adjust positions before seasonal patterns hit.

## Functional Requirements

### FR-1: Weather VN Fetcher (`src/infrastructure/fetchers/weatherVn.ts`)

- **Description**: Fetch Vietnam weather warnings and forecasts.
- **Primary source**: NCHMF (nchmf.gov.vn — Trung tâm Khí tượng Thủy văn Quốc gia).
- **Secondary source**: NOAA Pacific typhoon tracking (RSS/XML).
- **Data extracted**: Active warnings (bão, áp thấp nhiệt đới, lũ, hạn hán), severity level, affected regions, forecast timeline.
- **Output**: `WeatherEvent[] { type, severity, regions: string[], forecastDate, impactDuration, description }`
- **Weather types**: `typhoon` | `flood` | `drought` | `heat_wave` | `cold_snap` | `el_nino` | `la_nina`
- **Error handling**: Never throw. Circuit breaker.

### FR-2: Hydrological Data Fetcher (`src/infrastructure/fetchers/hydrologicalData.ts`)

- **Description**: Fetch reservoir levels for major hydropower plants.
- **Source**: EVN public data or news extraction (tin tức về mực nước hồ thủy điện).
- **Key reservoirs**: Hòa Bình, Sơn La, Lai Châu, Trị An, Ialy, Sông Hinh.
- **Output**: `ReservoirLevel[] { name, currentLevel, capacityPct, trend: 'rising'|'falling'|'stable', date }`
- **Auto-extraction fallback**: If no API, extract from news using pattern matching ("mực nước hồ X đạt Y%").

### FR-3: Climate Impact Mapper (`src/domain/services/climateImpactMapper.ts`)

- **Description**: Pure domain service. Map weather events to stock-level impacts.
- **Seasonal risk calendar**:
  ```typescript
  const SEASONAL_RISKS = {
    "06-08": { risk: "thiếu điện", stocks: ["IDC","KBC","GEG","REE"], direction: "mixed" },
    "09-11": { risk: "bão lũ", stocks: ["VNM","MPC","ANV","BVH","PVI"], direction: "bearish" },
    "12-04": { risk: "hạn hán/El Niño", stocks: ["REE","CHP","GEG"], direction: "mixed" },
    "01-03": { risk: "rét đậm miền Bắc", stocks: ["DCM","DPM"], direction: "bearish" },
  };
  ```
- **Impact mapping**:
  | Event | Stock | Direction | Reasoning |
  |---|---|---|---|
  | Drought/El Niño | REE | BULLISH | Solar/wind thay thế thủy điện bị thiếu |
  | Drought/El Niño | thủy điện nhỏ | BEARISH | Sản lượng giảm |
  | Typhoon Cat 3+ | BVH, PVI | BEARISH | Bồi thường bảo hiểm |
  | Typhoon | MPC, ANV | BEARISH | Tổn thất ao nuôi thủy sản |
  | Power shortage | IDC, KBC | BEARISH | FDI lo ngại, nhà máy cắt giảm |
  | Power shortage | GEG | BULLISH | Nhu cầu NLTT tăng |
- **Output**: `ClimateSignal { eventType, severity, affectedStocks, direction, seasonalContext, reasoning }`
- **Pure function**: No I/O.

### FR-4: Energy Market Analyzer (`src/domain/services/energyMarketAnalyzer.ts`)

- **Description**: Pure domain service. Analyze power grid data → impact on energy and industrial stocks.
- **Input**: `EnergyData { hydroCapacityPct, thermalDispatchPct, renewableDispatchPct, reservoirLevels, peakDemandGW }`
- **Key logic**:
  - Reservoir < 50% capacity → drought risk signal
  - Thermal dispatch > 60% → coal price sensitivity increases
  - Renewable dispatch rising → GEG, REE benefiting from policy
  - Peak demand > installed capacity × 0.9 → power shortage imminent
- **Output**: `EnergySignal { type, severity, affectedStocks, direction, reasoning }`
- **Pure function**: No I/O.

### FR-5: Cascade Engine Extension

- **Add `CLIMATE_RULES`** to `cascadeEngine.ts`:
  ```
  typhoon_vietnam → agriculture (bearish), insurance (bearish), construction (bullish rebuild)
  drought_vietnam → hydropower (bearish), solar (bullish), agriculture (bearish)
  power_shortage → industrial_zone (bearish), renewable (bullish)
  el_nino_onset → cross-sector seasonal cascade
  ```

### FR-6: Scheduler Integration

- **New cron job**: `weatherCheckJob` — every 6 hours during typhoon season (Jun-Nov), every 12 hours off-season.
- **Wire into morning briefing**: Add climate section with active warnings + seasonal context.

### FR-7: MCP Tools

- `get_climate_risk_signals(stock?: string)` → Active climate events + seasonal risk window
- `get_energy_grid_signals()` → Power grid status + reservoir levels + dispatch mix
