# REQ-1422: Morning Briefing — BCTC Upcoming Deadlines Section

status: READY_FOR_ARCHITECT
sprint: 151
po_vision: Show watchlist stocks with Q1 2026 deadlines within 14 days that have not yet filed in the morning briefing.

## User Story

As a Vietnamese stock investor using Claude,
I want the morning briefing to show which watchlist stocks have imminent or overdue BCTC filing deadlines,
So that I can act on information before the April 30 statutory deadline and avoid holding stocks that may surprise with late filings.

## Functional Requirements

### FR-1: BctcDeadlineRow type

- Description: New public type representing one row in the upcomingDeadlines section.
- Input: Output of `getCurrentDeadline()` + `classifyFilingStatus()` for one watchlist stock.
- Output: Typed row ready for JSON serialisation and Telegram formatting.
- Business rule:
  - `status` must be `"SAP_DEN"` or `"QUA_HAN"` — rows with `"DA_NOP"` or `"UOC_TINH"` are excluded.
  - `daysUntilDeadline` is negative for `QUA_HAN`, 0–14 for `SAP_DEN`.
- DDD layer: domain (pure type, no DB dependency)

Fields:
| Field | Type | Notes |
|---|---|---|
| `code` | `string` | Watchlist ticker |
| `domain` | `string` | Sector domain (e.g. "banking") — drives extended deadline |
| `quarter` | `1\|2\|3\|4` | Quarter number from `DeadlineInfo.quarter` |
| `year` | `number` | Fiscal year from `DeadlineInfo.year` |
| `deadline` | `string` | ISO date string (YYYY-MM-DD) of statutory deadline |
| `daysUntilDeadline` | `number` | Negative = overdue; 0–14 = imminent |
| `status` | `"SAP_DEN"\|"QUA_HAN"` | Filing status classification |

### FR-2: upcomingDeadlines field in DailyBriefing

- Description: New optional field added to the `DailyBriefing` interface.
- Input: Result of Step 18 (see FR-3).
- Output: `upcomingDeadlines?: BctcDeadlineRow[]`
- Business rule: Field is absent (`undefined`) only when the step throws. Empty array `[]` is valid and means all watchlist stocks have filed or have deadlines beyond 14 days.
- DDD layer: application (type lives in `assembleBriefing.ts`)

### FR-3: Step 18 in assembleBriefing.ts — populate upcomingDeadlines

- Description: Iterate over `watchlistRows`, call `getCurrentDeadline(today, row.domain)` + `classifyFilingStatus(today, {...deadlineInfo, filingDate})`, filter to `SAP_DEN | QUA_HAN`, sort by `daysUntilDeadline ASC` (most urgent first).
- Input:
  - `watchlistRows`: existing `WatchlistRow[]` already in scope (Step 5).
  - `today`: `new Date()` — injectable via `AssembleBriefingOptions.nowFn?: () => Date` for test determinism.
  - `filingDate`: look up `financial_reports` table — query `MAX(parsed_at)` where `action_code = code AND period_type = 'Q' AND period_year = year AND quarter = quarter`. If row exists → `filingDate = row.parsed_at`, else `null`.
- Output: `BctcDeadlineRow[]`, sorted ascending by `daysUntilDeadline`.
- Business rule:
  - Use `getCurrentDeadline(today, domain)` — returns the *current accountability quarter*, which on 2026-04-18 is Q1 2026 (deadline Apr 30 standard / May 14 banking).
  - Pass `domain` from `WatchlistRow.domain` to get correct extended deadline for banking/insurance stocks.
  - DB query for filing status: `SELECT MAX(parsed_at) AS filed_at FROM financial_reports WHERE action_code = ? AND period_type = 'Q' AND period_year = ? AND quarter = ?`. If no `quarter` column exists in DB, fall back to `period_type LIKE 'Q1%'` pattern matching — log a warning.
  - Wrap entire step in `try/catch`; on error log warn and set `upcomingDeadlines = []`.
- DDD layer: application (`assembleBriefing.ts`, Step 18 block)

### FR-4: nowFn injectable option in AssembleBriefingOptions

- Description: Add `nowFn?: () => Date` to `AssembleBriefingOptions` interface for test determinism.
- Input: Caller passes `nowFn: () => new Date("2026-04-18")`.
- Output: Step 18 uses `nowFn?.() ?? new Date()` for all date computations.
- Business rule: Production code never sets this — `new Date()` is the default. Tests always set it.
- DDD layer: application (interface only, no logic change elsewhere)

### FR-5: formatBriefingMessage — "BCTC sắp đến" section

- Description: Add a new section to `formatBriefingMessage` in `morningBriefingJob.ts` that renders `upcomingDeadlines`.
- Input: `briefing.upcomingDeadlines: BctcDeadlineRow[]`
- Output: Telegram plain-text lines appended after "TA Tín hiệu" section.
- Business rule:
  - Omit section entirely when `upcomingDeadlines` is undefined, null, or empty.
  - Section header: `"📅 BCTC sắp đến:"`
  - Per-row format: `"  {CODE}: Q{quarter}/{year} — hạn {deadline} ({N} ngày)"` for `SAP_DEN`; `"  {CODE}: Q{quarter}/{year} — QUÁ HẠN {|N|} ngày"` for `QUA_HAN`.
  - `{N}` = `Math.abs(daysUntilDeadline)` for overdue, `daysUntilDeadline` for imminent.
  - Rows sorted by urgency (already sorted by caller in FR-3).
- DDD layer: interface (`morningBriefingJob.ts`)

## Non-Functional Requirements

- Performance: Step 18 runs N synchronous DB queries (one per watchlist stock, max 30). All are parameterised prepared statements. Total time budget: < 50ms on local SQLite.
- Data freshness: `financial_reports` table populated by `bctcFetchJob` (VPS proxy). If table is empty (no filings yet this season), all stocks will show SAP_DEN or QUA_HAN — this is correct behaviour.
- Language: Vietnamese section header + labels; stock codes in uppercase.
- Telegram: Plain-text only (no Markdown). `parseMode: ""` already set in `runMorningBriefing`.

## Edge Cases & Data Quality

- [ ] `financial_reports` table missing `quarter` column — fallback to `period_type LIKE '%Q1%'` pattern; log warn once.
- [ ] Watchlist empty (`watchlistRows = []`) — `upcomingDeadlines = []`, section omitted.
- [ ] All watchlist stocks have `DA_NOP` status — `upcomingDeadlines = []`, section omitted.
- [ ] Banking/insurance stocks (VCB, CTG, MBB, BID, TCB, ACB, VPB) — `getCurrentDeadline` with `domain="banking"` returns May 14 deadline (45 days); these show `SAP_DEN` later than non-banking stocks.
- [ ] `QUA_HAN` stocks (deadline already passed) — shown in section with "QUÁ HẠN" label; included in count for `hasContent` guard.
- [ ] `nowFn` not injected in production — `new Date()` default; clock skew risk negligible (daily briefing).
- [ ] DB query throws (missing table or schema change) — caught in try/catch, `upcomingDeadlines = []`, briefing continues.
- [ ] Duplicate watchlist codes — `watchlistRows` already deduped by Step 5 upstream.

## Acceptance Criteria

### AC-1: SAP_DEN stocks appear in upcomingDeadlines

**Given** a watchlist with VNM (domain=consumer_goods) and today = 2026-04-18 (12 days before Apr 30) and VNM has no filing in financial_reports for Q1 2026
**When** `assembleBriefing` runs with `nowFn: () => new Date("2026-04-18")`
**Then**

- `briefing.upcomingDeadlines` contains one row for VNM
- `row.status === "SAP_DEN"`
- `row.daysUntilDeadline === 12`
- `row.deadline === "2026-04-30"`
- `row.quarter === 1` and `row.year === 2026`

### AC-2: QUA_HAN stocks appear in upcomingDeadlines

**Given** today = 2026-05-05 (5 days after Apr 30) and a non-banking watchlist stock has no Q1 2026 filing
**When** `assembleBriefing` runs with `nowFn: () => new Date("2026-05-05")`
**Then**

- Row appears with `status === "QUA_HAN"`
- `row.daysUntilDeadline === -5`

### AC-3: DA_NOP stocks excluded from upcomingDeadlines

**Given** a watchlist stock that has a Q1 2026 row in `financial_reports`
**When** `assembleBriefing` runs
**Then**

- That stock does NOT appear in `briefing.upcomingDeadlines`

### AC-4: formatBriefingMessage contains deadline section when upcomingDeadlines non-empty

**Given** a DailyBriefing with `upcomingDeadlines = [{ code: "VNM", status: "SAP_DEN", daysUntilDeadline: 12, deadline: "2026-04-30", quarter: 1, year: 2026, domain: "consumer_goods" }]`
**When** `formatBriefingMessage(briefing)` is called
**Then**

- Output contains `"BCTC sắp đến:"`
- Output contains `"VNM"`
- Output contains `"12 ngày"`
- Output contains `"2026-04-30"`

### AC-5: Section omitted when upcomingDeadlines is empty

**Given** a DailyBriefing with `upcomingDeadlines = []`
**When** `formatBriefingMessage(briefing)` is called
**Then**

- Output does NOT contain `"BCTC sắp đến:"`

### AC-6: Banking stocks get extended deadline (May 14)

**Given** watchlist stock VCB with `domain = "banking"` and today = 2026-04-18 and no Q1 2026 filing
**When** `assembleBriefing` runs
**Then**

- `row.deadline === "2026-05-14"` (45 days after Mar 31)
- `row.daysUntilDeadline === 26` (outside 14-day window)
- VCB does NOT appear in `upcomingDeadlines` (status = UOC_TINH, filtered out)
