## Architecture Decision

This sprint formalizes existing infrastructure:

1. **Ops Agent** (`.claude/agents/ops.md`) is production-ready Markdown documentation defining dev-cron observation + incident response workflow. No code changes in `src/` required — integration is deployment-level (scheduled in dev-cron loop after QA agent).

2. **OHLCV Guard Checks** (lines 103–112 in scheduler job) prevent partial OHLCV inserts via optional chaining (`?.price`, `?.high_p`) and explicit `undefined` checks. Test suite formalizes the behavior.

**Rationale:** DDD compliance achieved through test isolation (no domain logic extraction needed) + TDD discipline (RED tests first, then validation). No new abstraction layers required — guards are procedural defensive code.

## Test Design: 6 Test Cases (TC-1 to TC-6)

### Test File: `src/__tests__/1277-ohlcv-guard-checks.test.ts`

**Setup:**
- In-memory SQLite with `watchlist`, `market_prices_history`, `daily_ohlcv` tables
- Helper functions: `makeDb()`, `addTicker()`, `addTick()`
- Pinned time: 2026-04-17T09:00:00.000Z (VN window: 2026-04-16T17:00:00Z → 2026-04-17T09:00:00Z)

| TC | Scenario | Input | Expected | Guard Tested |
|----|----------|-------|----------|--------------|
| TC-1 | All OHLCV present (happy path) | 1 ticker, 3 ticks (open, high/low, close) | Insert to daily_ohlcv; rowsWritten=1, tickersSkipped=0 | None (baseline) |
| TC-2 | Open undefined (no early tick) | 1 ticker, 2 ticks (both after window start) | Skip ticker; rowsWritten=0, tickersSkipped=1 | `open === undefined` |
| TC-3 | Close undefined (no late tick) | 1 ticker, 2 ticks (both before window end) | Skip ticker; rowsWritten=0, tickersSkipped=1 | `close === undefined` |
| TC-4 | High undefined (empty window) | 1 ticker, 0 ticks in window | Skip ticker; rowsWritten=0, tickersSkipped=1 | `high === undefined` |
| TC-5 | Low undefined (empty window) | 1 ticker, 0 ticks in window | Skip ticker; rowsWritten=0, tickersSkipped=1 | `low === undefined` |
| TC-6 | Batch: 3 tickers, mixed completeness | 3 tickers: T1 complete, T2 missing open, T3 missing close | 1 insert (T1); rowsWritten=1, tickersSkipped=2 | All guards on mixed batch |

**Key assertions per test case:**
- Result object: `.tickersProcessed`, `.rowsWritten`, `.tickersSkipped`
- DB state: row count, OHLCV values match expected prices
- No NaN/null in output (guard check prevents coercion)
- No throw on missing components (guard check silently skips)
