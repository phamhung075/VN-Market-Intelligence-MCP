# REQ-135: fix(france-msg-quality) — Omit Empty Sections + Fix Vietnamese Diacritics in franceSummaryJob

status: READY_FOR_ARCHITECT
sprint: 135
po_vision: franceSummaryJob must not send "Khong co X" filler lines to MARKET when other sections have real data — omit empty sections entirely and use correct Unicode diacritics throughout.

## User Story

As a Vietnamese stock investor using Claude from France,
I want the morning digest to show only sections that contain real data,
So that I am not distracted by "Khong co du lieu gia." / "Khong co canh bao." spam lines when alerts or TA signals are present.

---

## Functional Requirements

### FR-1: Omit empty sections entirely in formatFranceSummaryVI

- Description: When a data array is empty (movers=[], alerts=[], taSignals=[]), omit the entire section — header line and body — from the formatted message. Do not emit any placeholder / fallback string.
- Input: `movers: MoverRow[]`, `alerts: AlertRow[]`, `taSignals: TaSignalRow[]` (same existing signature)
- Output: Message string containing only the header banner + non-empty sections, separated by single blank lines. No "Khong co X" lines anywhere.
- Business rule: At least one section must be non-empty for `runFranceSummary` to call `formatFranceSummaryVI` (the existing silent-skip guard in `runFranceSummary` already enforces this — no change to `runFranceSummary` logic required).
- Trailing blank line: No blank line should appear after the last section.
- DDD layer: interface/scheduler (`src/scheduler/franceSummaryJob.ts`)

### FR-2: Fix Vietnamese diacritics throughout formatFranceSummaryVI

- Description: Replace all unaccented ASCII Vietnamese strings with correct Unicode diacritics in every label, header, and fallback string inside `formatFranceSummaryVI` and its helper functions (`severityLabel`, `rsiLabel`, `ma20Label`, section headers).
- Input: existing string literals in the formatter
- Output: proper Unicode diacritics on all user-visible strings
- Business rule: Exact mappings required (exhaustive list):

| Current ASCII | Correct Unicode |
|---|---|
| `Ban tin sang Phap` | `Bản tin sáng Pháp` |
| `Thi truong VN` | `Thị trường VN` |
| `Top bien dong gia` | `Top biến động giá` |
| `dong` (currency suffix) | `đồng` |
| `Canh bao gan nhat` | `Cảnh báo gần nhất` |
| `Tin hieu ky thuat` | `Tín hiệu kỹ thuật` |
| `NGHIEM TRONG` | `NGHIÊM TRỌNG` |
| `CAO` | `CAO` (no change) |
| `CANH BAO` | `CẢNH BÁO` |
| `THONG TIN` | `THÔNG TIN` |
| `qua mua` | `quá mua` |
| `qua ban` | `quá bán` |
| `gia tren MA20` | `giá trên MA20` |
| `gia duoi MA20` | `giá dưới MA20` |

- DDD layer: interface/scheduler (`src/scheduler/franceSummaryJob.ts`)

## Acceptance Criteria

### AC-1: No empty-section filler lines in MARKET messages

**Given** `formatFranceSummaryVI` is called with movers=0, alerts=2, taSignals=0
**When** the function returns the formatted string
**Then**

- String contains the alerts section header `Cảnh báo gần nhất`
- String does NOT contain any `Khong co` substring
- String does NOT contain a blank header for the movers section
- String does NOT contain a blank header for the TA section

### AC-2: Correct Unicode diacritics in all labels

**Given** `formatFranceSummaryVI` is called with at least one non-empty section
**When** the function returns the formatted string
**Then**

- Header contains `Bản tin sáng Pháp — Thị trường VN`
- Movers header (when present) contains `Top biến động giá`
- Currency suffix reads `đồng` not `dong`
- Alerts header (when present) contains `Cảnh báo gần nhất`
- TA header (when present) contains `Tín hiệu kỹ thuật`
- `rsiLabel("overbought")` returns `quá mua`
- `rsiLabel("oversold")` returns `quá bán`
- `ma20Label("above")` returns `giá trên MA20`
- `ma20Label("below")` returns `giá dưới MA20`
- `severityLabel("critical")` returns `NGHIÊM TRỌNG`
- `severityLabel("warning")` returns `CẢNH BÁO`
