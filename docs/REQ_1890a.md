## Risk Flags

1. **BCTC banking cohort TODAY (ACB/BID/CTG/EIB/MBB/VCB/VPB):** T4 (`get_cash_flow`) is the highest-risk gap. Without G-step, FA cannot perform OCF vs NI forensic check on Q1/2026 earnings filings arriving today. Prioritize Subtask A.

2. **`get_insider_signals` caller contract mismatch:** The tool requires `outstandingShares` as mandatory param. The FA package doc previously listed it without params (`— `). Any FA cycle calling this tool without `outstandingShares` will receive empty signals (fallback `transactions = []`). Subtask B doc update MUST include correct params.

3. **`bctc_full` partial overlap with `get_cash_flow`:** `get_bctc_full` already returns `operatingCF` and `freeCashFlow`. If FA already calls `get_bctc_full` in Layer 7, the new `get_cash_flow` tool should be positioned as a *dedicated forensic tool* (full CF statement + OCF/NI ratio) that the flow calls **after** `get_bctc_full`, not as a replacement. Flow doc (`flows/financial-analyst/cycle.md`) does not need a code change — the agent reads the tool package and exercises judgment. Note this in package doc.

4. **SKILL_MANIFEST SSOT:** `agentBootstrap.ts` line 27 comment: "Update both files together whenever a tool is added or a skill changes." The mirrored file is `docs/SKILL_MANIFEST.md`. Subtask B must update both.
