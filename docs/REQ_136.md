# REQ-136: fix(evening-news-filler) — omit "Không có tin tức hôm nay" when newsCount=0

status: READY_FOR_ARCHITECT
sprint: 136
po_vision: Evening MARKET message must not emit filler noise when real content (alerts, movers, TA) is present.

## User Story

As a Vietnamese stock investor using Claude,
I want the evening summary Telegram message to stay clean when no news was ingested,
So that I am not distracted by a "no news" filler line when alerts and price movers are already in the message.

## Functional Requirements

### FR-1: Drop the "Không có tin tức hôm nay" else-branch

- Description: When `newsCount === 0`, the newsCount block must emit nothing — no blank line, no filler text.
- Input: `summary.newsCount` value from `assembleEveningSummary` result; value is `0` or falsy.
- Output: The `lines` array does not contain `"Không có tin tức hôm nay"` and the preceding `lines.push("")` blank line is also omitted.
- Business rule: Only observable diagnostic output is shown. Absence of news is not a user-facing event when other sections (alerts, movers, TA) carry content. Same rule applied in Sprint 135 for `franceSummaryJob`.
- DDD layer: interface (scheduler)

### FR-2: Retain "(N tin tức hôm nay)" when newsCount > 0

- Description: The existing positive-count branch is preserved exactly. No change to wording, formatting, or position in the message.
- Input: `summary.newsCount > 0`
- Output: `lines` contains `"(N tin tức hôm nay)"` with the preceding blank line separator.
- Business rule: Diagnostic visibility when news is present is still valuable — do not remove it.
- DDD layer: interface (scheduler)

## Non-Functional Requirements

- Performance: zero — single conditional removal, no new queries.
- Data freshness: n/a.
- Language: Vietnamese filler string removed; remaining label "(N tin tức hôm nay)" unchanged.

## Edge Cases & Data Quality

- [x] newsCount === 0, all other sections empty → message still sends (existing silent-skip guard unchanged); no filler line.
- [x] newsCount === 0, alerts=2, movers=3 → message sends with those sections only; no filler line.
- [x] newsCount === undefined → `?? 0` coalescion already present at line 157; treated as 0; no filler line.
- [x] newsCount === 1 → "(1 tin tức hôm nay)" emitted normally.

## Root Cause (confirmed)

File: `src/scheduler/eveningSummaryJob.ts`

```
// Lines 156-163 (current, broken)
const newsCount = summary.newsCount ?? 0;
lines.push("");                           // blank line always pushed
if (newsCount > 0) {
  lines.push(`(${newsCount} tin tức hôm nay)`);
} else {
  lines.push("Không có tin tức hôm nay"); // <-- filler: remove this branch
}
```

Fix (target state):
```
const newsCount = summary.newsCount ?? 0;
if (newsCount > 0) {
  lines.push("");
  lines.push(`(${newsCount} tin tức hôm nay)`);
}
// else: emit nothing
```

The blank-line separator is moved inside the `if` block so it is also suppressed when newsCount=0.
