status: DRAFT
sprint: 148
po_vision: All user-visible Vietnamese text reaches the user with correct diacritics.

## User Story

As a Vietnamese stock investor using Claude,
I want tool responses to display correct Vietnamese text (with full diacritics),
So that output is legible and professional, not transliterated Latin.

## Scope Rules (MUST be respected by Dev)

| IN SCOPE | OUT OF SCOPE |
|---|---|
| `content[].text` return strings | `.describe()` Zod schema strings |
| `lines.push(...)` building output blocks | DB enum keys (`DA_NOP`, `QUA_HAN`, etc.) |
| `return { content: [{ text: ... }] }` literals | Internal log messages (`logger.*`, `console.*`) |
| Formatting helper return values that reach `content[].text` | Internal guard strings (never user-facing) |
