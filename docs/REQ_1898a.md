## Problem

`get_market_snapshot` was observed returning non-stock content on two consecutive audit cycles: electricity grid data (TNB c45) and portfolio data (TNB c46). Both occurrences cleared on container restart, which points to a stale deployed build running handler code that no longer matches the current source. The current codebase at `apps/mcp-server/src/interface/mcp/tools/market-data/marketTools.ts` contains the correct HOSE/HNX/UPCOM fetch logic. The deployment artifact (compiled `.js` output inside the Docker container) was built from an older snapshot where the tool's handler body was different, causing the wrong response content to be served until the container was rebuilt. The fix requires: (1) a verified clean build guard to detect handler-content drift between source and deployed artifact, and (2) a response-shape assertion test for `get_market_snapshot` so any future regression is caught before deploy reaches the running container.

## Spec

Three targeted changes, all within `apps/mcp-server/`:

**1. Response-shape guard in existing test (`084-tool-market.test.ts`)**

Add one assertion to the existing `get_market_snapshot` test that explicitly verifies the response text:
- contains `"VN-Index:"` (market index header)
- does NOT contain `"ĐIỆN LỰC"` or `"TRẠNG THÁI ĐIỆN"` (electricity content markers)
- does NOT contain `"positions"` or `"portfolio"` (portfolio content markers)
- contains at least one pattern matching a stock line: ticker code + price in VND

**2. Build artifact drift check — add `tsc --noEmit` to the pre-deploy CI gate**

The existing `bunx tsc --noEmit` must be confirmed passing before any container image build. This is already the convention; the spec requires it to be verified clean for this task.

**3. `get_macro_snapshot` response-shape guard (in scope because same stale-build root)**

Add equivalent shape assertions to the `get_macro_snapshot` test: response must contain `"=== Macro Snapshot ==="`, `"[Commodity Prices]"`, `"[SBV Central Bank Rates]"`, and must NOT contain electricity or portfolio content.
