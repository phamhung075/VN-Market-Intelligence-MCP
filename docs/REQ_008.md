# REQ-008: Sprint 008 — Macro Intelligence Layer: Commodity Prices, SBV Rates, Cascade Integration

status: READY_FOR_ARCHITECT
sprint: 008
po_vision: Wire commodity prices and central bank rates into the causal cascade, completing the macro intelligence layer so that oil, gold, USD/VND, and SBV rates actively adjust confidence scores in every runImpactChain call.

---

## Sprint Overview and Business Value

Sprint 006 closed the news-signal and company-report signal layers. Sprint 008 closes the
**global macro layer** — the topmost tier of the causal cascade:

```
[Global commodity prices]  ←── task 025
[SBV central bank rates]   ←── task 028
         ↓
  cascadeEngine.ts          ←── task 126 (macro adjustment step)
         ↓
 get_macro_snapshot tool    ←── task 089
         ↓
  Stock watchlist impacts
```

Without this sprint, a news item like "Brent oil jumps to $110" produces the same confidence score
whether Brent is actually at $65 or $115. After this sprint the cascade engine reads live macro
data and adjusts sector confidence scores accordingly — making every `runImpactChain` call
numerically grounded in real market conditions.

**FIX-081** addresses pre-existing test flakiness (SSE timeout) that would otherwise mask failures
in the test suite as Sprint 008 tasks are merged.

---

## User Story

As a Vietnamese stock investor using Claude,
I want the cascade engine to incorporate live commodity prices and SBV interest rates when
estimating the impact of macro events on my watchlist,
So that confidence scores reflect current market conditions (oil at $110 vs $65 produces
meaningfully different alerts for GAS, PVD, HVN, VCB, VHM).

### FR-025: Yahoo Finance Commodity Fetcher (`src/infrastructure/fetchers/yahooFinance.ts`)

#### FR-025-1: Fetch Brent Crude Oil Price

- **Description:** Retrieve the current Brent crude front-month futures price in USD per barrel.
  Brent crude is the international benchmark that directly prices Vietnamese oil-sector stocks
  (GAS, PVD, PVS, OIL) and influences industrial energy costs.
- **Source URL:** `https://finance.yahoo.com/quote/BZ=F`
  - Env override: `Bun.env["YAHOO_FINANCE_BASE_URL"]` replaces the base domain. Tests must set
    this to a local fixture server so no real HTTP calls are made.
- **Scraping strategy:** Yahoo Finance embeds live prices in a `<fin-streamer>` element.
  Parse `value` attribute of the element with `data-symbol="BZ=F"` and
  `data-field="regularMarketPrice"`. Fall back to element text content if the `value` attribute is
  absent. Strip any commas used as thousands separators before calling `parseFloat`.
- **Output field:** `brentCrudeUSD: number` — USD per barrel (e.g. `84.37`).
- **Failure behaviour:** If the HTTP request fails or the element is not found, this field is set
  to `null` in the returned snapshot; the function does NOT throw.
- **DDD layer:** infrastructure/fetchers

#### FR-025-2: Fetch Gold Spot Price

- **Description:** Retrieve the current gold front-month futures price in USD per troy ounce.
  Gold is a safe-haven indicator that signals broad investor risk appetite.
- **Source URL:** `https://finance.yahoo.com/quote/GC=F`
- **Scraping strategy:** Same `<fin-streamer>` pattern, `data-symbol="GC=F"`,
  `data-field="regularMarketPrice"`.
- **Output field:** `goldUSDPerOz: number` — USD per troy ounce (e.g. `2341.50`).
- **Failure behaviour:** null on failure; no throw.
- **DDD layer:** infrastructure/fetchers

#### FR-025-3: Fetch USD/VND Exchange Rate

- **Description:** Retrieve the current USD/VND exchange rate. This is the primary currency
  signal for import/export businesses, aviation (lease costs), and banking FX exposure.
- **Source URL:** `https://finance.yahoo.com/quote/USDVND=X`
- **Scraping strategy:** Same `<fin-streamer>` pattern, `data-symbol="USDVND=X"`,
  `data-field="regularMarketPrice"`.
- **Output field:** `usdVndRate: number` — VND per 1 USD (e.g. `25450.0`).
- **Failure behaviour:** null on failure; no throw.
- **DDD layer:** infrastructure/fetchers

#### FR-025-4: CommoditySnapshot Interface and Return Contract

- **Description:** `fetchYahooFinancePrices()` returns a `CommoditySnapshot` — never throws.
  Individual fields are `null` when a specific instrument cannot be fetched (partial success is
  valid). The whole function returns `null` only on a catastrophic error where no fetch could
  even be attempted (e.g. import failure of the HTTP client).
- **Interface definition:**

```typescript
export interface CommoditySnapshot {
  /** Brent crude front-month futures price in USD per barrel. null if fetch failed. */
  brentCrudeUSD: number | null;
  /** Gold front-month futures price in USD per troy ounce. null if fetch failed. */
  goldUSDPerOz: number | null;
  /** USD/VND exchange rate: VND per 1 USD. null if fetch failed. */
  usdVndRate: number | null;
  /** ISO 8601 timestamp when the snapshot was attempted. */
  fetchedAt: string;
}
```

- **Function signature:**

```typescript
export async function fetchYahooFinancePrices(
  httpClient?: HttpClient,
): Promise<CommoditySnapshot | null>
```

- **DDD layer:** infrastructure/fetchers

#### FR-025-5: Injectable HttpClient

- **Description:** Accepts an optional `HttpClient` parameter (same interface used by
  `tradingEconomics.ts`, `ssc.ts`, `hose.ts`). When absent, defaults to axios with a 15-second
  timeout and a browser-like User-Agent header. Tests pass a mock client returning fixture HTML
  so no real network calls occur.
- **Env var:** `YAHOO_FINANCE_BASE_URL` — overrides the base domain for all three URLs.
- **DDD layer:** infrastructure/fetchers

### FR-028: SBV Macro Fetcher (`src/infrastructure/fetchers/sbv.ts`)

#### FR-028-1: Fetch Overnight Rate

- **Description:** Retrieve the SBV (State Bank of Vietnam) overnight interbank lending rate as
  a percentage. This is the most liquid short-term rate signal that banks reference for overnight
  repo transactions.
- **Source URL:** `https://www.sbv.gov.vn/webcenter/portal/en/home/rm/ir` (SBV interest rates page)
  - Env override: `Bun.env["SBV_BASE_URL"]` replaces the base domain.
- **Scraping strategy:** Parse HTML tables on the SBV interest rates page. Locate a row whose
  label text (case-insensitive) matches any of: `["overnight", "qua đêm", "lãi suất qua đêm"]`.
  Extract the numeric value from the adjacent cell. Strip `%` suffix. Use `parseFloat`.
  Wrap the entire parse in try/catch — return null on any error.
- **Output field:** `overnightRatePct: number | null` — percentage (e.g. `5.0` = 5.0%).
- **DDD layer:** infrastructure/fetchers

#### FR-028-2: Fetch Refinancing Rate

- **Description:** Retrieve the SBV refinancing rate. This is the key policy rate that
  determines the cost of liquidity for commercial banks and is the primary lever for VN monetary
  policy. High refinancing rate → tightens bank margins, weighs on real-estate demand.
- **Source URL:** Same SBV page.
- **Scraping strategy:** Row labels to match: `["refinancing rate", "lãi suất tái cấp vốn",
  "tái cấp vốn"]`.
- **Output field:** `refinancingRatePct: number | null` — percentage (e.g. `4.5` = 4.5%).
- **DDD layer:** infrastructure/fetchers

#### FR-028-3: Fetch Official USD/VND FX Rate

- **Description:** Retrieve the SBV's official central exchange rate for USD/VND. This differs
  from the Yahoo Finance market rate (FR-025-3) — the SBV rate is the regulatory reference used
  in official transactions. Knowing both rates allows computing the band spread.
- **Source URL:** `https://www.sbv.gov.vn/webcenter/portal/en/home/fm/exchangerate`
  - Env override: same `Bun.env["SBV_BASE_URL"]`.
- **Scraping strategy:** Parse the exchange rate table. Locate the USD row. Extract the "Selling"
  or "Transfer" rate column (the forward-purchase rate). Sanitise thousands dots and parse.
  Labels to match: `["usd", "dollar", "đô la mỹ"]`.
- **Output field:** `usdVndOfficial: number | null` — VND per 1 USD (e.g. `25452.0`).
- **DDD layer:** infrastructure/fetchers

#### FR-028-4: SbvMacroSnapshot Interface and Return Contract

- **Description:** `fetchSbvRates()` returns an `SbvMacroSnapshot` — never throws. Individual
  fields are `null` when a specific field cannot be scraped. The function returns `null` only on
  catastrophic failure.
- **Interface definition:**

```typescript
export interface SbvMacroSnapshot {
  /** SBV overnight interbank lending rate in percent. null if unavailable. */
  overnightRatePct: number | null;
  /** SBV refinancing (policy) rate in percent. null if unavailable. */
  refinancingRatePct: number | null;
  /** SBV official USD/VND reference rate: VND per 1 USD. null if unavailable. */
  usdVndOfficial: number | null;
  /** ISO 8601 timestamp when the snapshot was attempted. */
  fetchedAt: string;
}
```

- **Function signature:**

```typescript
export async function fetchSbvRates(
  httpClient?: HttpClient,
): Promise<SbvMacroSnapshot | null>
```

- **DDD layer:** infrastructure/fetchers

#### FR-028-5: Resilient Multi-Page Fetch

- **Description:** The SBV website has two relevant pages (interest rates + FX rates). Both are
  fetched independently. If the interest rate page fails, `overnightRatePct` and
  `refinancingRatePct` are null but `usdVndOfficial` may still succeed from the FX page, and
  vice versa. The function aggregates partial results and always returns an `SbvMacroSnapshot`
  object with a valid `fetchedAt`.
- **DDD layer:** infrastructure/fetchers

### FR-FIX-081: SSE Test Timeout Fix

#### FR-FIX-081-1: Resolve Intermittent SSE Timeout

- **Description:** `src/__tests__/081-bun-mcp-server.test.ts` intermittently times out when the
  SSE transport has not completed its startup handshake before assertions run. The fix must be
  minimal — no production code changes unless root cause analysis shows the timeout originates
  in `transport.ts` or `server.ts` rather than in test setup.
- **Root cause analysis:** The `GET /sse` test at line 45–68 aborts the request after 300ms and
  checks headers on the `res` object. Under CI load or cold-start conditions, the SSE stream
  header may not be flushed within 300ms if the `mcpServer.connect(transport)` call in
  `SseSessionManager.handleSse` is slow (registers 16+ tools). The `res` variable remains
  `undefined` when the abort fires before headers arrive, so the assertion block is skipped but
  the test may still hang on the `beforeAll` promise or surrounding timers.
- **Fix strategy:** Increase the abort timeout from 300ms to 2000ms for the SSE header check.
  Add an explicit `test.timeout` annotation of 10000ms on the SSE test case. Ensure `afterAll`
  forcibly calls `serverInstance.close()` even when a test throws. No change to production
  `transport.ts` or `server.ts`.
- **Acceptance:** `bun test src/__tests__/081-*.test.ts` passes 10 consecutive runs without a
  timeout failure.
- **DDD layer:** interface/test

### FR-126: Macro Cascade Integration

#### FR-126-1: MacroContext Type (Domain)

- **Description:** Define a new plain TypeScript interface `MacroContext` inside
  `cascadeEngine.ts`. This is a pure domain type — no imports from infrastructure.
  It carries the pre-fetched macro values into the pure cascade function so the function remains
  synchronous and side-effect-free.
- **Interface definition:**

```typescript
export interface MacroContext {

  brentCrudeUSD: number | null;
  /** Gold price in USD per troy ounce. null = unknown. */
  goldUSDPerOz: number | null;
  /** Market USD/VND rate from Yahoo Finance. null = unknown. */
  usdVndMarket: number | null;
  /** SBV refinancing policy rate in percent. null = unknown. */
  refinancingRatePct: number | null;
  /** SBV overnight rate in percent. null = unknown. */
  overnightRatePct: number | null;
  /** SBV official USD/VND rate. null = unknown. */
  usdVndOfficial: number | null;
}
```

- **DDD layer:** domain/services (inside cascadeEngine.ts)

#### FR-126-2: Confidence Adjustment Rules (Domain)

- **Description:** Define a hardcoded lookup table `MACRO_ADJUSTMENTS` in `cascadeEngine.ts`.
  Each entry specifies a condition on `MacroContext` and a delta to apply to the `confidence`
  field of matched domain-level `CausalChainEntry` objects. The table is applied after
  SECTOR_RULES produce the initial domain entries (Step 2 of `buildCausalChain`).
- **Adjustment rules table:**

| Condition | Affected domains | Confidence delta | Reasoning |
|-----------|-----------------|-----------------|-----------|
| `brentCrudeUSD > 90` | `oil_gas`, `logistics` | `+0.10` | High Brent price directly boosts margin for upstream producers and toll-road fuel levies |
| `brentCrudeUSD > 90` | `aviation` | `−0.08` | High Brent raises aviation fuel costs, compressing airline margins |
| `brentCrudeUSD < 70` | `oil_gas` | `−0.10` | Low Brent shrinks upstream revenue |
| `brentCrudeUSD < 70` | `aviation` | `+0.06` | Low fuel cost is a direct tailwind for airlines |
| `goldUSDPerOz > 2000` | `gold_mining` | `+0.05` | Higher gold price improves mining margins |
| `refinancingRatePct > 6` | `banking` | `−0.08` | Tight monetary policy compresses NIM over time |
| `refinancingRatePct > 6` | `real_estate` | `−0.10` | Higher borrowing cost reduces real-estate demand |
| `refinancingRatePct < 4` | `banking` | `+0.06` | Loose policy supports loan growth |
| `refinancingRatePct < 4` | `real_estate` | `+0.08` | Lower mortgage rates stimulate housing demand |
| `usdVndMarket > 25500` (or `usdVndOfficial > 25500`) | `aviation` | `−0.07` | Weak VND inflates USD-denominated lease and fuel costs |
| `usdVndMarket > 25500` | `steel` | `+0.05` | VND depreciation raises VND-equivalent export revenue |

- **Clamping:** After adjustment, confidence is clamped to `[0.05, 0.99]`. A single stock entry
  may receive multiple adjustments if it belongs to a domain that matches more than one rule;
  all applicable deltas are summed before clamping.
- **Null handling:** If a `MacroContext` field is `null`, all rules referencing that field are
  silently skipped (treated as "no data available"). The chain continues without that adjustment.
- **DDD layer:** domain/services (inside cascadeEngine.ts)

#### FR-126-4: runImpactChain MacroContext Injection (Application Layer)

- **Description:** Extend `RunCascadeInput` in `runImpactChain.ts` with two optional injectable
  fetcher callbacks. These callbacks are called once at the start of the chain run (not per stock)
  and their results are cached for the duration of the single `runImpactChain` call. The results
  are assembled into a `MacroContext` and passed to `buildCausalChain`. On fetcher failure, the
  corresponding fields in `MacroContext` are null and a warning is logged.

```typescript
export interface RunCascadeInput {
  newsText: string;
  seedEntry?: AnalysisEntry;
  watchlist: WatchlistEntry[];
  ragRetriever?: RagRetriever;
  /** Optional commodity data fetcher (defaults to fetchYahooFinancePrices). */
  commodityFetcher?: () => Promise<CommoditySnapshot | null>;
  /** Optional SBV rate fetcher (defaults to fetchSbvRates). */
  sbvFetcher?: () => Promise<SbvMacroSnapshot | null>;
}
```

- **Caching rule:** Both fetchers are called exactly once per `runImpactChain` invocation.
  Results are stored in local variables; there is no cross-call or module-level cache. This keeps
  the function idempotent while avoiding redundant HTTP calls within a single chain run.
- **Default fetchers:** When `commodityFetcher` is absent, dynamically import and call
  `fetchYahooFinancePrices` from `infrastructure/fetchers/yahooFinance.ts`. When `sbvFetcher`
  is absent, dynamically import and call `fetchSbvRates` from `infrastructure/fetchers/sbv.ts`.
  Dynamic imports (same pattern as the existing `defaultRagRetriever`) prevent circular
  dependency and allow test overrides without infrastructure imports at the application layer.
- **DDD layer:** application/usecases

#### FR-126-5: Reasoning Annotation

- **Description:** When macro adjustments are applied to a `CausalChainEntry`, append a brief
  annotation to the `reasoning` field of the affected entry:
  `" [Macro: brentCrudeUSD=84.3 → +0.10 confidence for oil_gas]"`. This makes the adjustment
  visible in the output returned to Claude and in the MCP tool response.

## Non-Functional Requirements

### NFR-1: Performance

- `fetchYahooFinancePrices()` and `fetchSbvRates()` must each complete within 15 seconds on
  a live call. Use `axios` timeout of `15_000` ms for all HTTP requests (same pattern as
  `tradingEconomics.ts`).
- `runImpactChain` overhead from macro fetching must not exceed 20 seconds in total (both
  fetchers called in parallel via `Promise.all`).

### NFR-2: Data Freshness

- These are snapshot fetchers, not streaming. Freshness is determined by when `runImpactChain`
  or `get_macro_snapshot` is called. No module-level caching. Scheduler jobs for periodic refresh
  are deferred to Sprint 009.

### NFR-3: Never-Throw Contract

- All four public functions (`fetchYahooFinancePrices`, `fetchSbvRates`, and both default
  fetchers used inside `runImpactChain`) must never throw to their caller. Errors are caught,
  logged at `warn` level with `logger.warn(...)`, and result in `null` return values.

### NFR-4: Test Coverage

- Every new file requires a `src/__tests__/NNN-*.test.ts` test file.
- Tests must pass with mocked HTTP — no real network calls allowed in `bun test`.
- Minimum assertions per file: happy path + HTTP failure path + partial success (one instrument
  fails, others succeed).
- `bun tsc --noEmit` must report 0 errors after all tasks merged.

### NFR-5: Language

- Log messages: English (same convention as all existing infrastructure files).
- MCP tool output (`get_macro_snapshot`): English with Vietnamese label context where directly
  useful (e.g. "SBV" abbreviation, "Brent Crude" understood by VN investors).

## Cascade Weighting Strategy

### Design Decision: Hardcoded vs Configurable Thresholds

**Decision: Hardcoded in Sprint 008. Configurable in Sprint 009+.**

Rationale: The thresholds ($90 Brent, $2000 gold, 6% rate, 25500 USD/VND) are economically
grounded Vietnamese market rules of thumb that change slowly (once or twice per year when the
macro regime shifts). Making them user-configurable adds schema, migration, and UI complexity that
is not justified until at least 3 months of production usage. The hardcoded table in
`MACRO_ADJUSTMENTS` inside `cascadeEngine.ts` can be refactored to a JSON config in Sprint 009
if the PO requests it.

### Weighting Rationale by Sector

| Sector | Primary macro driver | Why |
|--------|---------------------|-----|
| `oil_gas` | Brent crude USD | GAS, PVD, PVS revenue directly linked to oil price |
| `aviation` | Brent crude USD, USD/VND | Jet fuel ~30% of HVN/VJC OPEX; aircraft leases in USD |
| `gold_mining` | Gold USD/oz | OGC revenue directly follows gold price |
| `banking` | SBV refinancing rate | NIM (net interest margin) inversely correlates with rate tightening |
| `real_estate` | SBV refinancing rate | Mortgage demand inversely correlates with rate level |
| `steel` | USD/VND | HPG, HSG export pricing benefits from VND weakness |
| `logistics` | Brent crude USD | Transport fuel costs drive margin compression/expansion |

### Interaction with SECTOR_RULES

The macro adjustment step runs **after** `SECTOR_RULES` produces domain-level entries (Step 2).
It modifies the `confidence` field only — it does not change `sentiment`, `impactScore`, or
`direction`. This preserves the existing SECTOR_RULES semantics while layering quantitative
macro context on top of qualitative keyword matching.

## Caching Strategy

### Scope: per-call (within a single runImpactChain invocation)

Both fetchers (`commodityFetcher` and `sbvFetcher`) are called exactly once at the start of each
`runImpactChain` call via a single `Promise.all`. Their results are stored in local `const`
variables and passed into `buildCausalChain`. There is no module-level or process-level cache.

**Reason:** `runImpactChain` is called once per alert event (not in a tight loop). Cross-call
caching would add TTL complexity and staleness risk with no measurable performance benefit.
A scheduler-level cache (refresh every 15 minutes) is deferred to Sprint 009.

### SQLite persistence (deferred)

Storing `CommoditySnapshot` and `SbvMacroSnapshot` in SQLite tables (similar to
`macro_indicators`) is deferred to Sprint 009. Sprint 008 fetches live on demand only.

## Edge Cases and Data Quality

- [ ] Yahoo Finance HTML structure changes — `<fin-streamer>` element may be renamed or replaced
  with a JavaScript-rendered data fetch. If `<fin-streamer>` is not found, try `<span>` with
  `data-symbol` attribute as a secondary selector. Log a structured warning with the actual HTML
  snippet (first 500 chars) to assist debugging.
- [ ] Thousands separators in Yahoo Finance values — `"2,341.50"` must have commas stripped
  before `parseFloat`. VND values may appear as `"25,450.00"`.
- [ ] SBV website bilingual content — the English SBV pages are used (FR-028 uses the `/en/`
  URL path). Label matching must be case-insensitive. If English content is unavailable, attempt
  the Vietnamese label alternatives listed in FR-028-1 and FR-028-2.
- [ ] SBV website rate table layout — SBV sometimes presents rates as a multi-column table
  with "Effective From" dates per row. The parser should pick the row with the most recent date
  when multiple matching rows exist, not necessarily the first.
- [ ] `usdVndOfficial` value scale — the SBV table may show `25,452` (no decimal) or
  `25,452.00`. Both are valid VND/USD rates. Sanity-check: if the parsed value is less than 1000,
  it is almost certainly a parse error (the VND/USD rate has been above 20000 since 2010).
  Log a warning and return null in this case.
- [ ] `brentCrudeUSD` sanity check — valid range is approximately 20–250 USD/bbl. Values outside
  this range should log a warning but still be returned (do not silently null them — callers can
  decide). The same applies to gold (100–5000 USD/oz).
- [ ] MacroContext partial null — if `refinancingRatePct` is null (SBV fetch failed), rules that
  depend on it (`banking`, `real_estate` adjustments) are silently skipped. The cascade still
  runs with whatever data is available. This is the "graceful degradation" path and must be
  tested explicitly.
- [ ] Confidence clamping boundary — after summing all applicable macro deltas, a stock entry
  could theoretically receive `+0.10 + 0.05 = +0.15` if it matches two rules. Clamping to
  `[0.05, 0.99]` prevents invalid confidence values. Test this boundary explicitly.
- [ ] `bun:test` SSE abort race condition (FIX-081) — the `AbortController` fires at 300ms but
  `mcpServer.connect(transport)` (which registers 16 tools and initialises the MCP protocol)
  may not flush response headers before that deadline under cold-start. Increasing the abort
  timeout to 2000ms provides sufficient headroom while keeping the test fast.
- [ ] DomainType `logistics` and `gold_mining` — check whether these values exist in the
  `DomainType` union defined in `bctc-schema.ts`. If not, they must be added before the
  `MACRO_ADJUSTMENTS` table can reference them.
