## Sprint 1280 — URGENT FIX: BCTC Queue Timeout Blocker

| Task | Status | Commits |
|------|--------|---------|
| 1280 | FIX: `/api/bctc-fetch-queue` skip-enrichment flag | Done | 2d72d69 |

**Problem:** VPS BCTC fetch job times out when processing >50 BCTC PDFs because enrichment lookup (SSC credibility) is synchronous and blocks queue response. Returns 504 after 60s.

**Solution:**

**Impact:** VPS no longer times out on large BCTC batches. Queue API now fast (async-ready).

**Files Changed:**

## Data Freshness Monitoring (Sprint 1282 Addition)

### Flow
```
1. periodicalHealthCheck() queries data source ages (vps_push_log, financial_reports, etc.)
2. detectDataFreshnessBreach() calls domain SLA checker
3. classifySeverity() marks as HIGH/CRITICAL based on source importance
4. formatFreshnessAlert() formats for Telegram (Vietnamese + emoji)
5. Future: Gate cascade firing — skip alerts if data_freshness_status == CRITICAL_BREACH
```

### SLA Thresholds (per signal type)
- **price:** 15min (in market hours), 4h (off-hours)
- **bctc:** 6h (changes infrequently)
- **news:** 30min (rapid stream)
- **sbv_fx:** 2h (daily fix)
- **foreign_flow:** 2h (daily aggregate)
