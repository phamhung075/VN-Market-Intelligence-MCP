## Sprint 1280 — URGENT FIX: BCTC Queue Timeout Blocker

| Task | Status | Commits |
|------|--------|---------|
| 1280 | FIX: `/api/bctc-fetch-queue` skip-enrichment flag | Done | 2d72d69 |

**Problem:** VPS BCTC fetch job times out when processing >50 BCTC PDFs because enrichment lookup (SSC credibility) is synchronous and blocks queue response. Returns 504 after 60s.

**Solution:**
- Add `skip_enrichment=true` query parameter to `/api/bctc-fetch-queue` endpoint
- When set: return raw queue items without SSC credibility lookups
- Allows VPS to fetch raw PDF list in <1s, enrichment deferred to background job (future sprint 1287)

**Impact:** VPS no longer times out on large BCTC batches. Queue API now fast (async-ready).

**Files Changed:**
- `src/interface/api/bctcQueueHandler.ts` (+~10 lines, skip_enrichment flag)

**Tests:** Covered by existing BCTC integration tests (no new test file, <10 line fix)

5. Credibility threshold: 0.6 (weather data objective, lower bar than MSCI)
6. Forecast penalty: -0.2 for unconfirmed predictions

**Impact:** Weather alerts now cascade to agricultural stocks. Drying/flooding events trigger commodity hedges.
