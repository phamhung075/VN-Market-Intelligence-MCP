## Summary

The Deep Thinking Tree was a proposed recursive multi-agent reasoning architecture intended to solve:
1. Alert storms on correlated macro events
2. Shallow conviction math (simple averaging)
3. Stale RAG context
4. Cross-stock causal reasoning

## PO Decision: PARKED

After brainstorm analysis, all four problems above are more efficiently solved by targeted fixes:

| Problem | Solution | Where |
|---------|----------|-------|
| Alert storms | Causal root tagging (`causal_root_id`) | REQ_056 Fix A |
| Shallow conviction | Signal class weighting (`signal_class`) | REQ_056 Fix B |
| Stale RAG context | Recency weight in `search_similar_context` | REQ_056 Fix C |
| Cross-stock causal reasoning | Evidence accumulation + base rates | REQ_057 Phase A+B |

## Why Not the Tree

- 48x token cost increase per analysis cycle (tree = sequential Claude API calls per node)
- 800–1200 lines of new coordination code
- Sequential coordination latency: each node waits for its children before resolving
- Markets have feedback loops and network effects, not tree structures. A tree is the wrong data structure for prediction — it forces artificial parent-child reasoning where the actual causal structure is a graph (or flat with shared roots)

## Revisit Condition

If — after REQ_056 and REQ_057 Phase A+B are shipped and running in production for at least 30 days — cross-stock causal reasoning is still observably failing (e.g., correlated stocks producing contradictory conviction scores despite shared macro drivers), then revisit.

At that point, the preferred alternative is a **lightweight causal graph**: a flat node store keyed by `causal_root_id`, where each node holds a list of affected stocks and their direction/magnitude. No recursive tree. No agent-per-node. A single graph query at alert time.

This is faster to implement, cheaper to run, and fits the actual data structure of macro causality in VN markets.
