## Functional Requirements

### FR-1: MSCI Keyword Detection Domain Service

**Description:** Pure domain service that detects Vietnamese MSCI inclusion keywords in news text and returns detection result with confidence scoring.

**Input:**
- `seedSummary: string` — News article text (may contain Vietnamese diacritics)
- `sourceCredibility: number` — Credibility score [0, 1] (e.g., 0.95 for Reuters, 0.65 for local news)

**Output:**
```typescript
interface MsciDetectionResult {
  matched: boolean;                    // True if keywords detected + cred >= 0.7
  keywords: string[];                  // Matched keywords (lowercase)
  context: string;                     // Excerpt of text around matched keywords
  confidence: number;                  // (cred × matchedCount / 3.0) capped at 1.0
}
```

**Business Rules:**
- **Credibility threshold:** 0.7 (rejects low-confidence sources like local blogs, rumors)
  - Reuters/Bloomberg/SSC: 0.88+ → **PASS**
  - VnExpress/CafeF: 0.72–0.85 → **borderline, depends on source**
  - Local news/social media: <0.65 → **FAIL**
- **Keywords (whole-word, case-insensitive):**
  1. "nộp danh sách" (submit/list for inclusion)
  2. "đáp ứng tiêu chí" (meet inclusion criteria)
  3. "chỉ số msci" (MSCI index)
- **Confidence formula:** `min(1.0, sourceCredibility × matchedKeywordCount / 3.0)`
  - Rewards multi-keyword articles (stronger signal)
  - Rewards high-credibility sources
  - Capped at 1.0 (prevents over-confidence)
  - Examples:
    - 1 keyword, cred=0.75 → 0.25
    - 2 keywords, cred=0.90 → 0.60
    - 3 keywords, cred=1.0 → 1.0
- **Whole-word matching:** Multi-word keywords (e.g., "nộp danh sách") must not be substrings
  - Reject: "tờ nộp danh sách ngoài" (contains phrase but embedded)
  - Accept: "nộp danh sách cho MSCI" (phrase at word boundary)
- **DDD Layer:** domain/services (pure logic, no I/O, no side effects)

**File:** `src/domain/services/msciDetector.ts` (NEW, ~155 lines)

### FR-3: Large-Cap Cascade Executor Function

**Description:** Application-layer orchestration that calls domain detector, filters watchlist to large-cap stocks only, and returns targets with reasoning.

**Input:**
- `seedSummary: string` — News article text
- `sourceCredibility: number` — Credibility score [0, 1]
- `watchlist: WatchlistEntry[]` — Full watchlist with domain/sector info
- `largeCapListOverride?: string[]` — Optional override list (for testing)

**Output:**
```typescript
interface MsciCascadeResult {
  matched: boolean;                    // True if MSCI detected + cred >= 0.7
  detectedKeywords: string[];          // List of matched keywords
  targetStocks: string[];              // Large-cap watchlist stocks only
  reasoning: string;                   // Human-readable explanation
  confidence: number;                  // Confidence score from detector
}
```

**Business Rules:**
- **Large-cap definition (fallback):** `["MWG", "KDH", "FPT", "MSN", "VCB", "HPG", "BID", "CTG"]`
  - These are tier-1 large-cap stocks by market cap + liquidity
  - Excludes mid-cap (e.g., VNM/Vinamilk is ~$2B, not tier-1 like VCB/$8B+)
  - Default when `stock-classification.json` unavailable
- **Filtering logic:**
  1. Call `detectMsciInclusion()` domain service
  2. If `matched=false`, return empty `targetStocks` + credibility rejection reason
  3. If `matched=true`:
     - Use `largeCapListOverride` if provided (for testing flexibility)
     - Else use fallback list
     - Filter watchlist to stocks in large-cap list only
     - Return result with confidence + reasoning
- **Reasoning annotation:** Human-readable (e.g., "MSCI inclusion detected: nộp danh sách, đáp ứng tiêu chí. Targets large-cap watchlist stocks: VCB, FPT, MWG")
- **Contrast with insider dump:** Insider dump cascades to sector peers (banking contagion); MSCI cascades to cross-sector large-caps (index-level impact)
- **DDD Layer:** application/usecases (orchestration, pure function)

**File:** `src/application/cascadeExecutor.ts` (MODIFIED, +1 function + 2 interfaces)

## Implementation Notes

### Large-Cap Stock Definition Rationale

The fallback list `["MWG", "KDH", "FPT", "MSN", "VCB", "HPG", "BID", "CTG"]` represents tier-1 Vietnamese large-caps by:
- **Market cap:** VCB ($8B+), MWG ($5B+), FPT ($4B+), KDH ($3B+)
- **Liquidity:** Daily volume >1M shares at reasonable spreads
- **Index inclusion:** All 8 are in VN30 (top 30 by market cap)

**Explicitly excluded** from large-cap for MSCI cascade:
- **VNM (Vinamilk):** ~$2B market cap (mid-cap tier), dairy/agriculture focus, not tier-1
- **FRT (Phan Rui):** ~$1B (mid-cap), retail sector
- **PNJ (PNJ):** ~$1.5B (mid-cap), jewelry

This prevents alert spam for mid-cap inclusion announcements (which are less impactful).

### Word Boundary Matching for Vietnamese

The detector uses a custom `isWordBoundary()` helper (inline, not regex `\b`) because Vietnamese diacritical marks are not recognized by standard regex word boundaries.

Pattern:
```
/[a-z0-9àáảãạăằắẳẵặâầấẩẫậèéẻẽẹêềếểễệìíỉĩịòóỏõọôồốổỗộơờớởỡợùúủũụưừứửữựỳýỷỹỵđ]/i
```

This ensures "nộp danh sách" is matched as a phrase at word boundaries, not as a substring.

### Confidence Formula Justification

**Formula:** `min(1.0, sourceCredibility × matchedKeywordCount / 3.0)`

**Rationale:**
- **Baseline:** Single keyword + perfect source (cred=1.0) → 0.33 confidence (preliminary signal)
- **Multi-keyword boost:** 2 keywords → 0.67, 3 keywords → 1.0 (strong confirmation)
- **Source credibility scaling:** Lower credibility (0.7) reduces confidence proportionally
- **Capping at 1.0:** Prevents false certainty; multiple keywords don't guarantee impact

**Examples:**
- Reuters (0.95) + "nộp danh sách" alone → 0.32 (preliminary)
- Reuters (0.95) + "nộp danh sách" + "đáp ứng tiêu chí" → 0.63 (solid)
- Reuters (0.95) + all 3 keywords → 0.95 (near-certain)
