export interface BctcDeadlineRow {
  code: string;
  domain: string;
  quarter: 1 | 2 | 3 | 4;
  year: number;

  /** Negative = overdue; 0–14 = imminent */

}

### Step 18 DB query (confirmed column name: `period_quarter`)

```sql
SELECT MAX(parsed_at) AS filed_at
FROM financial_reports
WHERE action_code = ?
  AND period_type LIKE 'Q%'
  AND period_year = ?
  AND period_quarter = ?
```

Fallback when `period_quarter` column missing:

```sql
SELECT MAX(parsed_at) AS filed_at
FROM financial_reports
WHERE action_code = ?
  AND period_type = ?
  AND period_year = ?
```

Where `period_type` = `Q1|Q2|Q3|Q4` (from `buildPeriod` in `bctc-schema.ts`).

## Step 18 Implementation Spec

Location: after Step 17 TA signals block, before Step 13 (persist). Insert as:

```
// ── Step 18: BCTC upcoming deadlines ──────────────────────────────────────
```

Logic:

1. `const today = (options.nowFn ?? (() => new Date()))();`
2. Detect `period_quarter` column once: `PRAGMA table_info(financial_reports)` → check name list.
3. For each `row` in `watchlistRows`:
   a. `const info = getCurrentDeadline(today, row.domain)` — from `earningsCalendar.ts`
   b. Query `financial_reports` for `MAX(parsed_at)` using confirmed column shape.
   c. `const fs = classifyFilingStatus(today, { ...info, filingDate: filed_at ?? null })`
   d. If `fs.status === "SAP_DEN" || fs.status === "QUA_HAN"`: push `BctcDeadlineRow`.
4. Sort ascending by `daysUntilDeadline` (most urgent first — QUA_HAN negatives come before SAP_DEN positives).
5. Wrap entire step in `try/catch`; on error `logger.warn` + `upcomingDeadlines = []`.

### formatBriefingMessage section (morningBriefingJob.ts)

Append after the TA Tín hiệu block (line ~172), before `return lines.join("\n")`:

```typescript
// ── BCTC sắp đến ─────────────────────────────────────────────────────────────
if (briefing.upcomingDeadlines && briefing.upcomingDeadlines.length > 0) {
  lines.push("");
  lines.push("📅 BCTC sắp đến:");
  for (const row of briefing.upcomingDeadlines) {
    if (row.status === "QUA_HAN") {
      lines.push(`  ${row.code}: Q${row.quarter}/${row.year} — QUÁ HẠN ${Math.abs(row.daysUntilDeadline)} ngày`);
    } else {
      lines.push(`  ${row.code}: Q${row.quarter}/${row.year} — hạn ${row.deadline} (${row.daysUntilDeadline} ngày)`);
    }
  }
}
```

## DB Schema Note

`financial_reports.period_quarter` is `INTEGER` (nullable). Column confirmed at `bctc-schema.ts:734`. The query guard in Step 18 must check existence via `PRAGMA table_info(financial_reports)` before using it, per REQ edge-case. Use `period_quarter` as the primary path; fall back to `period_type = 'Q1'|'Q2'|'Q3'|'Q4'` matching only when the column is absent.

## AC-6 Clarification (VCB / banking)

`getCurrentDeadline(2026-04-18, "banking")` returns Q1 2026 deadline = **2026-05-14** (45 days). `daysUntilDeadline = 26` → `classifyFilingStatus` returns `UOC_TINH` (> 14 days). `UOC_TINH` is excluded from `upcomingDeadlines`. VCB does NOT appear — correct. Test must assert `upcomingDeadlines` does not contain `VCB` for this date.
