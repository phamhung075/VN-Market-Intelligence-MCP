## Architecture Decision

The system currently lacks macro-sentiment signals from international institutions. IMF releases (growth forecasts, currency warnings, debt sustainability reports) drive VN market reactions, but the signal chain doesn't capture this context.

**Design principle**: Reuse existing patterns, follow DDD layering strictly.

**Key decisions**:

1. **Domain layer** (`imfDataClassifier`) — Pure classification logic, no I/O, no dependencies on infrastructure
2. **Application layer** (`imfDataFetcher`) — Fetching from public IMF API (no VPS needed; unlike SSC portal, IMF API is publicly accessible)
3. **Signal integration** — IMF sentiment enriches ChainCatalyst signals via optional `imfSentiment` field (not mandatory, allows gradual rollout)
4. **Cascade rules** — 8–12 IMF-driven rules added to cascadeEngine (IMF growth ↑ → banking sector ↑, etc.)
5. **Scheduler** — 6h refresh cycle (aligned with macro_indicators job, per REQ-1296)

**Why this design**:
- Preserves DDD layering (domain never imports application or infrastructure)
- Reuses tested patterns (sentiment classifier, cascade executor, signal builders)
- Non-blocking enrichment (signals work without IMF data)
- Circuit breaker + rate limiting on all external calls (production safety)

```typescript
export interface ImfIndicator {
  /** Unique IMF indicator code (e.g., "BOP_FIN_FCLA_GD_ZS") */
  code: string;

  /** Human-readable name (e.g., "Net financial account") */
  name: string;

  /** Latest published value */
  value: number;

  /** Publication date (ISO 8601) */
  publishedAt: string;

  /** Days since publication */
  ageInDays: number;

  /** Previous value (for YoY change calculation) */
  previousValue: number | null;

  /** Percent change YoY (calculated) */
  yoyChange: number | null;

  /** Source: "imf_api" | "imf_world_outlook" | "imf_bulletin" */
  source: "imf_api" | "imf_world_outlook" | "imf_bulletin";

  /** Confidence in indicator freshness (0.0–1.0) */
  confidence: number;
}

export const IMF_INDICATORS = {
  // Growth forecasts

  ASEAN_GROWTH: "NGDP_RPCH_ASEAN",

  // Trade & FX

export type ImfIndicatorKey = keyof typeof IMF_INDICATORS;

export interface ImfSentimentInput {

}

export interface ImfSentimentOutput {
  sentiment: number; // [-1, +1]
```

### 6. Scheduler Job (Interface Scheduler)

```typescript
// src/scheduler/market-data/imfIndicatorPollerJob.ts

export async function runImfIndicatorPollerJob(): Promise<{ success: boolean; indicator_count: number }> {
  try {
    const indicators = await fetchLatestImfIndicators();
    await storeImfIndicators(indicators);

    // Classify and store latest sentiment
    const sentiment = classifyImfIndicators(indicators, baseline);
    await storeImfSentiment(sentiment);

    return { success: true, indicator_count: indicators.length };
  } catch (err) {
    logger.error(`[IMF Poller] Failed: ${err.message}`);
    return { success: false, indicator_count: 0 };
  }
}

// Cron registration: 0 */6 * * * (every 6 hours)
```
