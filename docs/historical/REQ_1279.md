# REQ-1279: MSCI Index Inclusion Cascade Detection

**Status:** READY_FOR_ARCHITECT
**Sprint:** 1279
**Size:** M (medium scope)
**PO Vision:** Detect MSCI inclusion announcements and cascade HIGH-severity alerts to large-cap beneficiaries

---

## Problem Statement

Vietnamese large-cap stocks benefit materially from index inclusions, especially MSCI (Morgan Stanley Capital International) indexes. When news announces Vietnam's MSCI status change or a specific stock joining MSCI (common eligibility keywords: "nộp danh sách", "đáp ứng tiêu chí", "chỉ số MSCI"), this triggers:

1. Passive fund inflows (ETFs tracking MSCI)
2. Foreign ownership rebalancing
3. Multi-quarter positive sentiment cascade

**Current state:** No systematic detection of MSCI inclusion signals. Relies on manual market scanning.

**User impact:** Real market event, proven price catalyst. Automated detection creates edge for watchlist large-caps (MWG, KDH, FPT, MSN) that benefit most from inclusion eligibility announcements.

---

## Scope

### Detection Scope

**Keywords (Vietnamese + English)**
- Vietnamese: "nộp danh sách", "đáp ứng tiêu chí", "chỉ số MSCI", "msci inclusion"
- English: "msci", "morgan stanley capital", "index inclusion", "criteria", "eligible"

**Target Stocks (large-cap beneficiaries)**
- MWG (Masan Group) — retail, strong foreign appeal
- KDH (Khương Dương) — retail/distribution
- FPT (FPT Corp) — tech, major MSCI constituent
- MSN (Masangroup) — real estate, large-cap
- VCB (Vietcombank) — banking, primary MSCI constituent
- HPG (Hoa Phát) — steel, mid/large-cap

**Cascade Rule Structure**
- Signal type: **index inclusion announcement** (MSCI_INCLUSION)
- Trigger: Keyword match + news source credibility (Reuters/Bloomberg/SSC > local news)
- Severity: **HIGH** (proven price catalyst, multi-quarter impact)
- Affected domain: **tech, retail, real_estate, banking** (large-caps cross sectors)
- Cascade target: Large-cap stocks in watchlist; peer stocks in same sector NOT cascaded (unlike insider dump)

**Alert Firing Criteria**
- Source credibility > 0.7 (Reuters/Bloomberg/SSC official)
- Keyword match + context check (not generic market commentary)
- Stock mentioned by name OR stock implied by "Vietnam eligibility" language
- Sentiment: bullish (index inclusion = positive signal)

## Functional Requirements

### FR-1: MSCI Inclusion Keyword Detection

**Description:** Detect Vietnamese news articles containing MSCI inclusion keywords and verify context relevance.

**Input:**
- `seedSummary` (string): News article summary text
- `sourceCredibility` (number 0–1): News source rating (Reuters=0.95, local=0.6)

**Output:**
- `MsciDetectionResult` (interface)
  - `matched` (boolean): True if keywords found and credibility >0.7
  - `keywords` (string[]): Matched keywords
  - `context` (string): Article context (full summary)
  - `confidence` (number 0–1): Detection confidence

**Business rule:**
- Keyword match required (case-insensitive)
- Credibility threshold enforces quality: only Reuters/Bloomberg/SSC/VNA news, not social media
- Returns false negatives on low-credibility sources (acceptable—avoids noise)

**DDD layer:** `domain` → `src/domain/services/msciDetector.ts`

---

### FR-2: Large-Cap Stock Identification

**Description:** Identify which large-cap stocks in watchlist are eligible for MSCI inclusion cascade.

**Input:**
- `newsStocks` (string[]): Stock codes mentioned in article
- `watchlist` (WatchlistEntry[]): Current watchlist
- `largeCapThreshold` (number): Market cap floor (default: 2 billion USD)

**Output:**
- `eligibleStocks` (string[]): Watchlist stocks eligible for cascade

**Business rule:**
- Definition: Large-cap = market cap >$2B VND (Vietcombank, FPT, MWG, HPG, VCB, KDH, MSN)
- Do NOT cascade to sector peers (unlike insider dump); only mentioned/eligible stocks
- Check `stock-classification.json` for sector classification
- Fallback: If market cap data unavailable, use hardcoded large-cap set (MWG, KDH, FPT, MSN, VCB, HPG)

**DDD layer:** `domain` → `src/domain/services/cascadeEngine.ts` (extend existing functions)

### FR-3: MSCI_INCLUSION_RULES Rule Definition

**Description:** Define 3 cascade rules for MSCI inclusion keywords; support both Vietnamese and English sources.

**Input:** None (static rule array)

**Output:**
- `MSCI_INCLUSION_RULES` (CascadeKeywordRule[]): Array of 3 rules
  ```typescript
  export const MSCI_INCLUSION_RULES: CascadeKeywordRule[] = [
    { key: "msci_large_cap_1", keyword: "nộp danh sách", sector: "all_largecp" },
    { key: "msci_large_cap_2", keyword: "đáp ứng tiêu chí", sector: "all_largecp" },
    { key: "msci_large_cap_3", keyword: "chỉ số msci", sector: "all_largecp" },
  ];
  ```

**Business rule:**
- `sector: "all_largecp"` is a pseudo-domain (not in DomainType enum); application layer filters by actual stock classification
- Keyword matching: case-insensitive, whole-word only (not substring)
- Keywords apply globally; news source determines true/false positive (high credibility required)

**DDD layer:** `domain` → `src/domain/services/cascadeEngine.ts:2180`

### FR-4: Cascade Detection Helper Function

**Description:** Orchestrate MSCI inclusion detection: check keywords + verify credibility + identify large-cap targets.

**Input:**
- `seedSummary` (string): News article summary
- `sourceCredibility` (number): Source rating (0–1)
- `watchlist` (WatchlistEntry[]): Current watchlist

**Output:**
- `MsciCascadeResult` (interface)
  ```typescript
  interface MsciCascadeResult {
    matched: boolean;
    detectedKeywords: string[];
    targetStocks: string[];  // Large-cap watchlist stocks eligible for alert
    reasoning: string;
    confidence: number;
  }
  ```

**Business rule:**
- Return empty array if credibility <0.7 (reject low-quality sources)
- Return only large-cap stocks from watchlist (not ALL stocks)
- Confidence = (sourceCredibility * keywordCount / 3.0) capped at 1.0
- Reasoning: human-readable explanation (e.g., "Reuters announces MSCI eligibility criteria; targets MWG, FPT")

**DDD layer:** `application` → `src/application/cascadeExecutor.ts`

**Business rule:**

- Severity = HIGH (index inclusion is proven catalyst)

**DDD layer:** `domain` → `src/domain/services/cascadeEngine.ts::buildCausalChain()`

## Non-Functional Requirements

**Performance**
- Keyword detection: <5ms per article (string comparison only)

**Data freshness**
- Stock classification: refreshed daily (via stock-classification.json)
- Source credibility: hardcoded mapping in `credibilityMap.ts` (Reuters=0.95, Bloomberg=0.90, SSC=0.88, VNA=0.85, CafeF=0.65, local=0.50)

**Language**
- English (code comments) + Vietnamese (keywords, examples in tests)
- Output Telegram alerts in Vietnamese (Cowork responsibility)

**Cascade scope**
- Do NOT cascade to sector peers (unlike insider dump cascade)
- Only include large-cap stocks in watchlist
- Credibility threshold prevents false positives from social media

## Edge Cases & Data Quality

- [ ] **Empty/null summary:** Return `matched=false`, no error
- [ ] **Mixed language:** Keywords in Vietnamese; news source credibility determines relevance
- [ ] **Partial match:** Require whole-word keyword match (not substring)
- [ ] **Generic market commentary:** e.g., "Vietnam may join MSCI soon" without official announcement → reject if source <0.8
- [ ] **Multiple stocks in article:** Filter to large-cap only; ignore mid-cap/small-cap mentions
- [ ] **Credibility edge case:** Source unknown/unmapped → default to 0.6 (reject)
- [ ] **Sector mismatch:** Stock mentioned in article but not in watchlist → skip (no alert)
- [ ] **Old news (>7 days):** Timestamp check in scheduler layer; cascade engine ignores age

## Implementation Notes

### Design Rationale

1. **Domain vs Application split**
   - Domain: Static rules (MSCI_INCLUSION_RULES), pure detection (keyword matching, large-cap filtering)
   - Application: Orchestration (cascadeExecutor helper), composition with sentiment classifier

2. **Credibility threshold (0.7)**
   - Reuters/Bloomberg (0.95/0.90): Always pass
   - SSC/VNA official (0.88/0.85): Always pass
   - CafeF/local news (0.65/0.50): Always reject
   - Prevents noise from unvetted sources; MSCI inclusion is material → require proof

3. **Large-cap static set (fallback)**
   - If `stock-classification.json` unavailable, hardcode: MWG, KDH, FPT, MSN, VCB, HPG, BID, CTG
   - Rationale: MSCI inclusion primarily benefits mega-cap and tier-1 large-caps

4. **No sector peer cascade (unlike insider dump)**
   - Insider dump (Task 1278): CEO exits banking stock → cascade to peer banks (contagion risk)
   - MSCI inclusion (Task 1279): Stock joins MSCI → target that stock + large-cap peers in OTHER sectors (cross-sector liquidity play)
   - Example: MWG joins MSCI → alert MWG, FPT, VCB (other large-caps), NOT VNM (retail peer)

5. **Sentiment direction**
   - Insider dump → bearish (negative)
   - MSCI inclusion → bullish (positive)
   - Cascade engine detects direction from keywords; MSCI keywords = bullish
