status: APPROVED
sprint: 044
po_vision: Tầng phân tích chuyên biệt cho sector dược VN (DHG, IMP, DBD). Theo dõi phê duyệt thuốc DAV, đấu thầu thuốc bệnh viện, outbreak dịch bệnh, FDI dược phẩm. Niche sector nhưng alpha cao khi có trong watchlist.

---

## User Stories

### US-1: Phê duyệt thuốc DAV
As a Vietnamese stock investor holding pharma stocks,
I want the system to monitor drug approvals from Cục Quản lý Dược (DAV),
So that I receive alerts when new drug registrations benefit DHG, IMP, or DBD.

### US-2: Đấu thầu thuốc bệnh viện
As a Vietnamese stock investor,
I want the system to track hospital drug procurement tenders,
So that I know which pharma companies are winning large hospital supply contracts.

### US-3: Outbreak detection
As a Vietnamese stock investor,
I want the system to detect disease outbreak signals from Vietnamese news,
So that I can position in vaccine distributors (IMP) and pharmaceutical manufacturers (DHG, DBD).

## Functional Requirements

### FR-1: DAV Pharmacy Fetcher (`src/infrastructure/fetchers/davPharmacy.ts`)

- **Description**: Scrape `dav.gov.vn` (Cục Quản lý Dược) for new drug registrations, price approvals, and regulatory changes.
- **Data extracted**: Drug name, manufacturer, registration number, approval date, category (generic/branded/biosimilar).
- **Output**: `DrugApproval[] { drugName, manufacturer, registrationNumber, approvalDate, category, relatedStocks: string[] }`
- **Manufacturer-to-stock mapping**:
  | Manufacturer | Stock |
  |---|---|
  | Dược Hậu Giang | DHG |
  | Imexpharm | IMP |
  | Dược Bình Định | DBD |
  | Pymepharco | PME |
  | Traphaco | TRA |
- **Error handling**: Never throw. Circuit breaker.

### FR-2: Pharma Event Mapper (`src/domain/services/pharmaEventMapper.ts`)

- **Description**: Pure domain service. Classify pharma events and map to stock impacts.
- **Event types**: `drug_approval` | `hospital_tender` | `outbreak` | `price_regulation` | `fdi_pharma`
- **Outbreak detection patterns**:
  ```
  dịch bệnh, outbreak, epidemic, pandemic,
  sốt xuất huyết (dengue), cúm A (influenza A), COVID,
  tay chân miệng (HFMD), dại (rabies), sởi (measles),
  tiêm chủng (vaccination), vaccine
  ```
- **Impact mapping**:
  | Event | Stock | Direction | Reasoning |
  |---|---|---|---|
  | Drug approval (generic) | DHG/IMP/DBD | BULLISH | Mở rộng portfolio thuốc |
  | Outbreak (dengue/flu) | IMP | BULLISH | Tăng nhu cầu vaccine nhập khẩu |
  | Outbreak (any) | DHG | BULLISH | Tăng nhu cầu thuốc điều trị |
  | Hospital tender won | Winner stock | BULLISH | Doanh thu đảm bảo |
  | Drug price cap decrease | All pharma | BEARISH | Biên lợi nhuận giảm |
  | Foreign pharma FDI | Target stock | BULLISH | M&A premium |
- **Output**: `PharmaSignal { eventType, severity, affectedStocks, direction, reasoning }`
- **Pure function**: No I/O.

### FR-3: Cascade Engine Extension

- **Add `PHARMA_RULES`** to `cascadeEngine.ts`:
  ```
  outbreak_vietnam → pharmaceutical (bullish), vaccine_distributor (bullish)
  drug_price_regulation → pharmaceutical (bearish)
  hospital_budget_increase → pharmaceutical (bullish), medical_equipment (bullish)
  ```
- **Add `DomainType: "pharmaceutical"`** to `bctc-schema.ts`.

### FR-4: Signal Integration

- **Extend `SignalType`**: Add `"pharma_event"` to union.
- **Wire DAV check**: Monthly cron job (drug approvals are not daily).
- **Wire outbreak detection into `pollNews.ts`**: Check for outbreak patterns alongside existing sentiment classification.

### FR-5: MCP Tools

- `get_pharma_signals(stock?: string, days?: number)` → Drug approvals, tenders, outbreaks

## Edge Cases

1. **Outbreak false alarm**: Single case report vs. actual outbreak → require 3+ mentions in 48h.
2. **Generic vs branded confusion**: Same drug approved for multiple manufacturers → map all affected stocks.
3. **DAV website structure changes**: Use Cheerio with loose selectors, fallback to keyword extraction from VnExpress/CafeF pharma news.
