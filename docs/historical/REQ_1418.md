# REQ-1418: fix(diacritics-wave6) — restore Vietnamese diacritics in 6 runtime output files

status: READY_FOR_ARCHITECT
sprint: 149
po_vision: All Vietnamese strings returned to users must carry correct Unicode diacritics.

## User Story

As a Vietnamese stock investor using Claude,
I want tool responses and error messages to display correct Vietnamese text with full diacritics,
So that output is legible and professional.

## Scope decision: in vs out

| File | Line(s) | String location | In scope |
|------|---------|-----------------|----------|
| customAlertTools.ts | 90, 94, 159 | `content[].text` / `lines[]` fed into content | YES |
| changelogTools.ts | 158, 195, 202, 218 | `content[].text` | YES |

## Non-Functional Requirements

- No logic change — string content only.
- TypeScript must compile clean after fix (`bun tsc --noEmit`).
- Tests must pass green after task 1419 fix.
- Language: Vietnamese with full Unicode diacritics (NFD/NFC both valid in source).

## Edge Cases & Data Quality

- [ ] `pad()` call in targetAllocationTools.ts uses string length for column width — diacritical characters add no extra bytes in JS `.length` (Unicode code points), so column alignment is unaffected.
- [ ] `SnapshotResult.error` sentinel `"(không thể ghi file)"` — any existing test that asserts on the old broken string `"(khong the ghi file)"` must also be updated in task 1419.
- [ ] Template-literal lines (interpolated `${...}`) — fix only the literal prefix/suffix, never the interpolated part.
