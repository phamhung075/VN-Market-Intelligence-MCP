# REQ-1294: Signal Payload Enrichment & BCTC Fallback Resilience

**Status:** APPROVED (blockers resolved 2026-04-23)
**Sprint:** 1294
**PO Vision:** Restore signal chain completeness (IMF sentiment context) and improve BCTC extraction resilience (PDF timeout fallback to news context).

---

## Executive Summary

Sprint 1293 hardened signal type interfaces (strict Zod validation), but revealed that **News Scout and Market Watcher agents are not populating numeric payload fields** required for 4-AND opportunity alerts. Additionally, **BCTC extraction timeouts have no fallback**, causing silent data loss when SSC portal is slow/unavailable.

This sprint adds two resilience improvements:

1. **Task 1294a:** News Scout IMF context detection — classify global macro events (policy vs crisis) to populate `newsSentiment` payload field for chain_catalyst signals.
2. **Task 1294b:** BCTC PDF timeout fallback — when OCR extraction fails, enrich BCTC fields from news chain signals instead of silent skip.

**Expected Outcome:** Signal chain completeness >95% (vs 40% current), BCTC extraction success rate improves from 82% → >90%.

---

## User Story

As a Vietnamese investor using Claude for market intelligence,
I want alerts to carry complete context (IMF policy vs crisis sentiment, BCTC data from alternative sources when PDFs timeout),
So that I can distinguish policy-driven dips from true credit crises, and make informed decisions even when data sources are partially unavailable.

## Functional Requirements

### FR-1: IMF Context Sentiment Detection (Task 1294a)

**Description:** Detect IMF-related news and classify sentiment as **policy_adjustment** (neutral/constructive) vs **crisis_signal** (threat to credit/currency). Populate `newsSentiment` field in chain_catalyst signals.

**Input:**
- News article headline + summary (from newsSourcePollerJob)
- Event classification from cascade engine (credit_policy, macro, crisis, legal)
- Macro indicators from SBV/Trading Economics stream

**Output:**
- `newsSentiment` numeric field in ChainCatalystFindingData:
  - `+0.7..+1.0`: Bullish policy (rate cut, credit expansion, FDI inflow signal)
  - `+0.3..+0.6`: Neutral/mixed macro news (GDP miss but EXP strength, inflation target miss but controlled)
  - `-0.3..+0.2`: Bearish policy (rate hike, credit tightening, FDI outflow risk)
  - `-0.6..-0.3`: Crisis-level sentiment (currency crisis risk, debt restructuring, geopolitical shock)

**Business Rule:**
- IMF oversight = policy_adjustment (+0.3..+0.7)
- IMF crisis program = crisis_signal (-0.6..-0.3)
- IMF staff report (no program) = neutral (0.0..+0.3) unless major escalation

**DDD Layer:** domain/services (sentimentClassifier.ts extension)

---

### FR-2: BCTC PDF Timeout Fallback (Task 1294b)

**Description:** When `fetchParseAndStoreBctc()` times out or returns extraction errors, populate financial_reports table with fallback BCTC fields from recent news chain signals (sector guidance, earnings momentum, balance sheet hints).

**Input:**
- PDF extraction failure (timeout >10s, OCR confidence <30%, parse error)
- Recent chain_catalyst signals for the same stock (last 7 days)
- News content with BCTC-like hints (e.g., "increased reserves by 15%", "NIM compression expected")

**Output:**
- Partial financial_reports row with:
  - `extraction_method: 'news_inference'` (vs 'ocr_pdf')
  - `confidence: 0.45..0.65` (lower than OCR, indicates fallback)
  - Fields auto-populated from signals: `revenue_growth_qoq`, `margin_trend`, `debt_ratio_hint`
  - `source_note: 'Populated from chain signals due to PDF timeout'`

**Business Rule:**
- Only fallback if ≥2 credible signals mention financial data (not just price action)
- Skip fallback if signals are >7 days old (stale)
- Mark extraction_method as 'news_inference' so downstream validation tools can apply different thresholds

**DDD Layer:** application/usecases (fetchParseAndStoreBctc.ts modification)

## Non-Functional Requirements

- **Performance:** Sentiment detection <100ms (cached IMF/macro keyword list)
- **Data Freshness:** IMF news crawled daily 08:00 UTC; signal fallback triggered within 30s of PDF timeout
- **Accuracy:** IMF sentiment classification ≥80% correct (vs manual labeling of 20 test articles)
- **Language:** Vietnamese + English news sources; output bilingual
- **Availability:** Fallback activates automatically on timeout, no user intervention needed

## Edge Cases & Data Quality

### IMF Sentiment Detection (FR-1)

- [ ] IMF staff report with no program attached → classify as neutral (policy observation, not action)
- [ ] Conflicting signals (IMF optimistic, but CPI data worse than expected) → take weighted average, log conflict
- [ ] Old news (>2 weeks) reappearing in feed → de-duplicate by headline hash before re-classifying
- [ ] Non-IMF organizations (World Bank, ADB) using IMF-like language → require "International Monetary Fund" or "IMF" in source to trigger full classification
- [ ] Vietnamese abbreviations (Quỹ Tiền Tệ Quốc Tế) → regex match for both English and Vietnamese
- [ ] Missing macro context (headlines only, no summary) → apply 0.2 confidence penalty, still populate field

### BCTC Fallback (FR-2)

- [ ] PDF timeout but no recent signals available → skip fallback, leave financial_reports row unwritten (existing logic)
- [ ] Contradictory signals (one says revenue up, another says down) → skip fallback, wait for next OCR attempt
- [ ] News signal mentions "2023 revenue" but current quarter is Q1-2024 → apply temporal discount (0.8x confidence)
- [ ] Multiple PDFs for same stock/quarter (e.g., corrected filing) → check extraction_method, prefer OCR over news_inference in aggregations
- [ ] Fallback populated, then OCR succeeds later → overwrite news_inference row with OCR row (OCR has priority)
- [ ] Signal hints at "margin compression" but no numeric value → store as `margin_trend: -1` (direction only, no magnitude)

## Blockers (STOP — user must answer before coding)

- [x] **B1: IMF sentiment scope — should we also classify World Bank, ADB, BIS macro events?**
  - **RESOLVED (PO decision 2026-04-23):** IMF-only. Vietnam-focused product; IMF is primary macro lever for VN currency/credit policy. World Bank/ADB/BIS add noise vs signal SNR for retail investors. Scope tight, MVP fast. Expand later if user requests.

- [x] **B2: BCTC fallback confidence threshold — at what confidence level should fallback field be used in downstream analysis?**
  - **RESOLVED (PO decision 2026-04-23):** MODERATE (0.5+). Preserves 80% of enriched signals vs conservative (0.7+) losing 20%. Downstream tools apply 10% confidence discount when extraction_method='news_inference'. Balances signal capture vs trust.

- [x] **B3: Signal age for BCTC fallback — should we extend the 7-day window or make it configurable?**
  - **RESOLVED (PO decision 2026-04-23):** CONFIGURABLE via env var `BCTC_FALLBACK_SIGNAL_MAX_AGE_DAYS` (default=7). Allows ops to adjust for seasonal illiquidity (lunar new year, holidays) without code redeploy. Maintains backward compat.

## Technical Notes

### Signal Payload Schema (existing, from Task 1293a)

ChainCatalystFindingData interface enforces:
```typescript
interface ChainCatalystFindingData {
  event_type: "credit_policy" | "trade_war" | "earnings" | "macro" | "legal" | "crisis" | "sector_event";
  direction: "bullish" | "bearish" | "neutral";
  confidence: number; // [0, 1]
  affected_stocks: string[];
  affected_sectors: string[];
  headline: string;
  source: string;
  // NEW in 1294a:
  newsSentiment?: number; // [-1, 1], optional during transition, becomes required after 1294
}
```

### BCTC Fallback Trigger

In `fetchParseAndStoreBctc()`:
```typescript
try {
  const parsed = await extractPdfText(pdfPath, timeout=10s);
} catch (err) {
  if (enableBctcFallback) {
    const signals = await querySignalsForStock(code, lookback=7d);
    if (hasBctcKeywords(signals)) {
      const fallbackRow = mapSignalsToBctc(signals);
      await insertFinancialReports({ ...fallbackRow, extraction_method: 'news_inference' });
    }
  }
}
```
