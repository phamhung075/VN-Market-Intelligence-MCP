## Overview

Detect Vietnamese weather events (rainfall, drought, storm, cold snap) from RSS news feeds using keyword matching, verify source credibility, and cascade HIGH-severity alerts to agricultural stock watchlist (VNR, BFC, QNT, ANV, MPC, ASM). Follows identical pattern to insider-dump (1278) and MSCI-inclusion (1279) cascade detectors.

## Architecture Decision

**Layer split (mirrors Tasks 1278 + 1279):**
1. **Domain** (`cascadeEngine.ts`, `agricultureDetector.ts`): Pure detection rules, keyword matching, credibility threshold enforcement, static rule definitions
2. **Application** (`cascadeExecutor.ts`): Orchestration helper that composes domain functions + business logic (agriculture stock filtering, domain-based peer identification)
3. **Tests** (`1281a`, `1281b`): Contract-first TDD with RED failing tests, GREEN passing implementation

**Design rationale:**
- Weather detection is **objective fact** (rainfall confirmed by meteorological data), unlike sentiment-dependent cascades (insider dump, MSCI)
- Credibility threshold (0.6) is lower than MSCI (0.7) because weather sources are less subject to misinformation (e.g., VnExpress weather report is factually verifiable)
- Agriculture stocks trigger rules: filter watchlist to domain="agriculture" only (hardcoded: VNR, BFC, QNT, ANV, MPC, ASM; extensible via domain field)
- Weather impact is **VN-wide by default** (no region filtering; geographic scoping deferred to ACv2 if user feedback warrants)
- Severity: **HIGH** (direct input cost/supply impact, not speculative like sentiment cascades)

**Comparison to prior cascades:**
| Aspect | Insider Dump (1278) | MSCI Inclusion (1279) | Agriculture Weather (1281) |
|--------|--------------------|-----------------------|--------------------------|
| Detection | Sentiment keywords | Index keywords | Weather event keywords |
| Direction | Bearish (negative) | Bullish (positive) | Neutral (factual) |
| Trigger sector | Banking only | All sectors (large-cap) | Agriculture only |
| Credibility threshold | (via sentiment) | 0.7 | 0.6 |
| Peer logic | Lateral (peers in same sector) | Hierarchical (all large-caps) | Domain-based (agriculture) |

### New domain service: agricultureDetector.ts

```typescript
/**
 * Detect agriculture weather keywords in news summary and verify source credibility.
 * Pure domain function — no I/O, no side effects.
 *
 * Keywords (Vietnamese, whole-word, case-insensitive):
 *   Rainfall: "mưa lớn", "mưa kiên kéo", "lũ lụt", "ngập lụt", "mưa gây lũ", "báo động 3", "báo động 2"
 *   Drought: "hạn hán", "thiếu nước", "tác động hạn", "khô hạn", "cạn nước"
 *   Storm: "bão", "gió mạnh", "gió bão", "thiệt hại bão"
 *   Cold snap: "rét đậm", "rét hại", "gió lạnh Siberia"
 */
export interface AgricultureWeatherDetectionResult {
  /** True if weather keywords detected + credibility >= 0.6 */
  matched: boolean;
  /** List of matched keywords (lowercase) */
  keywords: string[];
  /** Excerpt of text around matched keywords */
  context: string;
  /** Confidence score: min(1.0, sourceCredibility × matchedKeywordCount / 3.0) */
  confidence: number;
  /** Impact type: "rainfall" | "drought" | "storm" | "cold_snap" | null if no match */
  impactType: string | null;
}

/**
 * Detect agriculture weather keywords in seed text.
 *

 *   - If sourceCredibility < 0.6, return matched=false (reject low-confidence sources)
 *   - If sourceCredibility >= 0.6, proceed with keyword matching

 *   - confidence = min(1.0, sourceCredibility × matchedKeywordCount / 3.0)

 *
```
