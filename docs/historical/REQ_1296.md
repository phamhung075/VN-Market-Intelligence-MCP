## Part B: Edge Cases & Data Quality (IMF Integration)

- [ ] **Missing IMF data**: Indicator published late or skipped month → fallback to previous reading with age penalty
- [ ] **Stale IMF forecast**: 3-month-old growth forecast still in cache → deprecate confidence after 60 days
- [ ] **Conflicting signals**: IMF bullish but technical indicators bearish → resolve via composite scoring (weighted average)
- [ ] **Regional vs Vietnam-specific data**: IMF publishes ASEAN aggregate, Vietnam subset separately → use Vietnam-specific if available, fall back to ASEAN with modifier
- [ ] **VN currency volatility**: USD/VND spikes during IMF release → detect volatility spike, delay alert generation 5 min (wait for digestion)
- [ ] **Geopolitical noise**: IMF mentions trade war, sanctions → check if VN-specific or global-only, apply appropriate cascade rule
- [ ] **Language**: IMF releases in English, news sources in Vietnamese → ensure translation accuracy (LLM or manual keyword map)
- [ ] **Historical backfill**: Should we populate macro_indicators table with 2-year IMF history, or start fresh? (Decision for Architect after research)

## Blockers (BA Research, Not Development)

These questions must be answered before coding starts on task 1296b:

### B1: IMF API Selection

**Question**: Which IMF data source should we use?

**Options**:
- Option A: Official IMF Data API (https://www.imf.org/external/datamapper/) — requires API key, ~5 endpoints, lag 1–2 weeks
- Option B: IMF REST API (metadata.imf.org) — public, structured, ~50 endpoints, lag 1–2 weeks
- Option C: Web scraping (IMF World Economic Outlook portal) — no API key, lag <1 day, fragile to portal changes
- Option D: Third-party wrapper (Trading Economics IMF data) — simple, curated, but cost-dependent

**Context**: Sprint 1294 showed we need fast, fresh signals to enrich alerts. Lag >2 weeks may be too late.

**Recommendation**: Research task 1296a should test all 4 options, recommend by data freshness + reliability.

---

### B2: Integration Scope (IMF-Only vs Broader Macro)

**Question**: Should we also integrate World Bank, ADB, BIS signals, or keep Phase 1 IMF-only?

**Context**: Expansion could improve context richness (3 institutions) but may add noise or complexity.

**Recommendation**: Keep Phase 1 IMF-only (focused scope). World Bank/ADB can be Phase 2 (sprint 1298+) if IMF metrics improve signal quality.

---

### B3: Confidence Thresholds for Signal Enrichment

**Question**: At what IMF confidence level should we enrich signalPayload?

**Options**:
- Option A: Only >0.7 IMF confidence (strict, fewer enriched signals)
- Option B: >0.5 IMF confidence (moderate, balanced)
- Option C: All readings >0.3 confidence (permissive, more context but noise risk)

**Context**: If threshold too high, signals stay incomplete. If too low, noisy IMF forecasts pollute 4-AND logic.

**Recommendation**: Start with 0.55 as default (moderate), allow override via `IMF_CONFIDENCE_MIN` env var. Monitor false-positive rate in Sprint 1297.
