# REQ-040: Macro Catalyst — Đầu Tư Công + Tín Dụng BĐS-Ngân Hàng + Giao Dịch Nội Bộ

status: APPROVED
sprint: 040
po_vision: Phát hiện catalyst macro cho thị trường VN: gói thầu đầu tư công từ muasamcong.mof.gov.vn, dòng tín dụng BĐS→ngân hàng, và giao dịch nội bộ (insider trading) từ SSC. Ba nguồn tín hiệu này tạo alpha đáng kể cho nhà đầu tư retail.

---

## User Stories

### US-1: Radar đầu tư công
As a Vietnamese stock investor,
I want the system to monitor muasamcong.mof.gov.vn for new infrastructure contracts (highways, airports, power plants, IT),
So that I receive alerts when large contracts are awarded that benefit stocks in my watchlist (e.g., FPT for IT, HHV/CII for construction, ACV for airports).

### US-2: Tín dụng BĐS-Ngân hàng nexus
As a Vietnamese stock investor holding VCB,
I want the system to track NHNN credit growth data (total credit, RE credit ratio, interest rates),
So that I can assess the impact on banking stock earnings and real estate liquidity.

### US-3: Giao dịch nội bộ (insider trading)
As a Vietnamese stock investor,
I want the system to track insider transactions (board members buying/selling shares) from SSC disclosures,
So that I receive alerts when insiders are accumulating or distributing — a statistically significant predictive signal.

## Functional Requirements

### FR-1: Mua Sam Cong Fetcher (`src/infrastructure/fetchers/muasamcong.ts`)

- **Description**: Scrape `muasamcong.mof.gov.vn` for new public procurement packages (gói thầu).
- **Data extracted**: Package name, value (VND), category (construction/IT/equipment), awarding agency, winning bidder, award date.
- **Output**: `PublicContract[] { title, value, category, agency, winner, awardDate, relatedStocks: string[] }`
- **Contract-to-stock mapping**: Static map + keyword matching:
  | Category | Keywords | Stocks |
  |---|---|---|
  | Highway/bridge | cao tốc, cầu đường, giao thông | HHV, CII, VCG |
  | Airport/port | sân bay, cảng | ACV, GMD, PHP |
  | Power | điện, năng lượng | GEG, REE, PC1 |
  | Water/urban | nước, đô thị | BWE, TDW |
  | IT | công nghệ thông tin, phần mềm, số hóa | FPT, CMG |
- **Error handling**: Never throw. Circuit breaker + rate limiter.

### FR-2: Credit Flow Analyzer (`src/domain/services/creditFlowAnalyzer.ts`)

- **Description**: Pure domain service. Analyze credit growth data → impact chain to banking + RE stocks.
- **Input**: `CreditData { totalCredit, reCredit, reCreditRatio, yoyGrowth, interestRate }`
- **Output**: `CreditSignal { direction, affectedStocks, impact, reasoning }`
- **Chain logic**:
  ```
  NHNN tăng room tín dụng → thanh khoản BĐS cải thiện
    → VHM, NVL, KDH: doanh thu tăng → VCB, BID, CTG: nợ xấu giảm → EPS tốt
  NHNN siết tín dụng BĐS → thanh khoản BĐS giảm
    → VHM, NVL: doanh thu giảm → VCB, BID: provision tăng → EPS giảm
  ```
- **Pure function**: No I/O.

### FR-3: SSC Insider Fetcher (`src/infrastructure/fetchers/sscInsider.ts`)

- **Description**: Scrape SSC portal for insider transaction disclosures (công bố giao dịch nội bộ).
- **Source**: `ssc.gov.vn` or `congbothongtin.ssc.gov.vn` — insider transaction section.
- **Data extracted**: Stock code, insider name, position (CEO/CFO/Board member), transaction type (buy/sell), volume, price, transaction date.
- **Output**: `InsiderTransaction[] { code, insiderName, position, type: 'buy'|'sell', volume, price, date, registeredVolume }`
- **Error handling**: Never throw. Circuit breaker.

### FR-4: Leadership Signal Detector (`src/domain/services/leadershipSignal.ts`)

- **Description**: Pure domain service. Classify insider transactions into investment signals.
- **Signal classification**:
  | Event | Signal | Severity |
  |---|---|---|
  | CEO/CFO buys large volume (>0.5% outstanding) | BULLISH | HIGH |
  | Multiple insiders buy within 30 days | BULLISH | HIGH |
  | CEO/CFO sells entire holdings | BEARISH | CRITICAL |
  | Board member sells >50% holdings | BEARISH | HIGH |
  | New CEO appointment from major corp | BULLISH | MEDIUM |
  | CFO sudden resignation | BEARISH | HIGH |
- **Output**: `LeadershipSignal { type, severity, code, insiderName, position, action, volume, confidence }`
- **Pure function**: No I/O.

### FR-5: Signal Integration

- **Extend `SignalType`**: Add `"public_contract"` | `"credit_flow"` | `"insider_trading"` to union.
- **Wire muasamcong**: Add as Step A4 in intelligence cycle (parallel fetch).
- **Wire SSC insider**: Add as Step B2 (after existing SSC BCTC check).
- **Wire credit flow**: Triggered by NHNN data changes (monthly check).

### FR-6: MCP Tools

- `get_public_investment_signals(category?: string, days?: number)` → Recent contract awards
- `get_credit_flow_signals(days?: number)` → Credit growth impact analysis
- `get_leadership_signals(stock?: string, days?: number)` → Insider transactions

## Non-Functional Requirements

- Same as REQ-039 (pure domain, circuit breaker, rate limiter, tests).

---

## Edge Cases

1. **Contract winner not in watchlist**: Store for future reference but don't alert.
2. **Insider buys tiny amount**: Filter by % of outstanding shares (min 0.1%).
3. **Credit data lag**: NHNN publishes monthly with 2-week delay — store timestamp.
4. **Multiple insiders same stock**: Group into single leadership signal with elevated severity.
