# REQ-1298: IMF Sentiment Classifier — Implementation Spec

status: READY_FOR_ARCHITECT
sprint: 1298
po_vision: Enrich ChainCatalyst signals with IMF macro context to improve conviction accuracy in banking, export, and real estate sectors.

---

## User Story

As a Vietnamese stock investor using Claude,
I want IMF economic indicators (growth forecasts, inflation, USD strength, FDI outlook) automatically classified and injected into signal conviction scoring,
So that macro-level international sentiment (65–85% correlated with VN sector rotations) raises or lowers my trade conviction without requiring manual market research.

---

## Functional Requirements

### FR-1: IMF Indicator Domain Model

- **Description**: Define typed data structures for IMF economic indicators with confidence decay
- **Input**: Raw IMF API response (JSON), publication date, previous value
- **Output**: `ImfIndicator[]` with freshness-adjusted confidence scores
- **Business rule**: Confidence decays by age bracket — ≤7 days: 0.95, ≤14: 0.85, ≤30: 0.70, ≤60: 0.50, >60: 0.30
- **DDD layer**: domain
- **File**: `src/domain/models/imfIndicators.ts` (CREATE, ~120 lines)

**Types required:**

| Symbol | Description |
|--------|-------------|
| `ImfIndicator` | 9-field interface: code, name, value, publishedAt, ageInDays, previousValue, yoyChange, source, confidence |
| `IMF_INDICATORS` | `as const` map — 9 indicator codes for VN-relevant signals |
| `ImfClassificationInput` | `{ indicators: ImfIndicator[], historicalBaseline: number }` |
| `ImfClassificationOutput` | `{ sentiment, confidence, classification, reasoning, sectorImpacts[] }` |
| `calculateConfidenceDecay(ageInDays)` | Pure function, returns `number` from decay table above |

---

### FR-2: IMF Data Classifier (Pure Domain Logic)

- **Description**: Classify array of `ImfIndicator` into a sentiment score and sector impact map
- **Input**: `ImfClassificationInput` (indicators + historicalBaseline)
- **Output**: `ImfClassificationOutput` (sentiment [-1..1], confidence [0..1], classification, sectorImpacts[])
- **Business rule**: Weighted sentiment = sum(indicator.sentiment_contribution * indicator.confidence) / sum(indicator.confidence); result clipped to [-1, +1]
- **DDD layer**: domain
- **File**: `src/domain/services/imfDataClassifier.ts` (CREATE, ~180 lines)

**Rule mapping summary (11 rules — full spec in TECH_1296b.md):**

| Rule ID | Trigger | Threshold | Sector | Impact |
|---------|---------|-----------|--------|--------|
| imf_rule_01 | Growth ↑ | sentiment > 0.5 | banking, export | +0.45, +0.35 |
| imf_rule_02 | Growth ↓ | sentiment < -0.5 | real_estate | -0.35 |
| imf_rule_03 | Advanced economy ↑ | sentiment > 0.3 | export, manufacturing | +0.35 |
| imf_rule_04 | USD strength ↑ | sentiment > 0.3 | agriculture | +0.10 |
| imf_rule_05 | Inflation ↑ | sentiment < -0.4 | banking | -0.08 |
| imf_rule_06 | EM capital flight | sentiment < -0.6 | real_estate | -0.25 |
| imf_rule_07 | VN fiscal risk ↑ | sentiment < -0.4 | banking | -0.12 |
| imf_rule_08 | Oil forecast ↑ | sentiment > 0.4 | energy | +0.14 |
| imf_rule_09 | FDI outlook ↑ | sentiment > 0.3 | tech, manufacturing | +0.11 |
| imf_rule_10 | ASEAN growth ↑ | sentiment > 0.2 | retail, tourism | +0.09 |
| imf_rule_11 | Capital account stress | sentiment < -0.3 | banking | +0.08 (niche) |

**Invariants:**
- No `async`, no `import` from `application/` or `infrastructure/` — domain-pure
- Must extend, not replace, `src/domain/services/imfSentimentClassifier.ts` (keyword-based, existing)

### FR-3: IMF Data Fetcher (Application Layer)

- **Description**: Fetch IMF indicators from REST API; fallback to WEO scraping; store/retrieve from SQLite cache
- **Input**: None (periodic trigger); optional `days_back` filter for MCP tool reads
- **Output**: `ImfIndicator[]`
- **Business rule**:
  - Rate limit: 10 req/min (0.17 req/sec) on `data.imf.org`
  - Circuit breaker: open after 3 consecutive failures, reset after 60s
  - Fallback chain: IMF REST API → WEO scraping → SQLite cache with `confidence *= 0.8` penalty
  - All SQLite queries parameterized (no string interpolation)
- **DDD layer**: application
- **File**: `src/application/services/imfDataFetcher.ts` (CREATE, ~160 lines)

**Exported functions:**

| Function | Signature | Notes |
|----------|-----------|-------|
| `fetchLatestImfIndicators` | `() => Promise<ImfIndicator[]>` | HTTP + fallback chain |
| `storeImfIndicators` | `(indicators: ImfIndicator[]) => Promise<void>` | Upsert to `macro_indicators` table |
| `getLatestImfIndicators` | `() => Promise<ImfIndicator[]>` | Read from SQLite cache only |

- **Description**: Add optional `imfSentiment` field to `ChainCatalystFindingData`; extend Zod schema
- **Input**: Existing `ChainCatalystFindingData` (7 fields)
- **Output**: Same interface + optional `imfSentiment?: { sentiment, confidence, affectedSectors, reasoning }`
- **Business rule**: Field is optional and nullable — existing signals without it pass validation unchanged
- **DDD layer**: domain
- **File**: `src/domain/signals/signalTypes.ts` (MODIFY)

**Zod constraints on `imfSentiment`:**
- `sentiment`: `z.number().min(-1).max(1)` — rejects values outside range
- `confidence`: `z.number().min(0).max(1)`
- `affectedSectors`: `z.array(z.string()).min(0)`
- `reasoning`: `z.string().min(1)` — no empty strings

### FR-5: Cascade Engine Rules

- **Description**: Append 11 IMF-specific rules to existing `CASCADE_RULES` array
- **Input**: `ChainCatalystFindingData.imfSentiment` field (when present)
- **Output**: Cascade engine fires matching rules, adjusts sector weights
- **Business rule**: Rules fire only when `imfSentiment.confidence >= IMF_CONFIDENCE_MIN` (env: default 0.55)
- **DDD layer**: domain
- **File**: `src/domain/services/cascadeEngine.ts` (MODIFY — append `IMF_CASCADE_RULES`)

### FR-6: ChainSynthesizer IMF Conviction Weight

- **Description**: Extract `imfSentiment` from signal findingData; apply 20% weight to conviction score
- **Input**: `ChainLink[]` where some links contain `findingData.imfSentiment`
- **Output**: `conviction` score increased or decreased by up to ±0.20
- **Business rule**: IMF contribution = `imfSentiment.sentiment * 0.2` — only applied when `imfSentiment.confidence >= IMF_CONFIDENCE_MIN`
- **DDD layer**: domain
- **File**: `src/domain/services/chainSynthesizer.ts` (MODIFY — post-enrichment conviction step)

### FR-7: IMF Indicator Poller Job (Scheduler)

- **Description**: 6-hour cron job: fetch → store → classify; returns structured result
- **Input**: None (cron-triggered)
- **Output**: `{ success: boolean, indicator_count: number, sentiment?: ImfClassificationOutput, error?: string }`
- **Business rule**:
  - Fires at `0 */6 * * *` (00:00, 06:00, 12:00, 18:00 server time)
  - `timeoutMs: 30000`
  - On failure: log error, return `{ success: false, indicator_count: 0, error }` — do NOT throw
- **DDD layer**: scheduler
- **File**: `src/scheduler/market-data/imfIndicatorPollerJob.ts` (CREATE, ~80 lines)
- **Registration**: `src/scheduler/cron-registry.ts` (MODIFY — add `imf_indicator_poller` entry)

## Edge Cases & Data Quality

- [ ] IMF API returns `null` or missing value for an indicator → skip that indicator, log warning, do not crash
- [ ] `yoyChange` is null (no previous value available) → treat as 0.0, do not fire growth rules
- [ ] `publishedAt` is missing or malformed ISO date → use `ageInDays: 999`, apply 0.30 confidence floor
- [ ] All indicators stale (>60 days) → `ImfClassificationOutput.confidence <= 0.30`, classification forced to `imf_neutral`
- [ ] Circuit breaker open + SQLite cache empty → return `[]`, log error, do NOT throw (poller returns `success: false`)
- [ ] `IMF_CONFIDENCE_MIN` env var not set → default to `0.55`; if set to invalid value → fall back to `0.55`, log warning
- [ ] `imfSentiment.sentiment` field present but `confidence` below threshold → IMF contribution skipped silently (no error)
- [ ] Multiple indicators for same code from different runs → upsert on `code` key (last-write wins by `fetched_at`)

## Data Flow

```
[6h cron trigger]
  → imfIndicatorPollerJob.runImfIndicatorPollerJob()
    → imfDataFetcher.fetchLatestImfIndicators()
        → rateLimiter.checkAndThrottle("data.imf.org", 0.17 req/s)
        → circuitBreaker.execute(GET data.imf.org/api/v1/data)
        → [on failure]: fallback WEO scrape → [on failure]: SQLite cache * 0.8
    → imfDataFetcher.storeImfIndicators(indicators)   [upsert macro_indicators]
    → imfDataClassifier.classifyImfIndicators(input)  [pure, no I/O]
    → log result

[Signal synthesis path]
  News Scout
    → ChainCatalyst signal (findingData may include imfSentiment)
    → chainSynthesizer.synthesizeChain(links)
        → extract imfSentiment if present
        → if imfSentiment.confidence >= IMF_CONFIDENCE_MIN (0.55):
            conviction += imfSentiment.sentiment * 0.20
        → cascadeEngine fires IMF_CASCADE_RULES if imfSentiment meets trigger thresholds
    → conviction score with IMF macro context included

[MCP tool path]
  User calls get_imf_signals(days_back, indicator_code)
    → imfDataFetcher.getLatestImfIndicators()   [cache read, no HTTP]
    → imfDataClassifier.classifyImfIndicators() [pure classify]
    → return JSON { indicators, sentiment, classification, last_updated, confidence }
```
