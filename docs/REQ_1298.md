# REQ-1298: IMF Sentiment Classifier

status: READY_FOR_ARCHITECT
sprint: 1298
po_vision: Enrich ChainCatalyst signals with IMF macro context to improve conviction accuracy in banking, export, and real estate sectors.

## User Story

As a Vietnamese stock investor using Claude,
I want IMF economic indicators (growth forecasts, inflation, USD strength, FDI outlook) automatically classified and injected into signal conviction scoring,
So that macro-level international sentiment (65–85% correlated with VN sector rotations) raises or lowers my trade conviction without requiring manual research.

## Functional Requirements

### FR-1: IMF Indicator Domain Model — Task 1298a

- **Description**: Typed data structures for IMF economic indicators with confidence decay
- **Input**: Raw IMF API response (JSON), publication date, previous value
- **Output**: `ImfIndicator[]` with freshness-adjusted confidence scores
- **Business rule**: Confidence decays by age bracket: ≤7d → 0.95, ≤14d → 0.85, ≤30d → 0.70, ≤60d → 0.50, >60d → 0.30
- **DDD layer**: domain
- **File**: `src/domain/models/imfSentiment.ts` (CREATE)

**Types required:**

| Symbol | Description |
|--------|-------------|
| `ImfIndicator` | 9-field interface: code, name, value, publishedAt, ageInDays, previousValue, yoyChange, source, confidence |
| `IMF_INDICATORS` | `as const` map — 9 indicator codes (NGDP_RPCH, PCPI_ADVEC, POILAPSP, FDI_SCORE, DXY_IMF_PROXY, etc.) |
| `ImfClassificationInput` | `{ indicators: ImfIndicator[], historicalBaseline: number }` |
| `ImfClassificationOutput` | `{ sentiment, confidence, classification, reasoning, sectorImpacts[] }` |
| `calculateConfidenceDecay(ageInDays)` | Pure fn, returns number from decay table above |

> Full interface spec: `docs/TECH_1296b.md` §Interface Contracts §1.

### FR-2: IMF Data Classifier (Pure Domain Logic) — Task 1298a

- **Description**: Classify `ImfIndicator[]` into sentiment score + sector impact map
- **Input**: `ImfClassificationInput`
- **Output**: `ImfClassificationOutput` — `sentiment` clipped to [-1..+1]
- **Business rule**: Weighted sentiment = `Σ(contribution_i × confidence_i) / Σ(confidence_i)`; extend (do not replace) existing `imfSentimentClassifier.ts`
- **DDD layer**: domain
- **File**: `src/domain/services/imfSentimentClassifier.ts` (CREATE — new structured classifier alongside existing keyword-based)

**11 cascade rules (trigger → sector → impact):**

| Rule | Trigger | Sector(s) | Impact |
|------|---------|-----------|--------|
| imf_rule_01 | Growth ↑ (>0.5) | banking, export | +0.45, +0.35 |
| imf_rule_02 | Growth ↓ (<-0.5) | real_estate | -0.35 |
| imf_rule_03 | Advanced economy ↑ (>0.3) | export, manufacturing | +0.35 |
| imf_rule_04 | USD strength ↑ (>0.3) | agriculture | +0.10 |
| imf_rule_05 | Inflation ↑ (<-0.4) | banking | -0.08 |
| imf_rule_06 | EM capital flight (<-0.6) | real_estate | -0.25 |
| imf_rule_07 | VN fiscal risk (<-0.4) | banking | -0.12 |
| imf_rule_08 | Oil forecast ↑ (>0.4) | energy | +0.14 |
| imf_rule_09 | FDI outlook ↑ (>0.3) | tech, manufacturing | +0.11 |
| imf_rule_10 | ASEAN growth ↑ (>0.2) | retail, tourism | +0.09 |
| imf_rule_11 | Capital account stress (<-0.3) | banking | +0.08 (niche) |

**Invariants:**
- No `async`, no I/O, no imports from `application/` or `infrastructure/`
- O(1) per indicator (lookup table, no loop-heavy logic)

### FR-4: IMF Data Fetcher (Application Layer) — Task 1298b

- **Description**: Fetch IMF indicators from REST API; fallback to WEO scraping; store/retrieve from SQLite cache
- **Input**: None (cron-triggered) / optional `days_back` + `indicator_code` (MCP reads)
- **Output**: `ImfIndicator[]`
- **Business rule**:
  - Rate limit: `rateLimiter.checkAndThrottle("data.imf.org", 0.17)` (10 req/min)
  - Circuit breaker: open after 3 failures, `resetTimeoutMs: 60000` (not 30s — see circuit-breaker pattern)
  - Fallback: IMF REST API → WEO scraping → SQLite cache with `confidence *= 0.8`
  - All SQLite queries parameterized — no string interpolation
- **DDD layer**: application
- **File**: `src/infrastructure/fetchers/imfFetcher.ts` (CREATE)

**Exported functions:**

| Function | Signature | Notes |
|----------|-----------|-------|
| `fetchLatestImfIndicators` | `() => Promise<ImfIndicator[]>` | HTTP + fallback chain |
| `storeImfIndicators` | `(indicators: ImfIndicator[]) => Promise<void>` | Upsert `macro_indicators` |
| `getLatestImfIndicators` | `() => Promise<ImfIndicator[]>` | Cache read only (no HTTP) |

> Full HTTP contract: `docs/TECH_1296b.md` §Interface Contracts §3.

## Edge Cases & Data Quality

- [ ] IMF API returns `null` for indicator → skip, log warning, do not crash
- [ ] `yoyChange` is null (no previous value) → treat as 0.0, do not fire growth rules
- [ ] `publishedAt` malformed ISO date → `ageInDays: 999`, confidence floor 0.30
- [ ] All indicators stale (>60d) → `confidence <= 0.30`, classification forced `imf_neutral`
- [ ] Circuit breaker open + SQLite cache empty → return `[]`, log error, do NOT throw
- [ ] `IMF_CONFIDENCE_MIN` env var absent → default 0.55; invalid value → fall back 0.55 + log warning
- [ ] `imfSentiment.confidence` below threshold → IMF contribution skipped silently (no error)
- [ ] Duplicate indicator code across runs → upsert on `code` key (last-write wins by `fetched_at`)

## Data Flow

```
[6h cron: 0 */6 * * *]
  → imfPollerJob.runImfIndicatorPollerJob()
      → imfFetcher.fetchLatestImfIndicators()
          → rateLimiter.checkAndThrottle("data.imf.org", 0.17 req/s)
          → circuitBreaker.execute(GET metadata.imf.org/...)
          → [failure]: WEO scrape fallback
          → [failure]: SQLite cache × 0.8 confidence penalty
      → imfFetcher.storeImfIndicators(indicators)   [upsert macro_indicators]
      → imfSentimentClassifier.classifyImfIndicators(input)  [pure, no I/O]
      → log result

[Signal synthesis path]
  ChainCatalyst signal (findingData.imfSentiment optional)
    → chainSynthesizer.synthesizeChain(links)
        → if imfSentiment.confidence >= 0.55:
            conviction += imfSentiment.sentiment × 0.20
        → cascadeEngine fires IMF_CASCADE_RULES on imfSentiment triggers
    → conviction score with IMF macro context

[MCP tool path]
  get_imf_signals(days_back?, indicator_code?)
    → imfFetcher.getLatestImfIndicators()  [cache only, no HTTP]
    → imfSentimentClassifier.classifyImfIndicators()
    → return JSON { indicators, sentiment, classification, last_updated, confidence }
```
