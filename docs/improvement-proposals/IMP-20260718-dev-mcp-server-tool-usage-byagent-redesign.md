## Weakness

Fleet performance audit (Tier-4) requires per-agent tool-call attribution to identify precision anomalies (e.g. excessive retries, call failures per agent). Current `docs/agent-memory/modules/tool-usage-stats.json` is generated by `trackSessionToolUsageJob.ts` reading `perCallCounterStore.ts` (an in-memory `Map<toolName, count>` incremented by a gateway handler-proxy), but carries NO agent-identity dimension. The counter key is `toolName` only; no `agentId` compound key exists. This is documented as a Phase 0 prerequisite for Tier-4 permanent cadence (source brief `2026-07-18-cron-workflow-optimize-tier4-fleet-audit.md` §2c, Phase 0). Evidence: Tier-4 pilot run (2026-07-18) verified that `tool-usage-stats.json` has no `byAgent` key; pilot runs in degraded mode (global-only counts).

## Evidence

- **Source:** Tier-4 audit dimension T4-C (tool-usage-stats precision), pilot run #1
- **Data:** Read `docs/agent-memory/modules/tool-usage-stats.json` → `jq 'has("byAgent")'` returns `false`; only global keys present (generatedAt, uniqueTools, toolCounts)
- **Impact:** Tier-4 cannot attribute calls to agents; pilot must degrade to global-only counts per brief §2c
- **Blocking:** Brief §7 G5 — full (c) coverage required before permanent-cadence ask; pilot v1 degraded mode is acceptable
- **Reproducibility:** Run the hourly `trackSessionToolUsageJob.ts` and inspect the output JSON structure

## Proposed Change

Phase 0 (per source brief `2026-07-18-cron-workflow-optimize-tier4-fleet-audit.md` §8):

1. **perCallCounterStore.ts:** Change key from `toolName` to compound `${agentId}:${toolName}`. Add a separate error counter (increment on handler throw, not just entry; today there is no error tracking at all).

2. **server.ts (gateway handler-proxy):** Read optional `arguments._callerAgent` passthrough field (added to `mcp__gateway__call_tool` contract, see item 4). Default to `"unknown"` if absent. Pass `agentId` to the counter store.

3. **trackSessionToolUsageJob.ts:** Keep existing top-level `generatedAt`, `uniqueTools`, `toolCounts` fields (no breaking change to existing readers). Add **additive** `byAgent` key: `{ "<agent-id>": { toolCounts: {...}, errorCounts: {...} }, ... }`.

4. **Contract docs:** Update `docs/standards/mcp-tools.md` and `docs/standards/gateway-call-contract.md` to document the optional `_callerAgent` passthrough (stripped before tool business logic, read only by telemetry proxy; absent = no silent misattribution).

5. **QA gate-proof:** Inject a deliberate wrong-agentId call and prove it does NOT silently misattribute to the wrong bucket in the byAgent breakdown.
