# Analysis Ledger Template

When creating a new ledger file at `docs/analysis-briefs/{TICKER}.md`:

```markdown
# {TICKER} — Analysis Ledger {YEAR}
**Exchange**: {exchange}

## [Report Analyzer] Fundamentals & Valuation

## [News Scout] Headlines & Sentiment

## [Market Watcher] Price, Volume, Technicals

## [Unified Agent] Quarterly Syntheses
```

Each agent appends under its own section. Never overwrite other agents' sections.
