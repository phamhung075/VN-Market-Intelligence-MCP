## 2. Guardrail design — zero-tolerance, fix-now (not baseline/ratchet), but pattern/tree-level checks (not full unused-export tooling) for MVP

**Sizing call:** total live debt ≈ 2,070 LOC + 2 stray artifact files across 4 categories — bigger in absolute LOC than the metric-mask/depguard siblings' single-digit-line fixes, but **100% pure subtraction of already zero-verified-orphaned code** (not refactor-risk work), matching the audit brief's own framing verbatim: "Pure subtraction, behavior-preserving, and the fastest way to shrink the review surface — must lead the program." Far below size-lint's 733-file/systemic-refactor scale that forced baseline/ratchet there → **zero-tolerance: fix ALL of it in the same child task, gate opens clean.**

**Mechanism — one `scripts/audits/dead-code-gate.sh` (bash/grep/find, no toolchain), 4 cheap structural checks, purpose-built for the exact debt shapes found today** (not generic per-symbol unused-export analysis):
1. Tracked-file ban: any `git ls-files` match on `*.bak`/`*.backup`/`*.patch` fails. Extend `.gitignore`'s existing `*.bak` line to also cover `*.backup`/`*.patch`.
2. `_deprecated/`-directory-name ban: any tracked path with a `_deprecated/` path segment fails. Git history is the rollback reference (same precedent `FACTORY-INTERFACE-delete-bak-files` already established for `.bak`) — a graveyard folder adds zero safety over `git log`/`git show` while diluting every grep, per the audit brief's own rationale.
3. Go/TS-twin-scaffold ban: any `apps/<svc>/` with a Go `cmd/server/` at its root MUST NOT also carry a top-level `package.json` **and** `src/` (the exact `technical-analysis` shape). After the child task's cleanup this is 0/7 Go services — any future reintroduction fails immediately.
4. `//go:build ignore` ban on any tracked `*.go` file (archived-but-compiled-out code) — zero legitimate uses found today.

**Deferred, NOT built now (documented enhancement):** full per-symbol unused-export detection via knip (TS) / `go vet`+`deadcode` (Go) / `vulture` (Python) across *all* live files — a fundamentally larger-scope, higher-false-positive-risk mechanism (needs per-project entry-point config to avoid flagging MCP-tool-registration-style intentional exports) than the 4 checks above. Zero live-debt evidence today extends beyond what checks 1-4 already catch; same "no work justified at current debt scale, documented but deferred" call the metric-mask and depguard-Python clauses made.

**CI wiring:** new `dead-code-gate` job in `.github/workflows/ci.yml`, `ubuntu-latest` + checkout only — cheapest-job shape, matching every sibling.
