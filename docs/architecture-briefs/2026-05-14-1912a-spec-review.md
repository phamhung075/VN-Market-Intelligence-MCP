## Blocker Resolution

### D-1: `/healthz` route

**Decision: Option (b) — Add `/healthz` as liveness alias in Go implementation only.**

Source truth confirmed via `apps/api-gateway/src/interface/handlers.ts`:
routes are `/health`, `/health/:service`, `/health-dashboard`, `/:service/*` — no `/healthz`.

The brief § 3.1 route table listed `/healthz` in error (typo-level gap, not a design intent).
However the TASKS.md 1912a row also lists it under "functional parity" AC requirements, which
means it is an explicit deliverable, not just a typo to drop.

Resolution: Go implementation adds `GET /healthz → same handler as /health` as a standard
k8s liveness probe endpoint. TS gateway does NOT need a backport:
- The TS gateway runs behind docker-compose only (no k8s orchestrator consuming `/healthz`).
- The 24h smoke window tests the Go container in isolation before P2 dispatch.
- No mcp-server consumer calls `/healthz` (confirmed: `apps/mcp-server/src/infrastructure/
  microservices/clients.ts` calls `/health` only).

Brief § 3.1 interface layer row updated to read:
`pkg/interface/http/router.go — net/http or chi router, routes: /health, /healthz (alias),
/health/:service, /health-dashboard, /api/*, /:service/*`

AC-11 is satisfied by this decision. Implementation AC: `/healthz` returns identical JSON and
HTTP status as `/health` (same handler reference, not a copy).

### D-2: Dev Role Gap

**Decision: Option A — Extend `dev-api-gateway` agent.**

Rationale:
- Phase 1 is the only in-flight Go migration. A specialist agent adds overhead with no benefit
  until P2 (alert-engine) is approved.
- `dev-api-gateway` already holds the gateway domain model, proxy semantics, and service
  registry knowledge. A lazy-load Go block preserves that context.
- Option B cost (~1 agent-father cycle) is justified only if P2+P3 proceed AND the Go surface
  grows beyond what lazy-load can isolate.
- Reassess after 1912a ships: if P2 alert-engine proceeds, spawn `dev-go-gateway` then.

**Implementation route:** agent-father to add Go competency lazy-load to
`.claude/agents/dev-api-gateway.md`. Trigger: `go_migration`. Loads: Go 1.22 `net/http`
handler idioms, table-driven `testing.T`, `log/slog` usage, `chi` path param patterns.
Architect does NOT edit the agent file directly (per `feedback_agent_md_factory` policy).
