## 3. Design — Go: net-new composition-root-logic gate

Live scan (receiver-method granularity, `if`/`for` count per function body) across all 7 services' `cmd/server/**/*.go` found exactly **2 real offenders, both in macro-indicators/adapters.go**: `policyRatesAdapter.FetchPolicyRates` (52L, 3-branch HTML-vs-DB-fallback decision that also sets `IsEstimate` — a business-semantic confidence flag, the same bug class as the metric-mask ticket) and `omoAdapter.FetchOMO` (58L, 4-branch/2-loop transform + `ParseOK` decision). Every other receiver-method shim across all 7 services (10 checked: `bopParserAdapter`, `bopURLBuilderAdapter` x3, `iipParserAdapter`, `cpiParserAdapter`, `tradeBalanceParserAdapter`, `sjcFXAdapter`, `omoDailyRepoAdapter` x3) is pure single-line delegation or a lone nil-guard — zero false positives.

**Mechanism:** scope the check to **receiver methods only** (adapter/shim types) inside `cmd/server/**/*.go` — explicitly excludes `func main()` and free helper functions (`envStr`/`envInt`/`getenv`/`splitCSV`/`parseWatchlist`/`readWatchlistFromDB` all legitimately branch/loop for env-parsing or startup config-read and are NOT the ticket's concern; `main()`'s own branching — e.g. macro-indicators' `COMMODITY_LIVE_MODE` gate, every service's graceful-shutdown goroutine — is accepted DI wiring, already sign-off'd via each file's `size-justification` header). Flag any receiver method with `if`-count >=2 OR any `for`/`range` — this exact threshold cleanly separates the 2 real offenders from all 10 clean shims today (empirically zero false positives). Use `go/ast`+`go/parser` (Go stdlib, zero new go.mod deps, already-available toolchain in every `go-lint` job) rather than regex — Go's real grammar (multi-line signatures, receivers) is not reliably regexable, unlike the size-lint/metric-mask siblings' TS/Python targets. Escape hatch matches program convention: inline `// composition-root-logic-allow: <reason>` comment on the preceding line.

**Zero-tolerance, not baseline:** debt is 2 functions in 1 service, fixable in the same child task (move the fallback+`IsEstimate` decision into `pkg/application`, leave the shim a pure delegate) — same size-driven call as metric-mask, not size-lint's 733-file grandfather case.
