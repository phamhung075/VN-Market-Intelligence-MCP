# REQ-1408: fix(tool-diacritics) — MCP tool Vietnamese diacritics

status: READY_FOR_ARCHITECT
sprint: 144
po_vision: Fix unaccented Vietnamese text in kinhDichTools, technicalIndicatorTools, and supplyChainTools so every MCP tool call returns properly accented output.

## User Story

As a Vietnamese stock investor using Claude,
I want MCP tool responses (Kinh Dịch reading, TA indicators, supply chain analysis) to display correct Vietnamese diacritics,
So that I can read tool output fluently without mentally decoding stripped text like "THUAN LOI" or "sap xep hon hop".

---

## Functional Requirements

### FR-1: Export `formatKinhDichTradingContext` from kinhDichTools.ts

- **Description:** Extract the trading-context string-builder (lines 1031-1038) into a named exported function so the TDD test can call it directly without registering an MCP server.
- **Input:** `trend: string` — the uppercase trend label from `data.state.trend`
- **Output:** `string` — the accented Vietnamese trading context sentence
- **Current inline code (lines 1032-1038):**
  ```
  if (trend.includes("THUAN LOI") || trend.includes("THUẬN LỢI")) {
    tradingContext = "THUAN LOI cho giao dich — xu huong tich cuc";
  } else if (trend.includes("BAT LOI") || trend.includes("BẤT LỢI")) {
    tradingContext = "BAT LOI cho giao dich — can than trong";
  } else {
    tradingContext = "TRUNG TINH — can xem them tin hieu khac";
  }
  lines.push(`Nhan dinh giao dich: ${tradingContext}`);
  ```
- **Required strings (accented):**

| Branch | Current (broken) | Required (correct) |
|---|---|---|
| THUAN LOI branch | `"THUAN LOI cho giao dich — xu huong tich cuc"` | `"Thuận lợi cho giao dịch — xu hướng tích cực"` |
| BAT LOI branch | `"BAT LOI cho giao dich — can than trong"` | `"Bất lợi cho giao dịch — cẩn thận"` |
| else branch | `"TRUNG TINH — can xem them tin hieu khac"` | `"Trung tính — cần xem thêm tín hiệu khác"` |
| header label | `"Nhan dinh giao dich"` | `"Nhận định giao dịch"` |

- **Business rule:** "BAT LOI" as a lookup key in `kinhDichReading.ts` is NOT touched — only the user-facing output string changes.
- **DDD layer:** interface
- **File:** `src/interface/mcp/tools/kinhDichTools.ts:1031-1040`
