# REQ-041: Chuỗi Cung Ứng Động

status: APPROVED
sprint: 041
po_vision: Nâng cấp tradeRelationships từ static map thành dynamic supply chain intelligence. Theo dõi Baltic Dry Index, cước container, tắc nghẽn cảng → ảnh hưởng thực tế đến HPG (thép nhập), VNM (sữa xuất), GVR (cao su xuất), GMD (logistics). Cảnh báo trước 1-2 quý so với BCTC phản ánh.

---

## User Stories

### US-1: Chỉ số vận tải
As a Vietnamese stock investor,
I want the system to track global shipping indices (Baltic Dry, Freightos FBX, container rates Asia-US/Asia-EU),
So that I get early signals about import cost pressure (HPG steel scrap) or export competitiveness (VNM dairy, GVR rubber).

### US-2: Gián đoạn chuỗi cung ứng
As a Vietnamese stock investor,
I want the system to detect supply chain disruptions (port congestion, strikes, canal blockages) from news,
So that I receive alerts about logistics stocks (GMD, PHP) and companies with heavy import/export exposure.

### US-3: Dynamic trade exposure
As a Vietnamese stock investor,
I want the system to dynamically update trade exposure weights based on BCTC data and news,
So that the cascade engine uses current data instead of hardcoded estimates.

## Functional Requirements

### FR-1: Shipping Index Fetcher (`src/infrastructure/fetchers/shippingIndex.ts`)

- **Description**: Fetch global shipping indices from Yahoo Finance / Trading Economics.
- **Indices tracked**:
  - Baltic Dry Index (BDI) — bulk shipping cost indicator
  - Freightos Baltic Index (FBX) — container shipping Asia routes
  - Shanghai Containerized Freight Index (SCFI) — China export routes
- **Source**: Yahoo Finance tickers (^BDI or equivalent), Trading Economics API.
- **Output**: `ShippingIndex[] { name, value, change, changePct, date }`
- **Polling**: Piggyback on existing macroFetch (Step A2) — add shipping indices.
- **Error handling**: Never throw. Use existing Yahoo Finance fetcher pattern.

### FR-2: Supply Chain Analyzer (`src/domain/services/supplyChainAnalyzer.ts`)

- **Description**: Pure domain service. Map shipping index changes to stock-level impact.
- **Impact mapping**:
  | Index change | Stock | Impact | Reasoning |
  |---|---|---|---|
  | BDI +20% (1σ) | HPG | BEARISH | Thép nhập phế liệu chi phí tăng |
  | BDI +20% (1σ) | GMD | BULLISH | Doanh thu logistics tăng |
  | Container Asia-US +30% | VNM | BEARISH | Chi phí xuất sữa sang Mỹ tăng |
  | Container Asia-EU +30% | GVR | BEARISH | Chi phí xuất cao su sang EU tăng |
  | BDI -20% (1σ) | HPG | BULLISH | Chi phí nguyên liệu giảm |
- **Uses σ-based thresholds**: Integrate with existing `macroThresholds.ts` pattern.
- **Output**: `SupplyChainSignal { index, deviation, affectedStocks, direction, reasoning }`
- **Pure function**: No I/O.

### FR-3: Supply Chain Event Detector (`src/domain/services/supplyChainEventDetector.ts`)

- **Description**: Pure domain service. Detect supply chain disruption events from news text.
- **Vietnamese + English patterns**:
  ```
  tắc nghẽn cảng, port congestion, đình công cảng, dock strike,
  kênh Suez, Suez Canal, kênh Panama, Panama Canal,
  thiếu container, container shortage, gián đoạn chuỗi cung ứng,
  supply chain disruption, force majeure, allocation shortage
  ```
- **Output**: `SupplyChainEvent { eventType, severity, affectedRoutes, affectedStocks, confidence }`
- **Pure function**: No I/O.

### FR-4: Dynamic Trade Exposure Update

- **Extend `tradeRelationships.ts`**: Add method `updateExposureFromBctc(code, report)` to dynamically adjust trade exposure weights when BCTC data is parsed.
- **Extend `tradeStore.ts`**: Store timestamped exposure updates.
- **Wire into BCTC pipeline**: After `parseBctcReport()`, extract revenue breakdown by geography if available → update exposure.

### FR-5: Cascade Engine Extension

- **Add `SUPPLY_CHAIN_RULES`** to `cascadeEngine.ts`:
  ```
  shipping_cost_surge → oil_gas (HPG import), logistics (GMD revenue)
  port_disruption → all exporters + importers
  route_blockage → specific geographic exposure
  ```

### FR-6: Signal Integration

- **Extend `SignalType`**: Add `"supply_chain"` to union.
- **Wire shipping indices into macroStatsStore**: Store as tracked indicators for σ computation.

### FR-7: MCP Tool

- `get_supply_chain_exposure(stock?: string)` → Current supply chain exposure + active disruptions
