### FR-2: OHLCV Guard Checks Implementation + Test Coverage

**Description:**
Commit ff55779 added guard checks to `ohlcvDailyAggregatorJob.ts` (lines 103–112) to skip tickers if any OHLCV component is undefined. Formalize into test suite with 4+ test cases.

**Input:**
- market_prices_history table with missing/sparse price data
- Daily aggregation window (24h)

**Output:**
- daily_ohlcv inserts only for tickers with complete O, H, L, C, V
- tickersSkipped counter incremented for incomplete tickers
- Audit logging with ticker code + reason (missing open/close/high/low/volume)

**Business rule:**
- Open = earliest price tick in window
- Close = latest price tick in window
- High = MAX(price) in window
- Low = MIN(price) in window
- **Guard check**: if any of {open, close, high, low} is undefined, skip ticker
- Volume = count of ticks in window (must be > 0, inferred from row count)
- No NULL inserts into daily_ohlcv; partial tickers silently skipped + logged

**DDD layer:**
- `scheduler` — job execution + skip logic (already in place)
- `domain/services` — OHLCV validation (guard checks are inline in current implementation)

## Non-Functional Requirements

- **Performance:** Ops baseline health check ≤30s (skip expensive diagnostics if green)
- **Data freshness:** OHLCV aggregation daily (no real-time requirement)
- **Language:** Vietnamese financial terms in logs (e.g., "Không có dữ liệu giá" = "No price data")
- **Timezone:** All times in GMT+7 (Asia/Ho_Chi_Minh) for VN market alignment
- **Reliability:** Guard checks never allow partial OHLCV to insert; fail-silent on incomplete tickers

---

## Edge Cases & Data Quality

- [ ] Market closed (no ticks in window) → skip ticker, log warning
- [ ] VPS price-fetch stopped mid-day → sparse ticks, open or close undefined → skip
- [ ] Price spike outlier (e.g., 0.01 VND) → still included in high/low (no validation, just aggregation)
- [ ] Duplicate ticks from VPS retry → COUNT() includes all, no dedup (acceptable for volume)
- [ ] OHLCV already exists for date → ON CONFLICT clause upserts (idempotent)
- [ ] SQLite timeout on slow disk → job fails gracefully, retry next cycle
- [ ] Ops agent SSH timeout → escalate, do not retry indefinitely
