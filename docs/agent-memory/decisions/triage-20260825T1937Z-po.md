### Root cause, restated against the evidence

The envelope proposed "the B-01..B-13 check has no trading-calendar guard, route it through
vnTradingCalendar.ts". **That premise is false and would have produced the wrong fix.** The guard
already exists, in three places:

- `docs/agents/system-auditor/flow/main.md:425` — "Skip foreign-flow check outside VN market hours

  already wired, already reusing the trading-calendar module

- `docs/data/system-map.json` — `market_hours_only: true` already set on foreign-flow

Three guards existed and the cycle bypassed all three. So the durable defect is **not a missing
calendar predicate**. It is that `data_sources[]` cannot *express* the two properties the check

hardcoded exceptions — which is precisely the shape that already produced
`FIX-AUDITOR-B05-BCTC-FRESHNESS-LAYER-SPLIT` and `FIX-AUDITOR-B11-NEWS-FRESHNESS-LAYER-SPLIT` as
separate per-source patches.
