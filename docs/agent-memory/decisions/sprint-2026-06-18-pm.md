**why-change:** Adaptive tool selection per environment. jq works great on small files; large files need Python or manual shell-fu. No policy violation; both are atomic mutations.

**decision:** Use Python script to update orch-state.json (move ARCH task review → done, add 4 subtasks to ready, update _updated_at/_updated_by metadata). Commit discipline: explicit-stage only (orch-state.json + pm.md + sprint-*-pm.md + 4 handoff .md files). Verify git diff before commit (no intruders).
