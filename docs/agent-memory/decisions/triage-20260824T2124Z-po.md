## Decision 2 — the fix must not become the bug it replaces

current bug = INFORMATION ABSENCE (honest, empty); careless fix = FALSE ASSERTION
(actively misleading), strictly worse.
what-considered: prose warning in the desc vs. a hard AC.
why-change: prose loses. Proven on THIS table: BA spec `BA-DASH-CRON-RECHECK-TABLE.md:364`
carried "(Layer-A, never fired)"; architecture brief `2026-07-02-...:127` dropped the
qualifier; the implementer built the unqualified version. That dropped qualifier IS the
bug just fixed. → conditional framing written as AC-2 (hard, testable, blocks AC-1),
plus AC-3 (named exported constant — the column-1 string escaped every test by being an
inline literal) and AC-9 (brief correction, so it cannot be re-widened).

`zone` set to `apps/frontend/` as the collision-free DEFAULT with AC-8 instructing a
