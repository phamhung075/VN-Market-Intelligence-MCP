## Decision
Edited only the `CronCreate` prompt string in `cron-cowork-team/SKILL.md` (Step 2). New prompt
runs `cowork-tick-preflight.sh` first and branches on its one-line JSON `.verdict`:
- `SILENT` / `LOST_ELECTION` / `DEFER` → done, no further reads (script already handled
  pressure-state emit + lock release, or never claimed the lock).
- `WORK` → read `main.md` starting at `§ WORK continuation` (matches `main.md`'s own JUMP-TO
  table row verbatim — do NOT re-run Steps 0b/0b.3/0c/1-4b).
- `ERROR` → read `main.md` starting at **Step 0a**, not the file top — `main.md`'s own ERROR row
  says "read from Step 0a onward as if the script never ran"; re-reading Step 0 would re-invoke
  the already-errored preflight script a second time. This is a deliberate deviation from the
  audit brief's loose shorthand ("read main.md from the top") in favor of `main.md`'s actual
  internal contract.
Also updated the stale "prompt text below is UNCHANGED" WU-1 note (Notes section) to a WU-2
supersession note, so the file no longer contradicts itself. Did NOT touch `main.md`, the
preflight script, cadence, or the idempotency-guard check (Step 1 matches on `description`, not
prompt text — unaffected).
