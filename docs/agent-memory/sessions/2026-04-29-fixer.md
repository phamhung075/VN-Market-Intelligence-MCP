### Fix 1 — Year guard in extractNumber fallback loop

**Issue**: The fallback loop in `extractNumber` (lines 66–70) had no year guard. Bare 4-digit year tokens from legal references like "Nghị định 93/2017/NĐ-CP" slipped through and were returned as financial values.

**Root cause nuance**: A naive 1990–2030 guard breaks legitimate values like `2.000` (= 2000 triệu), because `parseVnNumber("2.000")` returns 2000 which is in the year range. Fix uses a BARE_YEAR regex (`/^\d{4}$/`) to distinguish bare year literals (no thousands separator) from Vietnamese-formatted numbers.

**Change**: Fallback loop now skips a token only when it is a bare 4-digit integer in 1990–2030.

This is a pre-existing structural gap requiring a bank-format parser — out of scope for this 2-file fix.
