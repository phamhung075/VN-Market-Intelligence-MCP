   - Diagnosis: networkidle event completes before PDF DOM insertion (timing gap)

### Key Finding

**Portal Discovery Architecture:**
```
Browser requests page → Server returns HTML shell (no PDFs)
                      ↓
                    React mounts, renders layout
                      ↓
                    Playwright `wait_until='networkidle'` completes ← WE ARE HERE
                      ↓
                    AJAX request for PDF list fires in background
                      ↓
                    ~500-2000ms later: DOM populated with PDF links
```

The wrapper waits for network idle (good practice), but the PDF links load asynchronously **after** that event.

### Remediation Plan (For Dev Team)

**Option A (Quick, 1h):** Add explicit wait for selector
```python
await page.wait_for_selector('a[href*=".pdf"]', timeout=10000)
```

**Option B (Better, 2h):** Inspect portal network requests, call API directly

**Option C (Thorough, 3h):** Portal-specific HTML parsing (inspect each portal's actual structure)
