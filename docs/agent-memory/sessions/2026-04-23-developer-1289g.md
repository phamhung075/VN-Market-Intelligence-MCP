## Technical Decisions & Rationale

### Decision 1: Enhance Wait Strategy Instead of Rewriting
**Why Not Change Portal URLs?**
- Tested URLs work (page loads, returns 107 links)
- Issue is content timing, not URL correctness
- Risk: Changing URLs blindly could break other things

**Why Not Switch to SSC Portal?**
- SSC is documented as JavaScript-only SPA (harder)
- HOSE/HNX simpler once timing fixed
- SSC should be fallback, not primary

### Decision 2: Add Alternative Selectors Instead of API
**Why Not Use Direct API?**
- API spec documented but never verified to actually exist
- Safer: Enhance working Playwright approach
- If API route needed, can implement later with proof

**Why Not Change CSS Selectors?**
- Primary selector `.pdf` is correct (same selector works in manual testing)
- Issue is timing (PDFs not in DOM yet), not selector
- Added fallback selectors for structural variations

### Decision 3: Conservative 5.5s Wait vs. Longer
**Why 5.5s Not 10–15s?**
- 5.5s is reasonable for JS rendering (most SPAs < 3s, 5s covers 95%ile)
- 10–15s makes backfill slower (296 PDFs × extra wait = many minutes)
- Better: Deploy 5.5s first, escalate only if needed

### Decision 4: Enhanced Logging for Debugging
**Why Add stderr Output?**
- If tests fail, need visibility into what happened
- 4 log points show: HTTP status, link count, selector fallback path
- Enables quick diagnostics without code changes
