# Session Logs — Retention Policy

## preflight-lsof-*.log (HEAD.lock diagnostics)

**Retention:** Last 7 days
**Rotation:** Automated via cron / janitor sweep (cleanup-lsof-logs job)
**Purpose:** Diagnostic logs for git HEAD.lock contention on concurrent agent worktree operations

**Rotation trigger:**
- Manual: `docs/agent-memory/sessions/ | find . -name "preflight-lsof-*.log" -mtime +7 -delete`
- Scheduled: janitor agent, every 3 hours after scan cycle

**Rationale:**
- Each cycle may generate 1–3 logs (one per agent worktree)
- Logs are diagnostic only — not source of truth
- 7-day retention covers ~150–200 logs before disk overhead becomes meaningful
- Older logs rarely needed for root-cause analysis
