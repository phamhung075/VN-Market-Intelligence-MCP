### 1349b: Circuit Breaker State Logging (M, 1.5h)

**Problem:** PDF download, Reuters fallback, foreign-flow jobs have circuit breakers but state transitions unlogged.

**Solution:**
1. Create `src/infrastructure/observability/circuitBreakerLogger.ts` middleware
2. Wrap CB.transition() calls with structured logging:
   ```
   {
     timestamp: ISO,
     job: string,
     state_old: 'closed' | 'open' | 'half-open',
     state_new: 'closed' | 'open' | 'half-open',
     reason: string (e.g., "error_threshold_exceeded"),
     error_count?: number,
     reset_timeout_ms?: number
   }
   ```
3. Wire logger into 3 affected jobs (pdfDownloadJob, reutersFallbackJob, foreignFlowJob)
4. Log at INFO level (ops visibility)

**Acceptance:** All CB transitions logged with reason; no silent failures.
