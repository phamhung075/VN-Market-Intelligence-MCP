## Decision Log

**Why restore 30 tickers vs. audit missing ones?**
- Ops confirmed 30-ticker watchlist was intentional user baseline (Sprint 054)
- Microservices migration reset the DB accidentally
- Restore from MEMORY.md watchlist catalog (canonical source)

**Why RED-GREEN for HOSE discovery (1343b–1343c)?**
- TDD discipline: write failing tests first to define contract
- Allows developer to verify implementation against real test cases
- Enables fallback strategy validation (SSC → cafef → vietstock)

**Why POST /api/bctc-skip not retry logic?**
- VPS script stateless; MCP is source of truth for queue state
- Skip endpoint marks status='skipped' so DB filters them out
- Cleaner state machine: pending → skipped (not infinite pending)

**Why integrate 1343d independently?**
- VPS skip endpoint doesn't depend on watchlist restore or PDF discovery
- Can be implemented + tested in parallel with 1343a–1343c
- Reduces critical path time
