OpenAPI Contract (P2-H)

OAS 3.0.3

The stock-price service exposes a formal OpenAPI 3.0.3 contract created in Phase 2 task P2-H. The contract is self-describing: zero credentials, served from the repo as a static YAML file.

📄
../api/openapi.yaml — OpenAPI Contract (OAS 3.0.3)
Covers: GET /health, POST /price/fetch, GET /price/history, GET /price/history/{code}
Endpoints defined in contract:
GET /health — Liveness probe, returns service name + port
POST /price/fetch — Fetch price for one or more tickers (3-tier fallback)
GET /price/history — OHLCV history, params: code=X&days=N
GET /price/history/{code} — Path-param variant (backward compat)

          (AC-2 / R-CGO gate). The sandbox has zero DB access, zero network calls, zero API keys (AC-3 / G7 security contract).

  -tier=all \
  -module=stock-price \
