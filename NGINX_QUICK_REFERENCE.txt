EMERGENCY PROCEDURES
─────────────────────
If nginx won't start:
  1. docker-compose logs nginx (check error)
  2. docker-compose exec nginx nginx -t (validate)
  3. docker-compose down
  4. docker-compose up -d nginx

If services unreachable:
  1. docker-compose ps (check all running)
  2. docker-compose logs nginx (check proxy logs)
  3. curl -v http://localhost/vn-market/health (test connectivity)
  4. lsof -i :80 (verify port binding)

If SSL cert issues:
  1. Check expiry: openssl x509 -in ssl/cert.pem -noout -dates
  2. Check validity: openssl x509 -in ssl/cert.pem -text -noout
  3. Replace cert: cp new_cert.pem ssl/cert.pem && docker-compose exec nginx nginx -s reload
