================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Origin Unreachable" in Cloudflare
Fix:
  1. Verify A record IPv4 is correct (not localhost)
  2. Check firewall allows port 443 inbound
  3. Verify nginx is running: docker-compose ps nginx
  4. Test locally: curl https://localhost/health

Problem: SSL Certificate Error (Browser)
Fix:
  1. Ensure you uploaded Cloudflare origin cert (not self-signed)
  2. Verify SSL mode is "Full (strict)"
  3. Wait 5 minutes for DNS to propagate
  4. Clear browser cache

Problem: Headers Missing
Fix:
  1. Verify DNS is "Proxied" (orange cloud, not gray)
  2. Wait 5 minutes for DNS propagation
  3. Check logs: docker-compose logs nginx
